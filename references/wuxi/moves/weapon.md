# 兵器招式

每次兵器动作写清持握手、兵器部位、攻击线路、距离变化、接触反馈、受力方向和收回状态。

## 基本顺序

`持械状态 → 起手与步法 → 兵器线路 → 接触、格挡或落空 → 兵器与身体反馈 → 收势、换位或追击`

刃器表现刃线和切割接触，长柄表现距离与转向惯性，钝器表现重量与形变，远程器械表现瞄准、弹道、遮挡和后坐。换手、脱手、损坏、收回和再次拿起必须有可见过程。

## 连续约束

- 同一兵器跨镜头保持类型、数量、尺寸、持握手和状态一致。
- 兵器碰撞写出接触部位、弹开、滑开、摩擦或震颤。
- 没有用户指定时不增加武器、弹药、护具或变形。
- 兵器名称不自动生成喊招台词，也不自动决定胜负。
