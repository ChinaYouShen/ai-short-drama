# 徒手招式

每次徒手动作写清支撑脚、重心、身体朝向、出手部位、攻击或控制线路、接触部位、对手反应和回收姿态。

## 基本顺序

`站稳或移动 → 进入距离 → 起手 → 出手或控制 → 接触或落空 → 受力反馈 → 回收、追击或脱离`

拳、掌、肘、膝、腿、擒拿和摔投都要落成可见动作，不只写招式名。被控制的肢体不能同时完成冲突动作；松脱、换向、起身和转身要有过程。

## 物理约束

- 支撑脚和重心支持当前攻击方向。
- 受击方向、身体位移和脚下摩擦保持一致。
- 贴身动作看清双方前臂、手腕和接触点。
- 大幅摔投、翻滚和腾空保留完整身体路径。
- 没有用户设定时不补拳种、摔法、伤势、骨折或致命结果。
