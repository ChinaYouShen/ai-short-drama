# 武戏交付检查

- 招式顺序、目标、结果和用户要求一致。
- 每个关键动作都有起势、线路、接触或落空、响应、受力和下一状态。
- 人物、武器、能力、朝向、距离、人数和伤势跨镜连续。
- 动作数量、台词和自然时长匹配。
- 有人物的镜头没有远景或大全景；中景只在必要时短暂出现，主体和动作接触点清晰可辨。
- 运镜服务招式或观察目标，跨镜方向、人物位置、动作线路和轴线连续。
- 声音与实际动作绑定，配乐和现场声音分层。
- 没有新增未授权的角色、武器、能力、伤势、对白、胜负或环境破坏。
- 没有重复招式、重复构图、重复受力方向或无过程复位。

## 用户锁定项逐条回写

交付前把用户说过的话分条列出来，一条一条对着成稿核对，不凭印象概括：

- 必须出现的动作、招式名、顺序；
- 明确禁止的动作、招式、镜头或表现方式；
- 必须保留的台词、喊招、结算和结尾画面；
- 时长、画幅、写实程度等硬指标；
- 指定的胜负、伤势、存活与是否见血。

每条都要能指出成稿里对应哪一处。全程没有出现的，要么补上，要么在交付时明确说明为什么没做到；不能用「已按用户要求处理」一句概括代替逐条对账。用户给的禁用项尤其不能破，为了画面张力放宽禁用项一律算不合格。

## 跳过的参数要交代

动作载体、战斗人数、分镜方式这类可选参数，如果因为信息足够而跳过，在交付里用一行说明跳过了哪些、按什么默认处理；不默默替用户决定。

## 必杀技另加六条

用于带名字、喊招、法相或场域的大招，按 [ultimate/index.md](ultimate/index.md) 核对：

- 范式判断与招式对得上，该范式的镜序一镜不缺；单体突进型不得省掉突进镜。
- 四段时长加起来等于总时长，喊招字数按 4.1～4.5 字/秒能放进对应秒数。
- 把能量层删掉后，身体层仍能看懂谁打了谁；法相落点与本体的接触点在同一处。
- 一招只有一个主色、一种主要光形、一个暖点色；法相比例全程 1.2～1.5 倍。
- 命中反馈至少两项；法相在命中后 1～2 秒内散干净；最后一帧停在最高点。
- 没有写「无数拳」「漫天拳影」「众人皆被震退」「天崩地裂」这类不可生成的概括；同人四条边界逐条对过。

## 可机检项（交付前用 `scripts/validate.py --prompt` 跑一遍）

脚本实际会拦这些，不是"建议人工确认"：

- **字段结构（P11）**：基础路线三字段／多参考六字段必须齐全且顺序固定，缺一个、颠倒一个都阻断。
- **时间码（P3）**：全部 `mm:ss.mmm`；首镜写 `At` 必须是 `00:00.000`，不写时第一个 `At` 就是第二镜起点且 ≥2 秒；段内严格递增。
- **镜长（P7）**：相邻切点差值 2～5 秒；首镜不写 `At` 时按切点连差推算（1 号镜从 0 秒起），不从 0 秒重算每个切点；**末镜（P12）**由「声明总时长 − 末镜起点」推出，同样必须落在 2～5 秒。
- **段长（P8）**：正文必须能找出「本段总长约 X 秒」，一段一句；超 15 秒阻断，动作与台词合计。
- **台词容量（P9）／密度（P10）**：可发声字数 ÷ 4.1 必须放得进本段；说话占本段超过 71% 给警告。
- **时间线（P21）**：任何一段都必须有 `[Shot N]` 与 `At mm:ss.mmm`；只有六段头、没有镜头时间线的提示词直接阻断——那不是视频提示词，只是设定。
- **路线一致（P22）**：路线由用户选择决定。写 I2VA／L2VA 还引用多张 `<Picture N>`、写 FL2VA 引用超过两张、写多参考却出现「首帧／尾帧／硬帧」都阻断；「不做首帧锁定」这类否定表述不拦。
- **语言码（P14）**：每组台词必须是 `<d>[完整语言名] 原文</d>`（Chinese、English…），写成 `zh`／`en` 短码阻断。
- **说话人（P13）**：有台词就必须有 `(S1)(S2)`，按首次发声顺序从 1 连续分配，跳号阻断。
- **主色（P15）**：一段内只允许出现一个色值；出现第二个 hex 阻断。
- **法相比例（P16）**：出现法相／金身时必须有明确倍率且落在 1.2～1.5 倍。
- **门派约束（P17／P18）**：加 `--method 武功名` 后，无光 12 门正文不得出现发光、光晕、光形；不给暖点 8 门不得出现暖色、暖点、火花。
- **角色名（P1）**：正文不得出现角色姓名，只允许在 `<d>` 台词里。
- **参考编号（P4）**：`<Picture N>`／`<Video N>`／`<Audio N>`／`<Subject N>` 各自从 1 起、不跳号。
- **音频账（P19）**：用了 `<Audio N>` 就必须在保留分析里有对应行，写清音色参考／对白复用／配乐参考。
- **图片绑定（P20）**：每张 `<Picture N>` 都要在同一行写明它对应哪个 `<Subject N>`，不许按上传顺序默认配对。
- **否定式动作（P5）**：只提醒不阻断；「没动」「没有收回」这类画不出来，改成正向描述。

```bash
python3 scripts/validate.py --prompt 某段提示词.txt --names 沈砚,苏晚
python3 scripts/validate.py --prompt 某段提示词.txt --method 独孤九剑
python3 scripts/validate.py --self-test
```

多段输出一次检查：脚本按段切开，每段各自判时间码、镜长、段长和台词容量，不会把「第二段从 `00:00.000` 起」误判成时间码倒退。
