# 降龙十八掌 招式链

所属分类：东方武侠 / 丐帮。分类说明见 [../../catalog/wuxia.md](../../catalog/wuxia.md)。

一套十八招的武学，用法是三层递进，不是十八连发。这份给的是：十八掌的参数表、三掌连段、一掌的成品级分镜与提示词。

## 版本差异先说清

十八掌的名单在不同版本里不一样，最常见两套：

- 一套以「亢龙有悔」开头，中间含「震惊百里」「突如其来」「履霜冰至」「羝羊触藩」，末招作「六龙回旋」或「神龙摆尾」；
- 另一套把「鱼跃于渊」「尺蠖之屈」并入，把部分招名替换掉。

下面的表按第一套排。你手上如果是另一套，换掉对应行即可，结构与分层不动。原文里没有明确卦象出处的，表里写「未确」，不替它编一个。

## 掌法共性

| 项 | 值 |
| --- | --- |
| 掌力形态 | 金龙：龙首在掌前，龙身随掌势拖出，掌到之处龙首先到 |
| 主要光形 | 面状（掌印与冲击面），全谱只用这一种；龙形属于法相体量，不是第二种光形 |
| 主色 | 金 `#E8C45A` |
| 辅色 | 赭 `#7A4A16` |
| 高光 | 暖白 `#FFF3D0` |
| 暖点 | 朱红 `#D94F2B`，只给命中掌印，面积不超过画面 5% |
| 法相比例 | 起手 1.0～1.1 倍、压上 1.2 倍、收束 1.4～1.5 倍 |
| 共性动作 | 掌推出的过程里掌势在最后一寸略收，接触点前留一小段空白——这是「发七分留三分」的可见证据 |

## 光形与范式的对应

同一条「一招只用一种主要光形」的规矩，落到五种范式上是不同的形状。掌法里的「龙形」是法相体量，不占光形名额：

| 范式 | 主光形 | 说明 |
| --- | --- | --- |
| 单体突进 | 面状掌印 | 一枚或多枚掌形实体光印，沿掌力方向推出 |
| 连打 | 多枚短面掌印，或两道平行光带 | 每一下一枚，不叠成一团 |
| 范围场 | 环状或放射 | 以脚或掌为圆心向外扩，允许波纹与放射裂 |
| 束缚 | 线状贴合 | 光只沿接触线走，不外扩 |
| 召唤 | 面状 | 法相本体负责体量，光只做前缘 |

范围场那两招（震惊百里、六龙回旋）用环状，不是破例，是这一范式的标准形状。别的招不许借用。

## 逐招提示词片段

每一段可以直接粘进 H3 提示词的对应镜头里，接在该镜的动作描述之后。主语按角色填，颜色按 [../palette.md](../palette.md) 的槽位描述。

- **亢龙有悔**：掌推出时，一枚完整的金色掌形光印脱掌而出，边缘锐利，掌后拖着一条拉直的龙形虚影；掌到最后一寸时手肘仍微屈，光印在接触点前微微一顿，随后落点炸开一小片朱红。
- **飞龙在天**：自上而下砸掌，头顶上方压下一道纵向的金色光柱，柱底是一枚平压的掌印，龙首自上倒压贯穿画面，落点四周的石子同时向上浮起再砸下。
- **见龙在田**：侧身斜切，一道细长的金色掌印贴着地面掠出，龙首低伏在尘里，沿路把浮土推成扇形，地面上留下一条斜向擦痕。
- **潜龙勿用**：左右两掌同时递出，两枚短掌印自两侧合拢夹向胸口，细密金点从指尖散开，胸前空气被压出一道波纹，两处受压后身体前折。
- **利涉大川**：双掌交叠向前横送，一枚宽而薄的长条掌印横扫而出，龙身随之拉成一道水平水线，把两人之间的距离整片切开，衣摆被掀成一片。
- **鸿渐于陆**：掌势贴地低走，两枚低位弧掌印先后掠出，掌缘把尘土卷成一个低矮的环，地上出现两道平行擦痕。
- **或跃在渊**：提气后左掌前探、右掌自左掌下方穿出，一枚窄掌印自下向上窜起，龙首从下方穿过，金点向上喷射后回落，地面被顶起一小块。
- **双龙取水**：双掌齐发，两枚掌印并排前推，两条龙首平行探出，双线碎光拖在掌后，两侧尘浪向左右分开，双肩同时受压后仰。
- **密云不雨**：掌压在对方手臂上而不发力，光只沿接触线走成一条细线，龙身盘旋压住对方手臂、龙首低垂不动，几乎没有粒子，只有被压出的细尘线。
- **损则有孚**：双掌交替连拍，两枚短掌印一上一下轮替落下，每次接触散出一小簇金屑，地面被拍出两个浅印，对方随节奏一顿一顿后移。
- **突如其来**：收着的手臂突然直拍，光印极短，几乎贴着身体才成形，只有半截龙首窜出，爆开一小团光屑，对方衣料被压出褶皱、来不及抬手。
- **震惊百里**：双掌并出，以脚下为圆心炸开一圈金色震波，龙身散成环、龙首消失，碎石与尘整体浮起再落下，地面出现放射状裂纹，同框两三人各自后退。
- **时乘六龙**：掌随身走一路劈开，一枚宽掌印带出六道分叉尾，近处三条龙首实、远处三条虚，大片碎屑被顶着前推，墙体被推出凹槽。
- **神龙摆尾**：背身旋腰反手扫出，一枚弧形带状掌印沿弧线掠出，龙尾横扫、龙身旋成弧，地面被扫出弧痕，身后的偷袭者被扫中横向飞出。
- **履霜冰至**：右拳左掌一直一横同时到，一横一竖两枚薄掌印交叉成十字，龙首与龙爪同时抵达，接触处空气凝出一层薄霜状的冷光，地面泛白。
- **龙战于野**：贴身处虚实相生，龙首绕身游走、龙身成圈，短掌印方向不断变化，密集小碎光贴着身体闪，对方手臂被缠住带偏重心。
- **羝羊触藩**：全身重量压进掌里前冲，楔形掌印前窄后宽，龙首低垂如顶角、龙身压成楔形，整片碎屑被顶着前推，地面犁出一道沟。
- **六龙回旋**：旋身连掌绕身一周，环状回旋面加多道弧线掌印，六条龙身绕身成环、龙首交替扫出，碎光带绕身一周，四周物体依次倾倒。

## 从表里选招的三条

1. **收束层只有四招**：亢龙有悔、震惊百里、时乘六龙、六龙回旋。要收得响，就从这四招里挑一招，别挑起手招当终结。
2. **起手层挑功能不同的两招**：一个负责扰（见龙在田、龙战于野），一个负责脱（利涉大川、鸿渐于陆）。功能重复就只留一个。
3. **压上层优先选能承接的**：飞龙在天接跃起，神龙摆尾接背身，羝羊触藩接前冲，或跃在渊接提气。看上一招把你送到什么姿态，再挑下一招。

## 三掌连段：见龙在田 → 飞龙在天 → 亢龙有悔

13 秒 5 镜，三层各一掌。想拉到 15 秒，把镜 5 从 2.8 秒加到 3.6 秒，余波写细，不加新招。

### 自检

- 范式：单体突进型，3 镜落在 3～4 镜区间。
- 时长：2.6＋2.4＋3.0＝8.0 秒，每镜 2.4～3.0 秒。
- 喊招：4 字 ÷ 1 秒 ≈ 4 字/秒，在 4.1～4.5 下限附近，可再给 0.1 秒余量。
- 身体层：删掉龙与光之后，仍是「划圆蓄势—沿弧推掌—掌停人退」三步，成立。
- 留手证据：手肘微屈、掌势最后一寸收住、回收气流，三项都有。
- 色彩：一个主色、一个暖点色、一种主要光形（面状掌印）。
