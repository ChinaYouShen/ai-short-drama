# 圣斗士星矢 必杀技案例库

所属分类：神话神系 / 青铜与黄金。分类说明见 [../../catalog/mythos.md](../../catalog/mythos.md)。

这不是设定集复刻，是把原作招式拆成可生成的参数表：查范式、查主色、查光形、查法相、查时长镜数，然后按范式套镜序。角色与招式版权属原作者与版权方，使用边界见 [../index.md](../index.md) 的「同人与版权边界」。

## 使用方式

1. 在参数表里找到招式，拿到范式、主色、光形、法相形态、时长、镜数。
2. 按该范式的镜序排镜头，四段结构与时长按 [../index.md](../index.md) 分配。
3. 法相细节读 [../aura.md](../aura.md)，配色读 [../palette.md](../palette.md)，爆发与收束读 [../finisher.md](../finisher.md)。
4. 需要逐镜成品与完整提示词的，直接照 [pegasus-meteor.md](pegasus-meteor.md) 的结构改写。

## 主色与共色登记

主色列只写基色，辅色与暖点在这里统一登记。三条规则：

1. **黄金十二人共用金系**，不靠颜色区分，靠光形与法相形态区分——所以十二人之间允许同色，但「主要光形」必须两两不同。
2. **同门同技可以共色**（冰河的钻石星尘与卡妙、紫龙与童虎的百龙霸、撒加与加隆的银河星爆），这种情况必须在光形或法相上做一处可见差异。
3. **其余角色主色唯一**，同一场戏里不允许两个非黄金角色同主色。
4. **第二招可以设同色相变体**（同一角色为区分招与招，允许在同色相内调明度或加一档色），但必须在登记表里写明是哪一招、怎么区分，不能临时换色。

## 五种范式的镜序

每格写的是「这一镜必须完成什么」，不是景别清单；具体景别与运镜按 [../../cinematography.md](../../../cinematography.md) 选。

### 连打型（4～6 镜）

1. **起势** 1.5～2.5 秒：承接上一姿态，重心下沉，拳收到腰侧，地面起裂纹，能量只在脚底、拳心两处起亮，法相未成形。
2. **宣言＋显形** 2 秒：喊招，身后空间起法相轮廓到六成。
3. **可见段** 2 秒：3 拳，写清拳路与落点，留 3～5 个残影。
4. **成线段** 2 秒：光带贯穿画面，只留肩背与拳峰，接触点连续火花。
5. **结果段** 2.5～3 秒：只写落点、受击位移、环境反应，法相向内塌陷，停在最高点。

### 单体突进型（3～4 镜）

1. **起势＋宣言** 2.5 秒：几乎是同一镜完成，喊招时身体已经进入发力位。
2. **突进** 1.5～2 秒：一条线穿过去，本体与光同向，路径上留下被切开的霜、尘、火星。
3. **命中** 2 秒：接触点必须看清，位移与护具形变同时给。
4. **余波** 1.5 秒：停住，只留一件余波。

这条范式最容易写成「两镜」，中间那一镜省掉就成了闪现。突进镜不能删。

### 范围场型（4～6 镜）

1. **起势** 2 秒：脚下或掌心出现几何起点（环、裂纹、光点）。
2. **宣言＋场域生成** 2.5 秒：几何图形从起点展开，形状固定（环、阵、漩涡），不写「无数光点」。
3. **扩散** 2.5 秒：由中心向外推进，环境先受击（霜、裂、烧、灰）。
4. **主体反应** 2 秒：同框不超过 3 人，各写各的反应，不写「众人皆被震退」。
5. **余波** 2 秒：场域下沉、稀薄，残留物落地或飘散。

### 束缚领域型（4～6 镜）

1. **起势** 2 秒：本体的手势或站位先定。
2. **阵图显形** 3 秒：几何阵从脚下或空中展开，环与环之间有明确层级。
3. **包覆** 3 秒：逐层合拢，写清每层锁住什么。
4. **剥夺** 3 秒：受害者失去什么，用身体反应表现（视线偏转、手抓不住、膝盖下沉），不用旁白说明。
5. **崩解** 2 秒：阵图碎裂，碎片下坠。

这条范式不许用拳头解决，也不许把结局写成「打输了」。

### 召唤法相型（3～5 镜）

1. **起势** 2 秒：本体做出指向或张臂姿态，能量从背部或手臂缝隙窜出。
2. **法相显形** 2.5 秒：法相作为独立主体成形，有头、有朝向，眼睛先亮。
3. **法相冲出** 3 秒：走的是法相自己的运动轨迹，本体只保持指向，不再出拳。
4. **命中** 2 秒：法相落点等于目标位置，气浪与环境反应同时给。
5. **消散** 1.5 秒：法相向内塌缩，碎屑上飘。

## 检查清单

- 范式与招式对得上；该范式的镜序一镜不缺（尤其单体突进型的突进镜）。
- 一招只有一个主色、一种主要光形；法相比例全程 1.2～1.5 倍。
- 喊招字数按 4.1～4.5 字/秒能放进秒数。
- 命中反馈至少两项，落在同一个接触点。
- 法相在命中后 1～2 秒内散干净。
- 收尾停在最高点，不是摆造型。
- 没有写「无数拳」「众人皆被震退」「天崩地裂」这类不可生成的概括。
- 同人四条边界过一遍：文字提示词、自建参考图、标注同人非官方、不商用。
- 招式名进表前先确认：译名不统一的进「待核实清单」，不要凭印象补进参数表。
- 与别的角色同主色时，光形或法相必须有一处可见差异，先查「主色与共色登记」再动笔。
