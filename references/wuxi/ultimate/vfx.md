# 特效提示词堆砌

所属分类：武戏 / 必杀技。上位说明见 [index.md](index.md)，配色见 [palette.md](palette.md)，法相见 [aura.md](aura.md)。

## 为什么单写打斗出不来特效

模型的默认行为是「拍两个人打架」：它给你真实的拳脚、真实的碰撞，但不会自己加光。写了「华丽的一击」，它只会把镜头摇得更花。特效必须被写成**画面里真实存在的东西**——有发光体、有形状、有运动方向、有落点、有残留物。写成一个物体，模型才画得出来；写成一个形容词，模型只会给你更亮的皮肤。

所以特效不是修辞，是**物件清单**。每一镜都要把下面五层填满，缺一层就掉一档。

## 特效主体：每招必须有一个「主角物件」

特效师接到一招，第一句话问的不是「多亮」，而是「飞出去的是什么」。降龙十八掌的亢龙有悔，答案是一条金龙：龙首先到、龙身随掌势拖出、掌收龙散。这一句定下来，镜头、光比、粒子、命中全都有依据；定不下来，拍出来就是两个人在推手。

所以每一招在参数表里必须先有**特效主体**，再谈五层。

### 三种主体类型

| 类型 | 长什么样 | 适合的招式 |
| --- | --- | --- |
| 生物型 | 有头、有躯干、有朝向的活物虚影：龙、凤、狮首、天马、蝎尾、蛇、魔女 | 召唤法相型、连打型的显形段 |
| 器物型 | 放大的真实物件：剑影、锁链、宝轮、竖琴弦、盾面、玫瑰、针、伞 | 束缚领域型、单体突进型 |
| 自然型 | 自然现象的放大：冰柱、极光、星屑漩涡、日蚀、雷柱、火墙 | 范围场型、神级招式 |

### 一句话公式

```text
<主体是什么、多大、什么材质或颜色> + <从哪出现> + <沿什么轨迹怎么动> + <命中时什么姿态> + <怎么消散>
```

举例：

- 亢龙有悔：一条金色龙形自掌前腾起，龙首昂起半人高，龙身随掌势拖出三米；龙首直冲对手胸口，龙身在后收卷；命中后龙首炸成金屑，龙身向内塌缩。
- 天马流星拳：数十条青蓝流星尾迹从双拳拖出，每条尾迹末端是一点白心光核；拳路斜下平行推进；每击落点炸开一圈小冲击环；尾迹熄灭成光点坠落。
- 天舞宝轮：一圈金色曼陀罗自脚下展开，环径四米，环间浮着佛像轮廓；逐层向内合拢；目标被困在轮心；宝轮碎成花瓣状光片飘落。

### 反例（这些写法等于没有特效主体）

| 写法 | 问题 |
| --- | --- |
| 只有手刀边光 | 没有物件，模型只会给手加个亮边 |
| 无外光，全靠重量与风压 | 观众看不见任何东西，等于普通挥剑 |
| 一团强大的能量 | 形状不可画，模型给出一团糊光 |
| 无形指力 | 无形就没有画面，必须给空气裂线、水汽痕这类可见痕迹 |
| 无数光点 | 数量不可控，最后变成雪花屏 |

**不发光也要有可见主体**：武侠里「无光」的招式，主体换成空气被压出的锥形、尘环、水汽裂线、衣料被撕开的方向，仍然是物件，只是材质是空气与尘。

## 照着范例学：六要素反推法

包里的两份现成范例已经把标准写全了，不需要另立一套：`cases/xianglong.md` 的逐招特效表（十八招各有一套龙形）和 `cases/pegasus-meteor.md` 的分镜表（天马流星拳五镜）。把它们拆开看，每一招都只回答了六个问题——照这六个问题去拆任何原作、任何招式，就能写出来。

| 要素 | 要回答的问题 | 亢龙有悔的答案 | 天马流星拳的答案 |
| --- | --- | --- | --- |
| 主体 | 飞出去的是什么 | 一条金色龙形 | 带翼天马虚影＋数十条流星尾迹 |
| 体量 | 多大、多长、多高 | 龙首半人高、龙身拖三米 | 天马身高约本体 1.3 倍，翼展略宽于肩 |
| 起点 | 从哪里出现 | 掌前腾起 | 背后偏上，前缘压到肩线之前 |
| 轨迹 | 怎么走 | 龙首直冲对手胸口，龙身在后收卷 | 拳路斜下平行推进，尾迹随后拖出 |
| 命中 | 触到对方时什么姿态 | 龙首炸成金屑，与掌印灼痕重合 | 每击一点白心蓝边冲击点，火花沿前臂连成线 |
| 消散 | 打完剩什么 | 龙身向内塌缩，金屑落地 | 尾迹熄成光点向上飘散 |

### 四步拆法

1. **先拆身体**：这招是谁、用什么部位、打哪里、对方怎么受。身体层不清楚，特效只会盖住一团糊。
2. **查原作的表现符号**：原作给这招配的是什么视觉符号——龙、剑影、冰柱、锁链、宝轮、光网。没有符号的招（点穴、擒拿、快剑），符号换成空气裂线、尘环、布屑，仍然是物件。
3. **补体量与轨迹**：给主体一个尺寸，给运动一个方向。缺这两项，模型只会画一团光停在原地。
4. **定命中与消散**：落点给两到三项反馈（灼痕、结霜、位移、碎石），收尾给一项残留。这一步决定这一击有没有重量。

### 迁移到别的体系

- **神话神系**（圣斗士、希腊神话）：主体多为生物型与自然型，允许法相独立成主体，比例 1.2～1.5 倍。
- **东方武侠**：主体克制，以掌印、剑气、刀罡、爪痕为主，不加悬浮光柱；「无光」的招换成风压锥、尘环、空气裂线。
- **修真仙侠**：主体形态可变（剑意、符箓、灵兽），但**一招仍只用一个主体**，变形不等于换主体。
- **异能超能**：主体要体现机制（能量束、力场、机械臂），光效只是副产物，不能只写发光。

### 体检

改完一批参数表，跑一次体检，把「短到画不出来」「以无开头」「同体系两招共用一句」这三类问题扫出来：

```bash
python3 scripts/audit_vfx.py          # 全部招式
python3 scripts/audit_vfx.py --quiet  # 只看结论
```

## 破坏三栏：命中之后留下什么

特效主体的「触」只写到接触瞬间为止。观众判断这一招有多重，靠的是接触之后的三样东西。每招必须写全，缺一栏就等于没写：

| 栏 | 写什么 | 合格例 | 不合格 |
| --- | --- | --- | --- |
| 人 | 受击者的身体与贴身装备：位移、变形、甲片崩裂、脱手 | 人：胸甲凹陷、人被带离地半米 | 人：被打飞（没写飞多远、哪件甲坏了） |
| 物 | 场景里可破坏的道具：门板、木柱、石栏、兵器 | 物：身后石柱断一截 | 物：无（有石柱在场却写无） |
| 景 | 破坏之后留在地形上的痕迹：裂纹、焦痕、凹坑、堆起的碎屑 | 景：通道撞出凹坑 | 景：轰然巨响（只写声音，画不出） |

三档强度按「人／物／景」各升一级，写之前先定档，别一招就把三档全用满：

| 档 | 人 | 物 | 景 |
| --- | --- | --- | --- |
| 轻（点到即止） | 衣料裂、退半步、气血滞 | 竹栏断一截、木箱凹一处 | 霜痕、脚印、一点血 |
| 中（伤筋动骨） | 甲片崩、脱手、单膝跪地 | 门板断两截、石栏断裂 | 地面裂纹三尺、焦痕一道 |
| 重（场地改写） | 掀飞撞墙、甲胄切开 | 石柱断、宫墙整片崩落 | 地面塌陷、裂成放射状、堆石过膝 |

三条硬规矩：

1. **「无」必须是有理由的无**。空气防御壁、读心术、幻魔拳这类不接触或不留痕的招式可以写「物：无」「景：无」，但人和其余那栏要写实（例：读心术「人：动作被预判、招式落空」）。
2. **人和景不许同义重复**。「人：被打飞」＋「景：尘扬起」不是两栏，是同一件事说了两遍；景要落在不动的物件上。
3. **群招按覆盖面写三点**，不逐人复述。例：巨型号角「人：胸腹被顶凹、倒退撞墙／物：墙撞塌一角／景：砖石堆到膝高」。

## 命中、格挡、擦过、落空：后果只和结果绑定

破坏三栏写的是**完整命中之后**的最大表现，不是每一镜都照抄。分镜里先定这一招的结果，再决定能写哪一档：

| 结果 | 人能写什么 | 物／景能写什么 | 绝不能写 |
| --- | --- | --- | --- |
| 完整命中 | 位移、甲片崩裂、脱手、跪地；只有终结招才写濒死、气绝 | 门板断、石柱裂、地面塌陷 | 与下一镜伤情矛盾的新伤 |
| 格挡（兵器架住、光幕挡住） | 虎口裂、手腕发麻、后退半步；**身体不落伤** | 兵器弯折、盾面凹、光幕裂一道 | 断臂、见骨、吐血、甲胄切开 |
| 擦过 | 衣料裂一道、皮肤浅痕 | 墙面留一道浅槽 | 贯穿、内脏、断肢 |
| 落空 | 无 | 落点自己选的位置：墙凹、地裂、瓦落 | 任何人身伤害 |

三条硬规矩：

1. **重伤与死亡必须挂在命中上**。写「当场死亡」前面必须有「刺中／劈中／贯穿」这类命中依据；只写结果不写命中，模型会拍成凭空倒地。
2. **挡住时禁止写人身伤害**。格挡的能量必须有去处：接触点火花、光幕裂开、兵器弯折、脚下退半步，能量走物件，不走人。
3. **死亡是剧情结果，不是参数**。参数表只登记「命中后的破坏上限」，谁死谁伤在分镜与剧本层决定；表里写死亡会被体检拦下。

## 每镜五层

| 层 | 要写什么 | 缺了会怎样 |
| --- | --- | --- |
| 源 | 光从哪来：掌心、拳峰、背后裂缝、脚下阵纹、兵器刃口、眼睛 | 光凭空出现，像后期贴图 |
| 形 | 光的几何形状：线、锥、环、面、羽状、放射状、网格 | 只有一团亮雾，看不出是哪一招 |
| 动 | 光怎么走：沿直线贯穿、螺旋收束、向外扩散、逐层合拢、绕身盘旋 | 光停在原地，像灯泡 |
| 触 | 落点发生什么：结霜、灼痕、裂纹、气浪外推、护甲形变、碎屑飞散 | 特效和对手没关系，像两层画面 |
| 残 | 打完之后剩什么：余烬上飘、霜痕、积水震荡、灰尘落下、耳鸣 | 特效一帧消失，重量感归零 |

顺序固定：**源 → 形 → 动 → 触 → 残**。这不是文采顺序，是因果顺序；按这个顺序写，模型就不会把光画在错的位置。

## 词库

写的时候从这四组里取词，不要自己造模糊词。

**光源与载体**：掌心光核、拳峰包裹、刃口高光、背后裂缝、脚下阵纹、眼瞳点亮、鳞甲缝隙、锁链节点、竖琴弦光、盾面反光。

**形状**：细线、光带、光柱、锥形、环状、同心环、放射纹、网格、羽状、鳞片状、漩涡、掌印、曼陀罗、裂口。

**运动**：贯穿、推进、收束、盘旋、扩散、合拢、塌缩、拉升、下压、横扫、折返、分层上升。

**接触与残留**：结霜、灼痕、碳化、蛛网裂纹、碎石外推、气浪、冲击环、碎屑上飘、余烬熄灭、光点飘落、积水震荡、蒸汽、耳鸣。

英文侧可与 H3 的运镜词并列使用，写在能量句里即可：`volumetric light`、`energy particles`、`shockwave ring`、`glowing cracks`、`embers drifting upward`、`frost spreading`。

## 密度

- 特效描述占该镜文字量的 **40%～60%**，低于 30% 就是普通打斗。
- 每镜特效词 **6～10 个**，超过 12 个会互相抢注意力，模型开始乱画。
- 一段 15 秒里，特效强度的分配是 **3:6:1**：起势三成、爆发六成、余波一成。
- 同一镜里**只允许一种主要光形**；范围场型的「环＋放射」算一种。

## 三档强度

| 档 | 适用 | 特效写法 |
| --- | --- | --- |
| 轻 | 普通对打、试探、连招中段 | 只写源与触：拳峰包裹一层薄光，命中处起一小圈气浪、衣料被推 |
| 中 | 有招名的招式、单招决胜 | 五层写满，但形只一种、残只一项 |
| 重 | 必杀技、法相、终极一击 | 五层写满，允许法相独立成主体、环境残留两项、定格 1～2 帧 |

## 每镜的填空模板

```text
[Shot N] At MM:SS.mmm, <景别>，<运镜>。<本体姿态与发力>；<源>亮起，<形>自<起点>向<方向><动>，<伴随粒子或碎屑>；<落点><触>，<环境反应>；<残>。
```

举例（连打型第 3 镜，轻中档）：

```text
[Shot 3] At 00:04.500, 侧向中近景，镜头跟随右移。一名短发青年右拳收到腰侧后连出三拳，拳峰各裹一层青白色薄光；三道线状光痕沿斜下方贯穿，路径上留下被切开的水雾，水雾里浮着细碎光点；第三拳落在对方抬起的护臂上，护臂表面炸开一圈冲击环，雨水被气浪推成扇形；光痕熄灭后只剩几粒光点向地面坠落。
```

## 常见废写法

| 废写法 | 为什么废 | 改成 |
| --- | --- | --- |
| 华丽的光芒照亮全场 | 无源、无形、无落点 | 掌心光核亮起，一圈环状光向外扩散，照亮墙面砖缝，砖缝里浮尘被推起 |
| 无数光点漫天飞舞 | 数量不可控，模型画成雪花屏 | 三十余点光粒沿螺旋线绕身升起 |
| 红蓝金三色光交织 | 混光，认不出是哪一招 | 主色青蓝，暖点只留在命中瞬间 |
| 强大的能量波动 | 抽象名词，没有形状 | 锥形光柱自拳峰推进，前端顶出冲击环 |
| 烟尘遮住两人 | 遮住接触点，观众看不懂谁打谁 | 碎石外推、气浪横扫，两人轮廓始终可见 |
| 一招打完地裂山崩 | 超出镜内可呈现范围 | 只写脚下三米内的蛛网裂纹与碎石外推 |

## 与法相、配色的配合

- 法相是**独立主体**：它有头、有朝向、先亮眼；法相出手的光形可以比本体大一级，但落点必须与本体落点重合，见 [aura.md](aura.md)。
- 主色定光，辅色定边，暖点只给命中帧：一镜之内不要出现两套主色，见 [palette.md](palette.md)。
- 特效最亮、人物中等、背景最暗，三档拉开；全画面同亮度会读成廉价特效。

## 自查

- 每镜五层齐不齐（源、形、动、触、残）。
- 一镜只有一种主要光形，没有混第三种。
- 接触点始终可见，没有被烟、雾、光斑盖住。
- 特效词在 6～10 个之间，没有堆形容词。
- 收尾有残留物，不是一帧归零。
- 删掉全部特效词后，身体层仍然能看懂谁打了谁；做不到说明动作写虚了。
