# 动作导演：因果、状态与配速

招式参数表解决「这一招长什么样」，这一份解决「两招之间为什么成立」。缺了这层，提示词里每个动作都好看，连起来却像各打各的。

配套：[ultimate/vfx.md](ultimate/vfx.md) 特效主体规范、[../cinematography.md](../cinematography.md) 景别与运镜、[../production/storyboard.md](../production/storyboard.md) 分镜排版。

## 一、每个参战角色先建动作档案

八项，缺一项就会在交手里露出破绽：

| # | 项 | 要写到什么程度 | 例（降龙掌使用者） |
| --- | --- | --- | --- |
| 1 | 优势距离 | 几米内最强 | 一米内贴身，一步外靠掌风 |
| 2 | 起手姿态 | 开打前身体怎么摆 | 左脚前虚点、右掌贴腰 |
| 3 | 移动方式 | 步法特征 | 直线抢中，少侧绕 |
| 4 | 主要攻击方式 | 靠什么打 | 双掌推、肩撞 |
| 5 | 防守与反制习惯 | 挨打后怎么回 | 卸力半步、立即反推 |
| 6 | 资源 | 兵器、弹药、内力 | 内力有限，三掌后要换气 |
| 7 | 力量节奏 | 快慢如何起伏 | 两慢一快，第三掌最重 |
| 8 | 结束战斗的方式 | 靠什么收 | 一掌定身，不追打 |

两个角色至少在**优势距离、移动方式、反制习惯**三项上明显不同；三项都一样，打起来就是自己打自己。远程角色要写视线与弹道，近战角色要写怎么缩短距离，体型差要落在速度与受力上。

## 二、每轮交锋写六项

一次交锋＝一个可读的攻防单元。六项齐全才算「有因果」：

1. 谁发起；
2. 动作指向哪里（部位、方向）；
3. 接触、格挡还是落空；
4. 对方怎么回应；
5. 双方位置怎么变；
6. 什么状态支撑下一拍（距离、失衡、遮挡、资源、场景损伤、暴露的空当）。

反例：两人同时出招、各打各的、镜头一换又都站回原位。这类写法在视频里读不出胜负，观众只觉得乱。

**命中必须给结果**：加速方向、接触点、受力方向、位移终点、环境反馈（水花、尘土、砖裂、雨线断开）。同一次命中的环境变化，要在后面镜头里留着。

## 三、跨镜不重置的四样

切镜之后自动复原，是打戏最常见的崩坏：

| 状态 | 要延续什么 |
| --- | --- |
| 位置 | 上一镜结束时双方在哪、朝向谁 |
| 兵器 | 是否脱手、断口在哪、刃口朝哪 |
| 损伤 | 谁身上哪处有伤、血往哪流、衣服哪块破了 |
| 场景 | 已碎的物件不会复原，已塌的墙不会立回 |

写下一镜开头一句「承接上一镜：他退到墙根、刀在左脚边」，比任何解释都有效。

## 四、配速预算：两个档位，不靠形容词

**强度与速度是两条独立的轴**，不要混成一个「很猛」。强度管动作多大，速度管切多快。

以 15 秒段为单位：

| 档 | 段数 | 每段 | 交锋次数 | 微动作 | 镜头数 |
| --- | --- | --- | --- | --- | --- |
| 标准 | 4 段 | 3～4 秒 | 高强度 6～8／中间 5～7／慢 4～6 | 12～18 | 高强度 6～8／中间 5～7／慢 3～4 |
| 极速 | 5～6 段 | 2～3 秒 | 高强度 7～9／中间 6～8／慢 5～7 | 16～22／12～16／10～14 | 高强度 6～9／中间 5～7／慢 3～4 |

极速档的三条硬规矩：

- 第一个有效动作不晚于 0.15 秒出现（标准档 0.3 秒）；
- 纯走位或纯恢复动作不超过 0.3 秒（标准档 0.7 秒）；
- 极速档默认不用慢动作；决定性命中要看清楚时，全片只留一次，0.15～0.3 秒。

**注意本包的口径**：H3 单镜下限是 2 秒（见 [../wuxi/validation.md](../wuxi/validation.md) P7）。所以极速档不是靠切更碎的镜头，而是靠**段更短、镜内动作更密**。想切 0.5 秒的特写，只能放在多段结构里去拆段，不能压单镜时长。

时长与结构的对应：

| 时长 | 装什么 |
| --- | --- |
| 4～8 秒 | 一个完整动作闭环，最多一次明显转折 |
| 9～18 秒 | 起动、争夺、反制、结果四到五阶段 |
| 19～30 秒 | 五到七段，中段安排一次有效反转 |

## 五、重击与终结技

- 重击必须有**可见起势**：重心下沉、脚步压地、兵器后引、光形收缩，四样里至少两样；
- 终结技多一道流程：触发 → 蓄力 → 锁定目标 → 释放 → 结果，五步都要有画面；
- 普通交手可以快，终结技不能省步骤，省了就变成「莫名其妙赢了」。

## 六、参考素材按职责分工

一份素材只干一件事，别让它同时管身份、场景、动作和镜头：

| 素材 | 只管 |
| --- | --- |
| 角色图 | 外观 |
| 场景图 | 环境 |
| 站位图／首帧 | 第 0 帧谁在哪、朝哪 |
| 轨迹图 | 后续路线 |
| 动作参考视频 | 身体轨迹、力量方式、节奏 |
| 运镜参考视频 | 机位、路径、速度 |

用户最新的一条明确指令永远优先。素材编号属于沟通，**不写进生成正文**（正文留空或只写「见附图」）。

## 七、交付：净稿与面板分开

实测反复出现同一个问题：把编号、时长预估、检查点、自检表混在正文里，拿去生成就会一起被喂进模型。

规矩：

1. 交付文件分两段：**可复制正文**（只有场景、动作、台词、声音）+ **节奏调整面板**（段长、镜数、待改项）；
2. 面板明确标注「不进生成」；
3. 正文里不出现「自检」「检查点」「预估 90.8 秒」「【本集结算】」这类工作痕迹；
4. 校验器 `P29` 会在正文里发现这些词时提示。

## 八、失败修正：一次只改一类

打戏出问题的三类变量：**动作、镜头、素材**。每轮只动一类，改完重新生成再判断。

| 症状 | 先改哪类 |
| --- | --- |
| 看不出谁打谁 | 镜头（换一个能看清接触的角度） |
| 动作软、没力量 | 动作（补起势与受力结果） |
| 人物脸崩、服装乱 | 素材（补角色图或换更近的参考） |
| 特效糊成一片 | 动作（把特效主体改成可画形状，见 vfx.md） |

一次改两类以上，出了问题无法归因。

## 九、自查

- 每个角色八项档案齐了吗？三人以上有没有两项以上同质？
- 每轮交锋六项齐吗？有没有「同时出招、各打各的」？
- 命中写了受力结果吗？环境变化延续到下一镜了吗？
- 切镜后位置、兵器、损伤、场景是否保留？
- 段数、交锋次数、镜头数落在所选档位预算内吗？慢动作是否只留一次？
- 重击有起势吗？终结技五步齐吗？
- 每份素材只担一个职责吗？素材编号是否留在正文外？
- 交付正文里还有工作痕迹吗？
