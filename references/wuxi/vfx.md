# 必杀技与特效：主体、三类型、五要素、破坏三栏

## 特效提示词堆砌

所属分类：武戏 / 必杀技。上位说明见 index.md，配色见 palette.md，法相见 aura.md。

## 为什么单写打斗出不来特效

模型的默认行为是「拍两个人打架」：它给你真实的拳脚、真实的碰撞，但不会自己加光。写了「华丽的一击」，它只会把镜头摇得更花。特效必须被写成**画面里真实存在的东西**——有发光体、有形状、有运动方向、有落点、有残留物。写成一个物体，模型才画得出来；写成一个形容词，模型只会给你更亮的皮肤。

所以特效不是修辞，是**物件清单**。每一镜都要把下面五层填满，缺一层就掉一档。

## 特效主体：每招必须有一个「主角物件」

特效师接到一招，第一句话问的不是「多亮」，而是「飞出去的是什么」。降龙十八掌的亢龙有悔，答案是一条金龙：龙首先到、龙身随掌势拖出、掌收龙散。这一句定下来，镜头、光比、粒子、命中全都有依据；定不下来，拍出来就是两个人在推手。

所以每一招在参数表里必须先有**特效主体**，再谈五层。

### 三种主体类型

| 类型 | 长什么样 | 适合的招式 |
| --- | --- | --- |
| 生物型 | 有头、有躯干、有朝向的活物虚影：龙、凤、狮首、天马、蝎尾、蛇、魔女 | 召唤法相型、连打型的显形段 |
| 器物型 | 放大的真实物件：剑影、锁链、宝轮、竖琴弦、盾面、玫瑰、针、伞 | 束缚领域型、单体突进型 |
| 自然型 | 自然现象的放大：冰柱、极光、星屑漩涡、日蚀、雷柱、火墙 | 范围场型、神级招式 |

### 一句话公式

```text
<主体是什么、多大、什么材质或颜色> + <从哪出现> + <沿什么轨迹怎么动> + <命中时什么姿态> + <怎么消散>
```

举例：

- 亢龙有悔：一条金色龙形自掌前腾起，龙首昂起半人高，龙身随掌势拖出三米；龙首直冲对手胸口，龙身在后收卷；命中后龙首炸成金屑，龙身向内塌缩。
- 天马流星拳：数十条青蓝流星尾迹从双拳拖出，每条尾迹末端是一点白心光核；拳路斜下平行推进；每击落点炸开一圈小冲击环；尾迹熄灭成光点坠落。
- 天舞宝轮：一圈金色曼陀罗自脚下展开，环径四米，环间浮着佛像轮廓；逐层向内合拢；目标被困在轮心；宝轮碎成花瓣状光片飘落。

### 反例（这些写法等于没有特效主体）

| 写法 | 问题 |
| --- | --- |
| 只有手刀边光 | 没有物件，模型只会给手加个亮边 |
| 无外光，全靠重量与风压 | 观众看不见任何东西，等于普通挥剑 |
| 一团强大的能量 | 形状不可画，模型给出一团糊光 |
| 无形指力 | 无形就没有画面，必须给空气裂线、水汽痕这类可见痕迹 |
| 无数光点 | 数量不可控，最后变成雪花屏 |

**不发光也要有可见主体**：武侠里「无光」的招式，主体换成空气被压出的锥形、尘环、水汽裂线、衣料被撕开的方向，仍然是物件，只是材质是空气与尘。

## 照着范例学：六要素反推法

包里的两份现成范例已经把标准写全了，不需要另立一套：`cases/xianglong.md` 的逐招特效表（十八招各有一套龙形）和 `cases/pegasus-meteor.md` 的分镜表（天马流星拳五镜）。把它们拆开看，每一招都只回答了六个问题——照这六个问题去拆任何原作、任何招式，就能写出来。

| 要素 | 要回答的问题 | 亢龙有悔的答案 | 天马流星拳的答案 |
| --- | --- | --- | --- |
| 主体 | 飞出去的是什么 | 一条金色龙形 | 带翼天马虚影＋数十条流星尾迹 |
| 体量 | 多大、多长、多高 | 龙首半人高、龙身拖三米 | 天马身高约本体 1.3 倍，翼展略宽于肩 |
| 起点 | 从哪里出现 | 掌前腾起 | 背后偏上，前缘压到肩线之前 |
| 轨迹 | 怎么走 | 龙首直冲对手胸口，龙身在后收卷 | 拳路斜下平行推进，尾迹随后拖出 |
| 命中 | 触到对方时什么姿态 | 龙首炸成金屑，与掌印灼痕重合 | 每击一点白心蓝边冲击点，火花沿前臂连成线 |
| 消散 | 打完剩什么 | 龙身向内塌缩，金屑落地 | 尾迹熄成光点向上飘散 |

### 四步拆法

1. **先拆身体**：这招是谁、用什么部位、打哪里、对方怎么受。身体层不清楚，特效只会盖住一团糊。
2. **查原作的表现符号**：原作给这招配的是什么视觉符号——龙、剑影、冰柱、锁链、宝轮、光网。没有符号的招（点穴、擒拿、快剑），符号换成空气裂线、尘环、布屑，仍然是物件。
3. **补体量与轨迹**：给主体一个尺寸，给运动一个方向。缺这两项，模型只会画一团光停在原地。
4. **定命中与消散**：落点给两到三项反馈（灼痕、结霜、位移、碎石），收尾给一项残留。这一步决定这一击有没有重量。

### 迁移到别的体系

- **神话神系**（圣斗士、希腊神话）：主体多为生物型与自然型，允许法相独立成主体，比例 1.2～1.5 倍。
- **东方武侠**：主体克制，以掌印、剑气、刀罡、爪痕为主，不加悬浮光柱；「无光」的招换成风压锥、尘环、空气裂线。
- **修真仙侠**：主体形态可变（剑意、符箓、灵兽），但**一招仍只用一个主体**，变形不等于换主体。
- **异能超能**：主体要体现机制（能量束、力场、机械臂），光效只是副产物，不能只写发光。

### 体检

改完一批参数表，跑一次体检，把「短到画不出来」「以无开头」「同体系两招共用一句」这三类问题扫出来：

```bash
python3 scripts/audit_vfx.py          # 全部招式
python3 scripts/audit_vfx.py --quiet  # 只看结论
```

## 破坏三栏：命中之后留下什么

特效主体的「触」只写到接触瞬间为止。观众判断这一招有多重，靠的是接触之后的三样东西。每招必须写全，缺一栏就等于没写：

| 栏 | 写什么 | 合格例 | 不合格 |
| 人 | 受击者的身体与贴身装备：位移、变形、甲片崩裂、脱手 | 人：胸甲凹陷、人被带离地半米 | 人：被打飞（没写飞多远、哪件甲坏了） |
| 物 | 场景里可破坏的道具：门板、木柱、石栏、兵器 | 物：身后石柱断一截 | 物：无（有石柱在场却写无） |
| 景 | 破坏之后留在地形上的痕迹：裂纹、焦痕、凹坑、堆起的碎屑 | 景：通道撞出凹坑 | 景：轰然巨响（只写声音，画不出） |

三档强度按「人／物／景」各升一级，写之前先定档，别一招就把三档全用满：

| 档 | 人 | 物 | 景 |
| 轻（点到即止） | 衣料裂、退半步、气血滞 | 竹栏断一截、木箱凹一处 | 霜痕、脚印、一点血 |
| 中（伤筋动骨） | 甲片崩、脱手、单膝跪地 | 门板断两截、石栏断裂 | 地面裂纹三尺、焦痕一道 |
| 重（场地改写） | 掀飞撞墙、甲胄切开 | 石柱断、宫墙整片崩落 | 地面塌陷、裂成放射状、堆石过膝 |

三条硬规矩：

1. **「无」必须是有理由的无**。空气防御壁、读心术、幻魔拳这类不接触或不留痕的招式可以写「物：无」「景：无」，但人和其余那栏要写实（例：读心术「人：动作被预判、招式落空」）。
2. **人和景不许同义重复**。「人：被打飞」＋「景：尘扬起」不是两栏，是同一件事说了两遍；景要落在不动的物件上。
3. **群招按覆盖面写三点**，不逐人复述。例：巨型号角「人：胸腹被顶凹、倒退撞墙／物：墙撞塌一角／景：砖石堆到膝高」。

## 命中、格挡、擦过、落空：后果只和结果绑定

破坏三栏写的是**完整命中之后**的最大表现，不是每一镜都照抄。分镜里先定这一招的结果，再决定能写哪一档：

| 结果 | 人能写什么 | 物／景能写什么 | 绝不能写 |
| 完整命中 | 位移、甲片崩裂、脱手、跪地；只有终结招才写濒死、气绝 | 门板断、石柱裂、地面塌陷 | 与下一镜伤情矛盾的新伤 |
| 格挡（兵器架住、光幕挡住） | 虎口裂、手腕发麻、后退半步；**身体不落伤** | 兵器弯折、盾面凹、光幕裂一道 | 断臂、见骨、吐血、甲胄切开 |
| 擦过 | 衣料裂一道、皮肤浅痕 | 墙面留一道浅槽 | 贯穿、内脏、断肢 |
| 落空 | 无 | 落点自己选的位置：墙凹、地裂、瓦落 | 任何人身伤害 |

三条硬规矩：

1. **重伤与死亡必须挂在命中上**。写「当场死亡」前面必须有「刺中／劈中／贯穿」这类命中依据；只写结果不写命中，模型会拍成凭空倒地。
2. **挡住时禁止写人身伤害**。格挡的能量必须有去处：接触点火花、光幕裂开、兵器弯折、脚下退半步，能量走物件，不走人。
3. **死亡是剧情结果，不是参数**。参数表只登记「命中后的破坏上限」，谁死谁伤在分镜与剧本层决定；表里写死亡会被体检拦下。

## 每镜五层

| 层 | 要写什么 | 缺了会怎样 |
| 源 | 光从哪来：掌心、拳峰、背后裂缝、脚下阵纹、兵器刃口、眼睛 | 光凭空出现，像后期贴图 |
| 形 | 光的几何形状：线、锥、环、面、羽状、放射状、网格 | 只有一团亮雾，看不出是哪一招 |
| 动 | 光怎么走：沿直线贯穿、螺旋收束、向外扩散、逐层合拢、绕身盘旋 | 光停在原地，像灯泡 |
| 触 | 落点发生什么：结霜、灼痕、裂纹、气浪外推、护甲形变、碎屑飞散 | 特效和对手没关系，像两层画面 |
| 残 | 打完之后剩什么：余烬上飘、霜痕、积水震荡、灰尘落下、耳鸣 | 特效一帧消失，重量感归零 |

顺序固定：**源 → 形 → 动 → 触 → 残**。这不是文采顺序，是因果顺序；按这个顺序写，模型就不会把光画在错的位置。

## 词库

写的时候从这四组里取词，不要自己造模糊词。

**光源与载体**：掌心光核、拳峰包裹、刃口高光、背后裂缝、脚下阵纹、眼瞳点亮、鳞甲缝隙、锁链节点、竖琴弦光、盾面反光。

**形状**：细线、光带、光柱、锥形、环状、同心环、放射纹、网格、羽状、鳞片状、漩涡、掌印、曼陀罗、裂口。

**运动**：贯穿、推进、收束、盘旋、扩散、合拢、塌缩、拉升、下压、横扫、折返、分层上升。

**接触与残留**：结霜、灼痕、碳化、蛛网裂纹、碎石外推、气浪、冲击环、碎屑上飘、余烬熄灭、光点飘落、积水震荡、蒸汽、耳鸣。

英文侧可与 H3 的运镜词并列使用，写在能量句里即可：`volumetric light`、`energy particles`、`shockwave ring`、`glowing cracks`、`embers drifting upward`、`frost spreading`。

## 密度

- 特效描述占该镜文字量的 **40%～60%**，低于 30% 就是普通打斗。
- 每镜特效词 **6～10 个**，超过 12 个会互相抢注意力，模型开始乱画。
- 一段 15 秒里，特效强度的分配是 **3:6:1**：起势三成、爆发六成、余波一成。
- 同一镜里**只允许一种主要光形**；范围场型的「环＋放射」算一种。

## 三档强度

| 档 | 适用 | 特效写法 |
| 轻 | 普通对打、试探、连招中段 | 只写源与触：拳峰包裹一层薄光，命中处起一小圈气浪、衣料被推 |
| 中 | 有招名的招式、单招决胜 | 五层写满，但形只一种、残只一项 |
| 重 | 必杀技、法相、终极一击 | 五层写满，允许法相独立成主体、环境残留两项、定格 1～2 帧 |

## 每镜的填空模板

```text
[Shot N] At MM:SS.mmm, <景别>，<运镜>。<本体姿态与发力>；<源>亮起，<形>自<起点>向<方向><动>，<伴随粒子或碎屑>；<落点><触>，<环境反应>；<残>。
```

举例（连打型第 3 镜，轻中档）：

```text
[Shot 3] At 00:04.500, 侧向中近景，镜头跟随右移。一名短发青年右拳收到腰侧后连出三拳，拳峰各裹一层青白色薄光；三道线状光痕沿斜下方贯穿，路径上留下被切开的水雾，水雾里浮着细碎光点；第三拳落在对方抬起的护臂上，护臂表面炸开一圈冲击环，雨水被气浪推成扇形；光痕熄灭后只剩几粒光点向地面坠落。
```

## 常见废写法

| 废写法 | 为什么废 | 改成 |
| 华丽的光芒照亮全场 | 无源、无形、无落点 | 掌心光核亮起，一圈环状光向外扩散，照亮墙面砖缝，砖缝里浮尘被推起 |
| 无数光点漫天飞舞 | 数量不可控，模型画成雪花屏 | 三十余点光粒沿螺旋线绕身升起 |
| 红蓝金三色光交织 | 混光，认不出是哪一招 | 主色青蓝，暖点只留在命中瞬间 |
| 强大的能量波动 | 抽象名词，没有形状 | 锥形光柱自拳峰推进，前端顶出冲击环 |
| 烟尘遮住两人 | 遮住接触点，观众看不懂谁打谁 | 碎石外推、气浪横扫，两人轮廓始终可见 |
| 一招打完地裂山崩 | 超出镜内可呈现范围 | 只写脚下三米内的蛛网裂纹与碎石外推 |

## 与法相、配色的配合

- 法相是**独立主体**：它有头、有朝向、先亮眼；法相出手的光形可以比本体大一级，但落点必须与本体落点重合，见 aura.md。
- 主色定光，辅色定边，暖点只给命中帧：一镜之内不要出现两套主色，见 palette.md。
- 特效最亮、人物中等、背景最暗，三档拉开；全画面同亮度会读成廉价特效。

## 自查

- 每镜五层齐不齐（源、形、动、触、残）。
- 一镜只有一种主要光形，没有混第三种。
- 接触点始终可见，没有被烟、雾、光斑盖住。
- 特效词在 6～10 个之间，没有堆形容词。
- 收尾有残留物，不是一帧归零。
- 删掉全部特效词后，身体层仍然能看懂谁打了谁；做不到说明动作写虚了。

### 必杀技（大招）

必杀技不是「更华丽的普通招式」，是另一套结构：能量层要当主角、一场只打一次、并且必须能被模型生成出来。

### 与普通招式的四条差别

1. **有名字，有喊招**。名字是台词，按口播预算算秒数，不当作音效处理；喊完才动手。
2. **有能量层**。法相、场域、光形三者至少出现一项，并走完显形、跟手、消散。
3. **只打一次**。同一场戏最多一次。要出现第二次，必须换条件：受伤、被封、被打断、半血爆发、换形态，并且要交代条件变化，不能原地重放。
4. **承诺要兑现**。说了打哪里、打成什么样，画面必须给同一处接触点和同一类结果；不靠光效强度暗示胜负。

### 五种范式

先判范式，再分镜。范式判错，后面全错。

| 范式 | 画面特征 | 能量层的作用 | 最小时长 | 建议镜数 | 最常见的失败 |
| --- | --- | --- | --- | --- | --- |
| 连打型 | 多接触点打同一目标，节奏越来越快 | 法相在背后同步挥拳，最后拉成光轨 | 10 秒 | 4～6 | 糊成一片白光，看不出打了几拳、打在哪 |
| 单体突进型 | 一条线打穿，一次接触定局 | 法相收成一道贯穿的形，或聚成一个点 | 6 秒 | 3～4 | 只有起手和结果，中间过程被省略 |
| 范围场型 | 从中心向四周扩散，多目标或环境受击 | 场域几何：环、纹、阵、雾墙 | 10 秒 | 4～6 | 只有特效铺满，没有主体受击反应 |
| 束缚领域型 | 不靠打击，靠规则剥夺 | 阵图、光球、链光包覆 | 12 秒 | 4～6 | 写成打斗，靠拳头解决 |
| 召唤法相型 | 法相实体化，自己冲出去打 | 法相是独立主体，有自己的动作与落点 | 8 秒 | 3～5 | 法相与本体动作脱钩，变成背景画 |

判范式看两件事：一是有几个接触点（多个同目标＝连打；一个＝单体突进；多个不同目标＝范围场；零个＝束缚或召唤），二是胜负由什么决定（打击、规则、法相本体）。

### 四段结构与时间分配

以 12 秒为例：起势 20%（2.4 秒）、宣言 15%（1.8 秒）、爆发 45%（5.4 秒）、收束 20%（2.4 秒）。

- **起势**：承接上一镜的结束姿态直接进入，重心下沉、拳或兵器收到发力位、能量从脚底或拳心起亮。写「地面开始出现细微裂纹」「拳套边缘亮起一线冷光」，不写「蓄势待发」。
- **宣言**：喊招那 3～8 个字，按每秒 4.1～4.5 个可发声字估算；同一镜同时给法相显形到六成。
- **爆发**：按 finisher.md 的三段表示法推进，能量层与本体动作严格同步。
- **收束**：命中瞬间定 1～2 帧，法相向内塌陷，余波至少一项，最后一帧停在命中、失衡或爆点最大处。

四段各段最短秒数：起势 1.5、宣言 1.2、爆发 3.0、收束 1.2。加起来撑不到 6 秒的，不是必杀技，是普通招式加了点光。

**四段是时间预算，不是镜头数量**。每镜仍受 2～5 秒硬约束，所以段长不足 2 秒时必须与相邻段同镜，不准为了凑四镜切出 1.2 秒的碎镜：

- 起势 + 宣言同镜（最常见）：喊招时人还在下沉，两声一口气完成，一镜 2.7～3.2 秒
- 爆发超过 5 秒时拆两镜，接触点分别落在两镜里，不被切碎
- 收束不足 2 秒时并入爆发的最后一镜，把「余波」与「定格」放在同一镜尾
- 拆分后镜数落在范式建议区间即可；单体突进型 ≥6 秒通常就是 3～4 镜，不必凑满四镜

时长装不下按 ../flow.md 的时长预算处理：先报冲突，给「减招式、拆两段、延长时长」三个选项，不硬塞。

### 三层因果

三层的每一层都要自己成立，不能互相顶替。

- **身体层**：谁、从哪个姿态、用什么部位、打在哪、对方怎么受的。把特效全部删掉，这一层还得能看懂谁打了谁——看不懂就是废片。
- **能量层**：法相、光形、粒子。它只能放大身体层，不能代替身体层；法相出手的落点必须等于本体的落点。
- **环境层**：地面裂、气浪、碎石浮起、光照被压暗或染成主色。至少给一处，它负责交代「这一招有多大」，不给就缺尺度。

三层的顺序是身体层带能量层、能量层带环境层，倒过来写会得到「先炸一片光，人还没动」的片子。

### 从原作提取特效，不搬原作画面

把原作镜头拆成三块板来读，只取参数，不取画面：

- **色彩板**：主色（识别色）、辅色（暗部与阴影）、高光（近白）、暖点（只有命中火花允许用的暖色）。一招只准一个暖点色。写法见 palette.md。
- **光形板**：线状（流星、光速、剑光）、点状（针、碎星）、面状（冰雾、火墙、光幕）、羽状（凤翼、鬃毛）、环状（冰晶环、宝轮、星云漩涡）。一个招式只用一种主要光形，混两种就认不出；范围场范式的标准光形就是环状或放射，不算混用。同一体系里的多招不能共用一套光效——每个招式必须有自己的一组可见元素（龙形怎么动、光印什么形状、粒子怎么散、环境怎么反应），否则观众分不出这是第几招。
- **速度板**：残影个数（3～5 个）、光带长度（跨 1/3 画面读作「快」、跨满屏读作「极快」）、爆点直径（拳头的 3 倍读作「重」）、拖尾衰减（1 帧内消失＝高速，留 3 帧以上＝滞重）。

读了这三块板，就能用文字把原著特效描述出来，不需要任何截图。直接喂原作截图当参考图会同时踩版权和生成质量两个坑：模型会去抠像素而不是理解动作，出来的是贴图不是动画。

### 使用边界

- 一场戏最多一次必杀技；连续两次会让第二次贬值，观众（和模型）都当普通招式处理。
- 必杀技不与普通攻防挤在同一镜：爆发前垫一个普通起手，爆发后接一段普通追击，节奏才有起落。
- 同节奏连续不超过 5 秒，按 ../flow.md 的「没有静止表演」执行：蓄力挂在下沉、绕步、上升上，不单独成段。
- 有角色出镜的镜不用远景；法相可以压满背后空间，但本体不得被压缩成小点。

### 同人与版权边界

创作基于已有作品的招式时，按下面四条执行，不越界：

1. 角色、招式名、世界观设定的版权属原作者与版权方。本模块只产出文字提示词，不复制任何原作画面、截图、台词录音或设定图。
2. 参考图必须自建：自绘设定图，或用生成工具出的图；不得把原作截图、动画截帧喂给模型当参考。
3. 公开发布标「同人作品，非官方」，不冒用官方名号、不做官方风格包装。
4. 不商用：不用于付费内容、带货、广告投放或任何形式的售卖。

原创角色用同一套结构，把招式名、主色、法相形态换成自己设定即可，其余参数照抄。

### 交付前检查

- 范式判断写出来了，四段时长加起来对得上总时长。
- 身体层删掉特效后仍能看懂；法相落点与本体落点一致。
- 每招先有「特效主体」——飞出去的是龙、是剑影、是冰柱还是锁链，一句话说得清；写不出主体就回 [vfx.md](vfx.md) 补，不要靠「强大的光芒」糊过去。
- 一招只有一个主色、一种主要光形、一个暖点色；同一体系的多招各有独立特效，没有共用一套光效。
- 起手与封堵阶段的招是否克制住了暖点，暖色留给了真正打实的那一掌。
- 喊招字数按 4.1～4.5 字/秒能放进对应秒数。
- 命中反馈至少两项；收尾停在最高点，法相已消散。
- 没有写「无数拳」「漫天拳影」这类不可生成的概括。
- 同人四条边界逐条对过，没有拿原作截图当参考。
- 一套多招武学：是否只用了 3～5 招、三层预算对得上、相邻两招没有复位动作，按 forms.md 的体系级检查过一遍。

### 法相与幻影层

法相是可生成、可同步、会消失的半透明巨像。它最容易做坏：生成出来像贴纸、像投影幕布、像一团半透明的鬼影。下面四条铁律和六要素就是用来防这三种坏法的。

### 三层结构

法相不是一个图层，它由三层叠出来：

1. **边光**：本体轮廓外 2～6 像素的发光带，主色，随呼吸强弱。法相还没显形时，先出现这一层。
2. **体量**：法相本体，半透明 40%～70%，内部有流纹（鬃毛、羽、鳞、星纹、甲片线），不是一块纯色剪影。
3. **碎屑**：从法相边缘剥离的细碎光点，沿运动的反方向拖出短尾。没有这一层，法相会读成纸片。

### 六要素

写清这六项，法相才可生成：

| 要素 | 写法 | 不写会怎样 |
| 形态 | 一个具体生物或器物：天马、龙、凤、冰晶环、曼陀罗、星系漩涡 | 只写「巨大的幻影」，模型给一团抽象云 |
| 比例 | 本体身高的 1.2～1.5 倍；占画面宽度不超过 1.5 倍 | 太小读成光晕，太大挤掉本体 |
| 位置 | 本体背后偏上、或从脚下向上升起、或环绕本体 | 位置不写，法相会飘在画面正中挡人 |
| 透明度 | 40%～70%，越靠边缘越透明 | 全实心＝第二个人；太透明＝看不见 |
| 色彩分配 | 内部主色、边缘高光、焦点处一个暖点，见 palette.md | 全白高光会把细部吃光，出来是一片白 |
| 同步相位 | 落后本体 0～0.2 秒 | 法相抢在前面，读成「法相在打、人没动」 |

### 四条同步铁律

1. **落点一致**：法相的拳、爪、牙、尾落点，必须与本体的接触点在同一构图位置上，误差不超过半个拳头。这是「贴纸感」的头号成因——本体打在中景，法相打在角落。
2. **相位滞后 0～0.2 秒**：法相略晚于本体，读作力量跟随；提前读作幻影自己动。逐镜写清「本体的拳先到，幻影的拳 0.1 秒后压到同一落点」。
3. **不遮脸、不遮接触点**：法相可以压满背后空间，但面部和拳锋接触处必须让出来。观众看不到谁在打，这一镜就废了。
4. **比例锁死在 1.2～1.5 倍**：跨镜不能变。第 3 镜 1.3 倍、第 5 镜 2 倍，会读成「又叫了一只更大的」。

### 显形三步

`光斑 → 轮廓 → 实体`

- **光斑**（0.3～0.5 秒）：脚底、拳心、胸口三处之一开始发亮，地面或空气里出现同色微粒。
- **轮廓**（0.3～0.6 秒）：边光先勾出整只法相的剪影，此时只有轮廓，内部还是空的。
- **实体**（0.4～0.8 秒）：内部流纹填满，碎屑开始外溢，法相进入可动作状态。

三步压缩到 0.8 秒以内就是「瞬间显现」，超过 2 秒会拖节奏。喊招的时候正好走到第二步。

### 消散三步

`停供能 → 向内塌 → 碎屑散`

- **停供能**：本体动作收住，法相不再跟随，边缘先失焦。
- **向内塌**：体量收缩成一个点或一条线（0.5～1 秒），不在原地淡出。
- **碎屑散**：剥离的粒子向上飘或落地熄灭，1～2 秒内完全消失。

命中后 1～2 秒内必须散干净。法相留到下一镜还在墙上挂着，是最常见的成品问题。

### 法相提示词模板

中文：

```text
<本体>背后偏上的空间里浮现 <形态> 的半透明幻影，约本体身高的 1.3 倍，边缘是一圈 <主色> 的冷光轮廓，体内有 <流纹> 缓慢流动；幻影随本体出拳向前压出，拳锋停在本体拳头正前方的同一落点，比本体晚约 0.1 秒；幻影胸腹处保持通透，不遮挡本体面部与拳锋接触点；幻影下缘持续剥落 <主色> 的细碎光点，沿出拳反方向拖出短尾。
```

英文：

```text
A translucent phantom <form> rises in the air behind and above <subject>, about 1.3× their height, rimmed with cold <color> light, with <internal pattern> drifting inside its body; it drives forward with the subject's punch and stops at the same contact point about 0.1 s later; its torso stays clear so the subject's face and fist contact remain visible; fine <color> particles peel from its lower edge and trail against the punch direction.
```

### 三种坏法的诊断

| 症状 | 成因 | 改法 |
| 贴纸感 | 落点不一致、无碎屑、透明度偏高 | 把落点写成本体同一接触点；加碎屑与拖尾；透明度降到 50% 上下 |
| 投影幕布感 | 法相是平面剪影，没有前后关系 | 写「从背后空间立体升起」「前缘压到本体肩线之前，后缘落在景深深处」 |
| 白雾一片 | 高光面积过大、缺辅色与内部流纹 | 降低高光覆盖率，补辅色阴影，写清内部流纹的具体形状 |

### 三种做法不要用

- 不要让法相自己演戏：说话、表情、独立格斗动作只有「召唤法相型」范式才可以，其余范式里法相只是本体的放大器。
- 不要给法相加第二套配色。法相用本体的主色，只允许边缘高光更亮。
- 不要让法相在画面里静止挂着当背景。它必须在本体动作的同一时间轴上动作，或者正在显形、正在消散。

### 必杀技配色

必杀技的识别度靠颜色，不靠光效大小。同一个角色换招式可以换光形、换节奏，主色不动。

### 四个色槽

| 槽位 | 用途 | 面积 | 说明 |
| 主色 | 识别色，法相、能量、边光 | 30%～40% | 一个角色一个主色，跨招不变 |
| 辅色 | 暗部、阴影、法相内部 | 20%～30% | 主色压深 2～3 阶，不是黑色 |
| 高光 | 边光最亮处、拳锋、爆点核心 | ≤10% | 近白但带主色倾向，不用纯白 |
| 暖点 | 只有命中火花、爆点核心允许用暖色 | ≤5% | 一招只准一个暖点色 |

面积加起来不超过 85%，剩下的留给环境。全画面都亮，等于没有亮。

### 一技一主色

- 同一角色的所有招式共用主色；不同招式换的是光形、节奏和暖点，不换主色。
- 不同角色的主色必须能在一张截图上分辨；两个角色都发蓝光，观众就分不清谁在出手。
- 主色只在能量层用，不染到皮肤和服装上。把人物整体染蓝，会让人读成「滤镜」而不是「能量」。

参考分配（可按自己的设定改，同一世界观内保持一致即可）：

| 角色 | 主色 | 辅色 | 暖点 |
| 天马 | 青蓝 `#4FC3F7` | 深蓝 `#1A4C8B` | 金 `#F5C542` |
| 龙 | 翠绿 `#2ECC71` | 墨绿 `#14603A` | 金 `#F5C542` |
| 白鸟 | 冰蓝 `#BFE9FF` | 灰蓝 `#5A7C99` | 白 |
| 仙女 | 粉紫 `#C08CE8` | 深紫 `#5B3A8E` | 暖粉 `#F3A6C8` |
| 凤凰 | 赤红 `#E5482E` | 暗红 `#7A1E14` | 金 `#F5C542` |
| 黄金系 | 金 `#E8C45A`（共色，靠光形区分） | 褐金 `#8A6A24` | 白 |

黄金系是特例：主色相同，就只能靠光形和法相形态区分——环状、点状、线状、羽状各归各家，不能都写成「金色光柱」。

### 亮度阶梯

环境 30%、角色 60%、特效 100%。三档要拉开：特效最亮、人物中等、背景最暗。

- 高光覆盖率不超过画面 30%；超过就是过曝，细节全丢。
- 全屏白闪不超过 2 帧，且只用在命中那一刻，不用在起手。
- 爆点核心允许 100% 亮度，但它周围的过渡带要迅速降到主色，不能整片死白。

### 冷暖对立

- 主角冷色、对手暖色（或按阵营反着来），一场戏定死，中途不换。
- 同画面最多两组色系。出现第三组（比如紫、绿、橙一起上），读成杂色，观众记不住谁是谁。
- 两个同色系角色对打时，用亮度差和饱和度差分开：一方亮而饱和，一方暗而灰。

### 不要用的六种配法

1. 彩虹多色——超过两组色系就是杂。
2. 纯饱和 RGB 撞色（纯红配纯绿、纯蓝配纯黄），读成廉价特效。
3. 紫绿大面积并用，视觉上会互相咬，边缘发脏。
4. 所有能量都纯白，丢掉角色识别。
5. 用整屏单色滤镜当「气氛」，把动作细节一起盖掉。
6. 给法相另配一套色——法相只用本体主色，只允许边缘更亮。

### 提示词怎么写颜色

四句写完，不堆色名：

```text
能量与法相统一为 <主色> 的冷调，暗部过渡到 <辅色>，边缘与拳锋处提亮为近白的 <高光>，只有命中爆点中心出现一小片 <暖点> 的暖色火花；环境整体压暗，墙面与地面被主色轻微染色，其余物体保持原有颜色。
```

写颜色时避免「五彩斑斓」「绚丽」这类形容词，只写槽位和面积，模型才落得下去。

### 检查

- 一招是否只有一个主色、一个暖点色，光形是否只有一种主要形态。
- 不同角色的主色在一张截图上能否分辨。
- 高光面积是否压住了细节；有没有出现整片死白。
- 同画面是否超过两组色系；冷暖关系是否全程一致。

### 招式体系与连段编排

单招级只回答「这一下怎么打」。一套十几招、几十招的武学，要回答的是另一个问题：这套功夫怎么用。核心结论先写在这里——**一次交手最多用三到五招**，其余不是没学会，是没有机会用。

十八招全上是什么效果：12 秒里塞 18 掌，平均每掌 0.67 秒，比起势还短。法相来不及显形，光效互相顶，观众看到的是一团金色残影，谁也记不住哪一掌是亢龙有悔。

### 体系级要定的四件事

1. **招式谱**：每招的名字、意象、范式、掌形或法相、递进层、最小秒数、能否连段。
2. **能量预算**：这一场一共能出几层力量，不是能出几招。
3. **选招**：这一场挑哪三到五招，为什么是这几招。
4. **连段编排**：上一招怎么接下一招，姿态、方向、重心都不能复位。

### 招式谱的写法

一张表就够了，七个字段缺一不可（表里另加一列序号）：

| 序号 | 招式 | 意象 | 范式 | 掌形或法相 | 递进层 | 最小秒 | 可否连段 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 某掌 | 一句话说清这一掌的画面 | 连打／突进／范围／束缚／召唤 | 手上做什么、法相是什么 | 起手／压上／收束 | 6～12 | 是／否 |

「意象」这一列最容易糊弄。写成「气势磅礴的一掌」等于没写；要写成「一掌推出后掌势在最后一寸收住，地面被推出一道浅槽」，模型才知道拍什么。

### 能量预算

按层分，不按招数分。一场 12～15 秒的交手：

| 层 | 用几招 | 能量表现 | 每招时长 |
| 起手层 | 1～2 招 | 只有掌力前缘与光影，法相不出或只出轮廓 | 2～2.5 秒 |
| 压上层 | 1～2 招 | 法相成形，比例 1.2 倍，第一处环境破坏 | 2～2.5 秒 |
| 收束层 | 1 招 | 法相 1.4～1.5 倍，主色占画面最满，命中定帧 | 2.4～3 秒 |

三层加起来正好 5 招、约 12 秒。想要更多招，加时长；在同一个时长里加招，就是把每招的画面摊薄。

超出 5 招会出两种坏结果：法相比例和亮度被反复抬满，后招不比前招重，力量感反而掉；观众的注意力被切碎，记住的是「打了很多下」，不是「哪一下最重」。

### 选招三问

每一招入选前问三句，有一句不成立就换招：

1. **这一招解决什么问题**：试探、脱离纠缠、突袭、压制、终结。功能重复的两招只留一招。
2. **能量够不够**：预算还剩哪一层。压上层的招不能放在开场，收束层的招不能连用两次。
3. **接不接得上**：它的起手能否直接从上一招的结束姿态进入。

### 承接铁律：不复位

上一招的结束姿态，就是下一招的起手。中间不「回中站好」、不「重新蓄力」、不「收招归位」。

- 一掌推尽，重心已在前脚，下一招必须顺着前倾方向走：下压、冲撞、追击。
- 一掌被架开，手臂已经偏向外侧，下一招就从外侧绕进来，不能先收回胸前。
- 一次跃起落下，落地膝已弯，下一招从低位起：扫、撞、反手。

这条铁律的意义：真人连招没有「复位」这个动作，写进分镜就会变成每招之间插一段「他又站好了」，节奏全断。素材库里那些「打完一套摆个造型」「然后再打下一套」，全是复位造成的。

### 递进与换挡

- **强度单调递增**：越往后越重。第 3 招不能比第 5 招还猛，否则最后一招就没戏。
- **同节奏不超过 5 秒**：连打四五秒之后必须换挡——一次重击、一次位移或一次环境反应。
- **同一招一次交手里不用两次**：第二次会自动贬值成普通招式。
- **收束那一招只打一次**，并且必须是全场最重的一下。

### 留手要看得见

武学设定里说「发七分、留三分」「盈不可久」，画面必须有证据，否则只是台词上的说法。可写的三个证据：

- 掌推到底时**手肘仍微屈**，没有完全伸死；
- 掌势在**最后一寸收住**，接触点前有一小段空白；
- 回收时带一道**回拉的气流**，把碎屑往回带。

这三个比加特效更能表达「还有后手」，也比任何一句旁白都有效。

### 体系级检查

- 招式谱的七个字段都写了，没有「气势磅礴」「威力无穷」这类空词。
- 一次交手 3～5 招，三层预算对得上总时长。
- 相邻两招的姿态连得上，没有复位动作。
- 强度单调递增，收束招最重且只出现一次。
- 每一招的范式与它的意象对得上（贴身的招不能写成范围场）。
- 留手型武学是否给了三个可见证据之一。

### 爆发、命中与收束

必杀技的爆发段是整段的成败所在。这一节只解决三件事：连打怎么表示、命中了怎么让观众看见、结尾停在哪儿。

### 连打的三段表示法

模型不会真的打出一百拳。写「无数拳」「拳影漫天」的结果是：它给你三拳加一片白光。所以把连打拆成三段，每段写不同东西：

1. **可见段**（2～3 拳，约 1.5～2 秒）：写清每一拳的拳路、落点、残影数量。这一段是观众唯一能数清的拳，「先打肩、再打肋、第三下被抬臂架住」，写到这里为止。
2. **成线段**（0.6～1.2 秒）：拳路连成 1～2 条贯穿画面的光带，本体只保留肩背与拳峰，接触点连续出现火花。这一段不写「第几拳」，只写光带的走向和密度。
3. **结果段**（1.5～2.5 秒）：不再写拳。只写落点、受击位移、环境反应。观众在这一段读「打实了」。

三段的顺序不能倒：先数得清，才成线，最后只剩结果。倒过来写（先光带再数拳），会读成「先放光，再随便打两下」。

### 命中反馈至少给两项

只写「击中」是不够的。至少从下面挑两项写进画面：

- 受击方沿攻击方向位移，脚跟在地上拖出痕迹；
- 格挡部位的金属火花，或护具形变、凹陷；
- 衣料、披风、头发的滞后撕裂或扬起；
- 地面裂纹、碎石浮起、墙体凹陷；
- 气浪把周围的浮尘、纸片、水面向外推；
- 受击方的呼吸、重心、表情在命中后 0.5 秒内变化。

两项是下限。一项都没有，观众只会看到两个人的光在打架。

### 收束三条

1. **最后一帧停在最高点**：命中、失衡、倒地、爆点最大处。不要收在出招者摆造型，那会让整段的力全部泄掉。
2. **法相在命中后 1～2 秒内散干净**，按 aura.md 的消散三步执行，不留到下一镜。
3. **余波给一项**：气浪、碎屑落地、地面碳化、光点飘落、耳鸣。余波负责把这一击的重量交代完整。

需要延长时间时，宁可加余波和对手反应，不要加更多拳。

### 声音

- 连打不每拳一声。底层用一条连续破空声，上面叠 3～5 记点状撞击，读作「密度」而不是「机关枪」。
- 命中那一下，0.5 秒内补一记低频轰鸣，重量感靠低频不靠音量。
- 喊招按台词处理，按 4.1～4.5 可发声字/秒算进时长，不叠加成音效。
- 法相出现时给一层低频嗡鸣，消散时让它自然衰减，不用「叮」的收尾音。
- 只有确实发生的接触才写撞击声；格挡写金属、命中写闷响、落空只写气流。

### 速度感的四个可见符号

速度不能靠形容词，靠这四项具体写法：

| 符号 | 写法 | 读作 |
| 残影数 | 同一拳的 3～5 个错位残影 | 快 |
| 光带长度 | 跨越 1/3 画面＝快；跨满屏＝极快 | 速度等级 |
| 拖尾衰减 | 1 帧内消失＝高速；留 3 帧以上＝滞重 | 轻重 |
| 镜头微抖 | 命中瞬间 2～3 帧轻微抖动，幅度小于画面 2% | 冲击 |

四项里挑两项就够。四项全上，会变 MV，不像打斗。

### 反例对照

| 写成这样 | 模型会给什么 | 改成 |
| 无数拳影铺满画面 | 三拳加一片白 | 三段表示法：3 拳可见 → 1 条光带 → 只剩落点 |
| 一拳击出，天崩地裂 | 一个人站着，背景爆炸 | 先给接触点、位移、护具形变，再给气浪 |
| 众人都被震退 | 几个小人一起后退 | 只写同框里能看清的 2～3 人各自怎么退，其余用气浪和声音交代 |
| 收招，缓缓落地 | 摆造型站定，力泄掉 | 停在命中那帧，法相塌陷，余波落地 |

### 检查

- 连打是否落在三段里，可见段能不能数清拳数。
- 命中反馈是否至少两项，且落在同一个接触点上。
- 最后一帧是否停在最高点；法相是否已经散掉。
- 声音是否分了三层：连续破空、点状撞击、低频轰鸣。

## 特效事件十二类：先定事件，再定主体

同一招可以写出不同事件，事件决定主体的形态和运动。写之前先选一类：

| 事件 | 主体长什么样 | 运动 | 常见用法 |
| --- | --- | --- | --- |
| 冲击 | 一团被压扁的气浪 | 从接触点向外扩散 | 拳脚命中、落地 |
| 穿刺 | 一条细长锐器 | 直线贯穿，尾端收细 | 指法、枪刺 |
| 切割 | 一道弧形薄刃 | 划过留痕，痕迹停留半秒 | 剑、爪 |
| 爆发 | 从体内向外炸开的碎片 | 先聚后炸 | 蓄力、觉醒 |
| 牵引 | 一条能拉动的绳索状物 | 缠、拉、扯 | 控制、擒拿 |
| 屏障 | 一面半透明墙 | 挡下时出现裂纹 | 格挡、护体 |
| 包裹 | 一层贴身外壳 | 从脚向上包 | 护甲、附体 |
| 坠落 | 一片下压的阴影与碎块 | 自上而下 | 压制、天罚 |
| 追踪 | 一条会拐弯的轨迹 | 追着目标改变方向 | 飞器、灵物 |
| 领域 | 一圈铺开的地面纹样 | 以人为圆心铺开 | 气势、结界 |
| 置换 | 一进一出的两个身影 | 原地消失、别处出现 | 身法、瞬移 |
| 消解 | 从边缘开始碎成颗粒 | 由外向内 | 破招、化解 |

选事件的规矩：一招只选一件事；两种事件同时出现，必须分先后写清哪一秒是哪一个。
