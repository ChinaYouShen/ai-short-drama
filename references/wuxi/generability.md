# 动作的可生成性

写武戏最容易出的问题不是招式不够花，而是写了模型拍不出来的动作。这一份只管「能不能拍成」，不管招式设计。招式设计读 [flow.md](flow.md)，分镜读 [storyboard/index.md](storyboard/index.md)。

## 一、优先写高频、整体、单部位能完成的动作

| 可直接写 | 需要改写 | 为什么 |
| --- | --- | --- |
| 走进、坐下、起身、回头、点头、递物、接过、抱住、推门、放桌面、翻页、伸手去够 | 用工具挡住运动中的物体、厘米级位移、单指拧微小部件、四步以上双手编排、只靠微表情承重 | 前者高频、整体、单躯干或单臂即可完成；后者要求多部位同时精确对位 |

## 二、四类必须改写的高风险写法

1. **精确拦截**：两人同时争夺同一个小物、用手掌挡住正在合上的东西、运动中截住飞行物。要求双主体的时序与位置同时精确，几乎必崩。
2. **不可见的内部状态**：「像是听见了什么」「神色一凛」「忽然明白过来」。改写为可见表情与身体动作：「眉头猛地皱起，转头看向门口」。
3. **否定式动作**：「没有接话」「没有按下去」「不去看他」。画面生成不了「没发生的事」，改写成正在发生的替代动作。
4. **精细编排链**：一拍内串起三步以上手部动作或左右手分工。

## 三、改写方法，按顺序试

1. **换承担者**：让物件或环境承担变化——「门被风带上」替代「他用脚勾住门」。
2. **拆到相邻镜**：拆成「动作前」（笔停在纸上）与「结果」（纸上多了一行字），略掉难生成的过程。
3. **换成停留**：把精细操作换成「做完后手没有拿开」。停留只替换精细操作，情绪峰值仍要有可见表情与身体变化。
4. **交给声音**：动作不可见时由已声明声源承担（门被撞开的巨响由 `overall_soundscape` 交代）。
5. **标注高风险与降级方案**：确实无法替代时，在镜头说明里注明高风险，并给一个可接受的降级实现。

改写不得改变已确认的镜头边界、起止状态与剧情结果；若唯一可行的改写会改变结果，先说明再让用户定。

## 四、打斗与身体接触

**一时段只有一个主体出手。** 按回合分时写，每段只写一个人的发力路线，另一段写承受者顺着来力的反应：

```text
0～1.5 秒 他抡起木棍朝对方头顶劈下；
1.5～3 秒 对方上身朝自己右侧一偏，木棍擦着左肩落空。
```

双主体同时发力就是精确拦截，做不成。交锋咬合的画面靠剪辑在动作中途切换，不指望一次生成完成。

- **左右按人物自身写，不按画左画右**：写「他的右拳」「朝集装箱一侧偏身」。机位一换，画左画右就翻，按画面方位写必然穿帮。
- **写路线与反应，不写接触点形变**：写「右拳从镜头前方朝他下巴方向挥过，他的头猛地朝左甩开，踉跄后退两步」，不写「拳头打在脸上、脸被打得变形」。
- **贴身控制写两态**：先说清谁的哪只手臂箍住谁的哪里，再说松开或放倒；中间不写多步换手。
- **慢动作只给决定性一击**，并写明起止时刻；其余变速留给剪辑。
- **打击特写单独成段**：画面只写承受者，拳脚从画外闯入，头顺来力甩开，飞溅物（雨水、汗、尘）与镜头震动写在这一段；段与段之间写「切到」，不写连续运镜。
- 兵器在每镜的**起点与终点各在谁手里**都要写清；脱手要有落点，不能中途凭空换手。

## 五、固定机位必须写满三件事

写「固定机位」四个字等于什么都没说，执行端会自由漂移。必须写：

1. **固定构图**：景别、机位高度、轴线在哪一侧；
2. **画面里唯一在动的表演与环境元素**；
3. **保持时长**：「保持约两秒半不动」。

例：「固定特写，俯拍，轴线左侧，取她的头肩；画面内只有她的呼吸和身后帘子在动；保持约两秒半不动。」

## 六、同一时段不许指令打架

同一时间段里不能既写固定机位又写推近、跟随，也不能无过渡地先左摇再右摇。先静后动要写成不重叠的分段：

```text
0.0～1.2 秒 固定机位：等他抬眼；
1.2～4.0 秒 缓慢推近：从双人中景收至他的头肩近景，终点保持在既定轴线。
```

## 七、交付前自查

- 有没有一段里两个人同时发力？
- 有没有写「挡住」「截住」「捏住指尖」这类精确对位？
- 有没有用「神色一变」「似乎察觉」交代内心？
- 有没有「没有动」「没接话」这类否定式动作？
- 每一个「固定机位」是否三件事都写满了？
- 兵器每镜首尾是否都在明确的一只手里？
- 打斗镜的左右是不是按人物自身写的？
