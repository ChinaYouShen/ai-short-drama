# 选型交互：逐层下钻与返回

## 为什么需要这份规则

分类做完之后，选项数量已经超出「一次问完」的范围：六大类、几十个门派与阵营、十五部金庸作品、六十几门武功。如果把这些一次性摆出来，用户只会看到一个巨大的列表，然后随便挑一个，或者干脆放弃自己选。

所以选型必须**逐层下钻**，并且**随时能退回上一层**。这份文件就是这套交互的规则。

## 四层结构，一层一问

| 层 | 叫什么 | 典型选项数 | 例子 |
| --- | --- | --- | --- |
| L1 | 大分类（能量设定） | 5 | 武侠、神话、修真、异能、原创 |
| L2 | 门派 / 阵营 | 4～6 | 丐帮、少林、武当、明教；青铜、黄金 |
| L3 | 作品 / 流派 / 卷 | 3～5 组 | 射雕三部曲、天龙、笑傲、其余中篇、其余短篇 |
| L4 | 招式 | 5～8 推荐 | 见体系卡的参数表 |

**每层只列最多 5 项**。超过 5 项就先分组，再问组内——这是硬约束，不是建议。

## 状态要记住

每次提问都带一行面包屑，让用户随时知道自己站在哪、已经定了什么：

```
已定：武侠 › 丐帮｜待定：招式
```

规则：

- 已定的层**不重复问**，除非用户主动改；
- 待定的层不预先假设，但**能推断就不问**（见下一条）；
- 面包屑只说已定项，不铺开所有可选分支。

## 先推断，推不出来才问

用户给的输入里通常已经有答案，不要为了走流程而重复问：

| 输入里的信号 | 直接定到 |
| --- | --- |
| 「内力、经脉、掌门、帮派」 | 武侠 |
| 「小宇宙、圣衣、星座」 | 神话 |
| 「御剑、丹田、宗门」 | 修真 |
| 「异能、基因、外骨骼」 | 异能 |
| 「降龙十八掌 / 亢龙有悔」 | 武侠 › 丐帮 › 降龙十八掌 |
| 「天马流星拳 / 庐山升龙霸」 | 神话 › 青铜 |
| 「独孤九剑 / 吸星大法」 | 武侠 › 笑傲 |
| 直接给了招式名与时长 | 跳过全部选择，直接出镜 |

**只问缺失并且会改变结果的那一层**。如果用户说「写一场武侠对决，8 秒」，门派没定也不影响开写——按默认（丐帮或少林）先出一版，并在开头说明选了哪派，让用户可以改。

不要问「你想选哪个门派」这种开放式问题。给不超过 5 个具名选项，或直接默认。

## 返回上一步

用户说的每一句「退」都要能落到具体动作。识别与处置如下：

| 用户说 | 落到哪一层 | 保留什么 | 清空什么 |
| --- | --- | --- | --- |
| 返回 / 上一级 / 退一步 / 回去 | 上一层 | 上面的层 | 该层及其下的选择 |
| 换一个 / 不要这个 / 再看看 | 停在同层 | 上面的层 | 只清空本层这一项，重列本层选项 |
| 重来 / 从头开始 | L1 | 无 | 全部清空 |
| 第 N 个 | 停在同层 | 全部 | 无，直接落定该层第 N 项 |
| 随便 / 你定 / 都行 | 停在同层 | 全部 | 无，按默认策略自动选，并**明确说出选了哪一个** |
| 就到这 / 不用选了 | 当前层 | 全部已定 | 未定的按默认补齐，并说明补了什么 |

三条附加规则：

1. **返回一次只退一层**。用户连说三次返回，就退三层，不要一口气清空。
2. **返回后必须重列该层选项**，并带更新后的面包屑，不能让用户自己回忆上一屏是什么。
3. **已经产出的内容不算废掉**。如果上一层已经出过一版镜头，只改选择，不改已验证的结构——告诉用户「已按新选择重出，前版的时长与镜数不变」。

## 默认策略（用户说「随便」时）

按可执行性排序，不按名气排序：

| 缺什么 | 默认给谁 | 理由 |
| --- | --- | --- |
| 大分类 | 跟着剧本题材推；推不出按武侠 | 武侠的能量层最省算力，也最容易验证身体动作对不对 |
| 门派 | 挑一个「刚猛」加一个「阴柔」 | 有对撞才有交锋层次 |
| 招式 | 起手 1～2 招 + 收束 1 招，共 3 招 | 符合「一次交手 3～5 招」的上限 |
| 时长 | 起手 5 秒、收束 8 秒，合计约 13 秒 | 够走完四段，又不至于一镜太长 |

默认值要说出来，并且标明「可以改」。默默替用户决定是最坏的做法。

## 深层怎么分组

到 L3 时选项开始变多（金庸十五部就不是 5 个能装下的），用「先分群、再点名」：

| 层 | 分法 |
| --- | --- |
| 金庸作品 | 先给 5 组：射雕三部曲 / 天龙八部 / 笑傲江湖 / 中篇群 / 其余短篇，选定组再列作品 |
| 逍遥派武功 | 先分「吸与转」「掌与擒」「身法」三类，再点名 |
| 少林武功 | 先分「掌」「指」「抓」「防御」四类 |

分组依据是**打起来像不像**，不是书里的辈分或门派大小。同一组里的武功特效写法接近，用户选哪一门都不会翻车——这才是分组的价值。

## 提问模板

一句话，带上已定项，给不超过 5 个选项，最后留一个「或直接说招式名」。

```
已定：武侠 › 丐帮｜待定：招式
想打哪几招？（1 亢龙有悔 收束 · 2 见龙在田 起手 · 3 飞龙在天 压上 · 4 三掌连段 · 5 你按 8 秒帮我配）
也可以直接说招式名，或说「返回」回到门派。
```

关键是最后那句：**永远告诉用户可以退**。用户不知道自己能退，就会硬着头皮乱选。

## 反例

| 做法 | 为什么不行 |
| --- | --- |
| 一上来列 61 门武功 | 用户只会挑最有名的那一个，其余全白写 |
| 问「你想用什么武功」 | 开放式问题，等于把设计工作推回给用户 |
| 连着问四层才出内容 | 用户还没看到任何东西就被 interrogate 了四轮 |
| 用户说返回，却清空全部选择 | 用户只想改一层，却被惩罚 |
| 用户说随便，自己默默定了一套 | 用户不知道定的是什么，后面无法修正 |
