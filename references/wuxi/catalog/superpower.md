# 异能超能

## 能量形态

力量来自基因、科技或规则，不来自修炼。特征是**能量有机制，光效只是副作用**：

- 电弧、冲击波、力场、激光——每一种都对应一个物理或伪物理机制；
- 光效要跟着机制走：电弧走折线，激光走直线，力场走曲面，冲击波走球面；
- 明显的「过热、冷却、耗尽」状态可以做戏，这是别的分类没有的资源。

这类武戏最容易写成「谁的光更亮」，正确的写法是「谁的机制克制谁」。

## 法相

**通常不做神性法相**，取而代之的是三种：

| 类型 | 形态 |
| --- | --- |
| 能量外骨骼 | 贴身包覆的发光结构，只在发招时出现 |
| 能量拟形 | 由能量构成的兽或人形，半透明，动作跟随本体 |
| 机械投影 | 装备、无人机、外挂模块在身后展开 |

比例不要超过 1.3 倍，否则读成神话。透明度和边缘要「硬」——异能的光是锐利的，不是柔和的。

## 色板

异能偏好高对比的冷色配暖色：

| 槽 | 写法 |
| --- | --- |
| 主色 | 电蓝 `#1E90FF`、青绿 `#00E5C0`、紫 `#8A2BE2` |
| 辅色 | 近黑 `#101418` 压底 |
| 高光 | 白，给电弧与镜头光斑 |
| 暖点 | 橙红，给过载与熔毁 |

## 术语

招式名偏「代号、编号、功能描述」：

- 代号：雷霆一型、零式斩、第三形态；
- 功能：电磁炮、重力井、相位切割。

不要给异能角色配四字文言招名，一配就串味。

## 常见失败

| 表现 | 成因 | 改法 |
| --- | --- | --- |
| 光效无机制 | 随便糊一层发光 | 先定机制（电/力/热/重），光按机制几何形状走 |
| 和神话撞车 | 也做法相、也喊招 | 换成装备展开或能量拟形，语感改代号 |
| 全程满功率 | 没有过热与耗尽 | 一场里至少一次功率下滑或冷却 |
| 电弧像烟雾 | 折线画成软曲线 | 电弧走锐角折线，每次转折有节点 |

## 阵营与小分类

| 小分类 | 特征 | 状态 |
| --- | --- | --- |
| 单能力者 | 一种机制打到底，靠用法取胜 | 待补 |
| 能力团队 | 三到五人互补机制，靠配合 | 待补 |
| 机械强化 | 装备驱动，有损耗与维修 | 待补 |
| 规则系 | 改写局部规则（时间、距离、方向） | 待补 |

## 搭一套新的异能武学

1. 能源先定机制，一句话说清「靠什么产生效果」；
2. 色板冷底加一个暖点，过载时才用暖；
3. 显形选外骨骼或能量拟形，比例 ≤1.3；
4. 招式谱 8～12 招，每招对应一种用法（不只是更亮），并留一次耗尽的低谷。
