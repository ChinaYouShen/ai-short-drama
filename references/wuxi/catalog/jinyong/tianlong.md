# 天龙八部

## 为什么单列一卷

这本书的高特效武学最密，也是「能量离体后仍是实体」写得最狠的一本：六脉神剑的剑气能削断梁柱，北冥神功能把人抽干，生死符能让人痒到自伤。写这一卷，特效可以放开，但仍要守住一条——**每一招先有身体动作，再有能量**。

三条设定线：大理段氏的剑气、逍遥派的吸与转、少林与姑苏慕容的硬功与借力。

### 特效卡：六脉神剑

六脉不是六种颜色乱闪，是**六条不同长度、不同角度的细剑气**，一次最多出两三条。

| 脉 | 手位 | 画面特征 |
| --- | --- | --- |
| 少商剑 | 拇指 | 最粗最短，正面直刺，可断梁 |
| 商阳剑 | 食指 | 长而灵活，能拐弯绕柱 |
| 中冲剑 | 中指 | 最正、最快，一条直线贯穿画面 |
| 关冲剑 | 无名指 | 宽而钝，像一堵推过去的墙 |
| 少泽剑 | 小指 | 最细，可穿缝隙 |
| 少冲剑 | 小指内侧 | 最短促，近身突袭 |

- **形态**：剑气本身几乎看不见，看到的是**它经过的路径**——空气被划开的一道白线，持续不到半秒。
- **环境**：剑气扫过的梁柱出现平整切口，石块沿切面滑落，切口处冒白烟。
- **声音**：不是爆炸声，是**极细的破空声**，像鞭梢。
- **常见错**：把六脉做成六根彩色光柱。那是法术，不是剑气。
- **光形／粒子**：六道线状剑气，色统一为青白，靠长度与角度区分，见下表。
- **命中**：受击处是平整切口，石块沿切面滑落。
- **暖点**：无。剑气是「冷」的。

### 特效卡：北冥神功

这门武功的视觉逻辑是**减法**。

- **形态**：掌心形成一个向内塌的暗色漩涡，边缘有一圈幽蓝。
- **流向**：对手身上的光（或体温、气感）被抽成丝状，向掌心汇聚；对手的手由暖变灰，皮肤失去血色。
- **环境**：被吸者脚下的地面先湿后干（比喻体内水汽被夺），或周围温度下降。
- **命中反馈**：被吸者站不稳、扶墙、手指发抖；吸者掌心由暗转亮。
- **铁律**：绝不做成向外炸开的能量波。方向错了，这门武功就不成立。
- **光形／粒子**：内旋涡流一圈，边缘幽蓝，向内塌。
- **暖点**：掌心由暗转亮的那一息，就是暖点。

### 特效卡：斗转星移

姑苏慕容的核心是「以彼之道，还施彼身」，所以画面要给**两次同形不同向**：

1. 对方招式打到慕容复，接触点出现一个偏移的银色弧；
2. 同一个招式形态从慕容复侧后方反打回去，方向偏了三十到九十度。

观众看到的必须是「同一招又出现一次」，而不是一个新招。偏移的角度就是这门武功的性格。
- **形态**：接触点出现一个偏移的银色弧，招式被「拨」出去。
- **光形／粒子**：银色弧线，偏转角度 30～90 度，不闭合。
- **环境**：被转移的力在墙面、地面留下偏移痕迹，方向与原招不同。
- **命中**：同一招式形态从侧后方反打回去，打在谁身上由使用者决定。
- **暖点**：银弧亮一下，随即消失。

### 特效卡：生死符

- **形态**：掌心先凝出一片薄冰，薄得几乎透明，脱手后翻转着飞；命中时**看不见了**。
- **命中反馈**：中者当时无感，一息之后突然抓挠、打滚、自伤。
- **环境**：冰片划过空气留下一道极短的冷雾。
- **写法要点**：生死符的力量在于「之后才发作」，所以镜头必须给一个**空镜或旁观者反应**来承接这个时间差。
- **光形／粒子**：点状冰片，冷蓝，飞过时留一道极短的冷雾。
- **暖点**：无。

### 特效卡：火焰刀

- **形态**：掌缘横切，火不是喷出来，是**沿掌缘长成一柄刀的形状**，刃口最亮。
- **环境**：刀形火焰掠过之处，草叶先焦后燃，木柱出现一道焦黑斜切口。
- **命中**：受击处是一道灼痕，不是一片烧伤。
- **暖点**：整招都是暖色，所以**周围环境必须压成冷暗**，否则画面发糊。
- **光形／粒子**：刀状火焰，刃口最亮，向后逐渐散成火星。

## 选招建议

一场交锋建议这样配：一个「大理段氏」的剑气（六脉或一阳指）开场、一个「逍遥派」的吸或转做转折、一个「少林或丐帮」的硬功收束。

三方混战最忌讳每人都放绝学——按三层预算，让每人只出一次。

## 逐门特效卡（本卷全部补齐）

以下顺序与本卷武学总表一致，卡标题与表中武学名完全一致，可直接按名检索。

打狗棒法、一阳指已在射雕卷给出特效卡，本卷不重复；降龙十八掌见逐招专篇。

### 特效卡：小无相功

- **形态**：这门内功的特殊之处是「仿」——运行时体表没有固定光色，而是在**模仿对手的内力特征**。
- **光形／粒子**：淡银镜面感，贴身一层，边缘像水银流动；出招时的光形会**与对手同形**，只有色差。
- **环境**：脚下的影子会短暂变浅（模仿带来的错觉，可作为一种视觉诡计）。
- **命中**：看不出是它打的，像是对手自己的招式反打回来。
- **暖点**：不设暖点，它本身是「灰」的武功。
- **常见错**：做成银色光柱。它的高级感来自「看不出底色」。

### 特效卡：天山六阳掌

- **形态**：掌面朝上托起再翻压，像捧着火；掌过之处空气发烫扭曲。
- **光形／粒子**：面状掌印，橙金，边缘有热浪波纹；粒子上升不下降。
- **环境**：掌风过处草木先蔫后焦，水汽被蒸成白雾。
- **命中**：受击处衣物焦卷，人不是被打飞，是被**烫得后退**。
- **暖点**：整招暖色，只允许掌心一点最亮。
- **打击面（单）**：热浪要拍出「空气扭曲」，靠背景波纹而不是靠亮光。

### 特效卡：天山折梅手

- **形态**：全是擒拿：抓腕、扣肘、锁喉，动作短、转折多，一指一勾。
- **光形／粒子**：淡青细钩线，长度不过半尺。
- **环境**：几乎无破坏，只有布料被扯裂的声音。
- **命中**：关节被反向锁住，人**自己跪下**，不是被推倒。
- **暖点**：无。

### 特效卡：凌波微步

- **形态**：走位，不走直线，每一步都踩在对方攻击的空档；身法轻、脚跟不着地。
- **光形／粒子**：残影 2～3 层，间距均匀，**不做光带**。
- **环境**：踏过水面只起一圈很小的涟漪；踏过雪面只留浅印。
- **命中**：不攻击。它的功能是「不被击中」，镜头要拍对方连打三下全落空。
- **暖点**：无。

### 特效卡：参合指

- **形态**：隔空一指，指不动声色，身体几乎不转。
- **光形／粒子**：极淡的银线，**几乎看不见**，只在空气里留一道折光。
- **环境**：远处的柱子、门框突然出现一个小孔——**画面里要先看到结果，再回切出指的人**。
- **命中**：中者无声倒地，没有外伤。
- **暖点**：无。这是暗杀用的武功。

### 特效卡：化功大法

- **形态**：掌贴上去不发力，掌心先聚出一团毒烟，同时**抽走对方内力**。
- **光形／粒子**：内旋涡流 + 毒绿薄雾，雾向下沉。
- **环境**：被化者脚边的草枯黄；施术者袖口沾一层绿灰。
- **命中**：对方不是被打退，是**力气被抽空**：手垂下来、站不住、眼神散。
- **暖点**：无。毒绿是唯一主色。
- **铁律**：方向向内。做成外放光波就变成另一门武功了。

### 特效卡：冰蚕毒掌

- **形态**：掌面覆一层青碧色薄冰，出掌时冰屑沿掌缘脱落。
- **光形／粒子**：面状掌印 + 冰纹，冰屑**向下落**，不是向上飘。
- **环境**：掌风过处地面结霜，霜呈蛛网状扩散。
- **命中**：受击处先白后青，皮肤冻裂，人发抖。
- **暖点**：无。至寒至毒，不给暖色。

### 特效卡：易筋经

- **形态**：不动，只呼吸；体表浮起一层很淡的暗金，把外力化掉。
- **光形／粒子**：环状贴身，几乎不流动，像一层膜。
- **环境**：脚下的砖缝里冒出一点尘，被气机顶起。
- **命中**：受击时身体微退半步，衣袍先动、人后动。
- **暖点**：暗金只在受击点亮。
- **打击面（自）**：长镜头拍呼吸，不要剪碎。

### 特效卡：降魔掌 · 般若掌

- **形态**：掌出时掌心向下压，掌根先着；动作有「顿」，每掌之间停半拍。
- **光形／粒子**：面状掌印，边缘带一圈梵纹波动，暗金。
- **环境**：掌落地面，石砖下陷一寸，四周裂出细纹。
- **命中**：被打者全身一震，站原地吐血，不退。
- **暖点**：暗金在掌印中心一点。

### 特效卡：鸳鸯刀法

- **形态**：双刀一长一短，长的封、短的取；两人背靠背或并肩上。
- **光形／粒子**：两道短刀光，银白，交错成 X 形。
- **环境**：刀风切过布幔，布幔裂成两片不同角度。
- **命中**：一人被两刀同时制住，前一刀逼退、后一刀取要害。
- **暖点**：无。
- **打击面（单·群）**：可两人合击一人，也可分头各打一个，广角拍两组动作。
