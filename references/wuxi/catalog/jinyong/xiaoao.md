# 笑傲江湖

## 这一卷的特点

笑傲的武学几乎**不谈内力量级，只谈剑理**：独孤九剑是「无招胜有招」，辟邪剑法是「快到看不清」，两者恰好是特效的两极——一个是几乎不给光，一个是不给画面。

写这一卷的核心判断：**看不见的比看得见的更高级**。所以不要给独孤九剑加光效。

### 特效卡：独孤九剑

九式各有针对性，写特效要「一式一痕」：

| 式 | 针对 | 画面 |
| --- | --- | --- |
| 总诀式 | 通用起手 | 剑尖在身前画一个极小的圆，空气跟着起一个涡 |
| 破剑式 | 对方用剑 | 剑尖贴着对方剑身滑进去，两剑相擦出一点火星 |
| 破刀式 | 对方用刀 | 从刀背外侧切入，刀被带偏半尺 |
| 破枪式 | 长兵 | 剑走内圈，枪杆被削掉一截，断口平齐 |
| 破鞭式 | 软兵 | 剑尖挑住鞭梢，鞭子反卷回去 |
| 破索式 | 绳索 | 一剑断索，索头飞出 |
| 破掌式 | 徒手 | 剑尖停在掌前一分，掌风被逼散 |
| 破箭式 | 暗器 | 剑尖连点，暗器被逐一磕飞（最多三件） |
| 破气式 | 内功 | 剑尖刺入气墙，气墙从刺入点裂开 |

- **铁律**：全程**不做发光剑气**。观众看到的是剑、是手、是被破的东西，不是光。
- **速度符号**：残影 2～3 层，剑身与剑尖各一条极短的拖影，镜头微抖不超过 2%。
- **声音**：金属轻响，不轰鸣。
- **形态**：剑尖先到位，身体再跟上；所有动作都「先到后到」，没有预备。
- **光形／粒子**：**无光**。只有剑痕与 2～3 层残影。
- **环境**：被破的兵器留下切口；其余物件不动。
- **命中**：不是砍中，是**贴在对方兵器的破绽上**，让对方自己失手。
- **暖点**：无。加光就毁了「无招胜有招」。

### 特效卡：辟邪剑法

这门剑法的难点是「太快以至于拍不出来」。可生成的写法只有三条：

1. **不做全身动作**，只拍局部：手腕、剑尖、衣角；
2. **镜头切得比动作快**，每镜 0.5～1 秒，四五个短镜连成一串；
3. **结果先出、动作后补**：先给布屑飞起、对手衣带断开，再回切到出剑的人已经收势。

反例：写「只见一道红光闪过，敌人已倒下」。不可生成，也失去了这门剑法「快而阴」的性格。
- **形态**：不做全身动作，只拍手腕、剑尖、衣角；每镜 0.5～1 秒。
- **光形／粒子**：无光，只有残影与飞起的布屑。
- **环境**：布屑、纸片被切开后先飞起，动作后补。
- **命中**：**结果先出、动作后补**——先给衣带断开，再回切出剑的人已收势。
- **暖点**：无。

### 特效卡：吸星大法

与北冥神功同源，但要写出差别：

- 北冥是**静水深流**：暗蓝、缓慢、无声；
- 吸星是**强取**：黑紫、带撕裂感，被吸者会痛叫、青筋暴起；
- 共同铁律：方向必须向内，绝不做成外放光波。
- **形态**：掌心向下按住，五指张开，被吸者身体前倾。
- **光形／粒子**：黑紫内旋涡流，带撕裂感，边缘不稳。
- **环境**：周围温度微降，被吸者脚边草叶干枯。
- **命中**：被吸者痛叫、青筋暴起、站不住；吸者掌心由暗转亮。
- **暖点**：无。

## 选招建议

一场戏里同时出现令狐冲与岳不群（同门不同路），最有效的对比是：

- 令狐冲：无光、剑痕、慢半拍却总在先；
- 岳不群：紫气缠身、剑快、有残影。

两种视觉语言并置，观众立刻知道这是两种剑道，不需要任何台词解释。

## 逐门特效卡（本卷补齐）

以下顺序与本卷武学总表一致，卡标题与表中武学名完全一致，可直接按名检索。

独孤九剑、辟邪剑法、吸星大法已有专卡，不重复。

### 特效卡：紫霞神功

- **形态**：气从丹田起，沿任督上行，**贴体流转**，不外放。
- **光形／粒子**：紫色环状贴身，像一层流动的绸；出掌时紫气顺臂涌到掌心。
- **环境**：脚下尘土被气机推成一圈，向外扩散半尺。
- **命中**：掌力不猛，但一击之后对方**经脉发麻**，动作迟滞。
- **暖点**：紫色本身偏冷，暖点只在掌心一点金。
- **常见错**：做成紫色光柱冲天。紫霞是「护体与蓄力」，不是「放射」。

### 特效卡：寒冰真气

- **形态**：掌不发力，先握拳再张开，掌心已结一层白霜。
- **光形／粒子**：面状掌印 + 霜纹，霜从接触点向外爬。
- **环境**：墙面、地面结一层薄冰，半秒后化成水痕。
- **命中**：受击处青白，人抖，牙齿打颤；寒毒是「之后」发作。
- **暖点**：无。

### 特效卡：葵花宝典（残）

- **形态**：以针为兵，动作极小，只手腕动；出手速度高于画面帧率。
- **光形／粒子**：银白偏青的**点状细线**，一次一到三点，不成面。
- **环境**：绣架上的绸缎被无声穿出几个小孔，孔边无焦。
- **命中**：中者只觉一点刺痛，随后半边身子失控。
- **暖点**：无。
- **写法要点**：不做全身动作，只拍手部特写 + 结果镜头，中间靠剪辑省略。
