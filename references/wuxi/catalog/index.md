# 武戏分类与选招

## 武戏体系分类

## 为什么要分

原来的 `wuxi/` 是按**文档功能**排的：范式怎么判、法相怎么挂、颜色怎么配、收束怎么收。那是「怎么写」，回答不了「写哪一套」。

结果就是用户想看「武侠类的打法」，得先知道有个 `cases/xianglong.md`；想看神话题材，得先知道圣斗士那份叫 `saint-seiya`。两个案例并排躺着，没有共同的上一层，也没法往上加第三套。

这里补的就是缺的那一层：**先定体系，再定门派，最后定招式**。

## 两条轴，不要混

| 轴 | 回答的问题 | 放在哪 |
| --- | --- | --- |
| 体系轴（写什么） | 这是哪个世界的武学、谁的招式、什么能量 | 本目录 |
| 技术轴（怎么写） | 用哪种范式、几个接触点、几秒几镜、什么光形 | ../ultimate/ 与 ../moves/ |

两条轴正交。同一套「范围场范式」的写法，武侠里是掌力震波，神话里是星屑爆发——技术参数共用，能量形态不共用。所以不要为题材另写一套范式，只需在体系卡里指明能源形态与色板。

## 三层结构

| 层 | 叫什么 | 内容 | 用户怎么选 |
| --- | --- | --- | --- |
| L1 | 大分类 | 能量设定的来源（真气、神力、灵炁、异能、原创） | 单选一个 |
| L2 | 小分类 | 体系内的门派、阵营、师承 | 单选一个或多个 |
| L3 | 招式 | 具体招式卡 | 选 1～5 招，或让体系替你挑 |

L1 决定**能量层长什么样**——这是最根本的差异，因为法相、光形、色板全部由它推导。
L2 决定**招式谱和术语**——同一个大分类里，少林和丐帮的招式名、发力方式完全不同，但金色法相、掌力光形这些底层设定可以共用。
L3 才是镜头与提示词。

## 选项多了怎么问：逐层下钻

层数一多，一次性展开全部选项就会让人放弃自选。所以选型按**一层一问**推进，每层最多列 5 个选项，并且随时可以退回上一层。完整规则（含「返回 / 换一个 / 重来 / 随便」各自落到哪一层、保留什么、清空什么、默认值怎么给）见 select.md。

## 单选怎么问

三种问法都认，越具体越省事：

1. **只给大分类**：`帮我写一场武侠武戏` → 按 wuxia.md 走，招式现搭；
2. **给到大分类加小分类**：`丐帮的对打，用降龙十八掌` → 直接取 `cases/xianglong.md` 的十八招；
3. **给到招式**：`亢龙有悔，8 秒` → 跳过选招，只走镜头。

用户没说体系时，按剧本的题材推：出现内力、经脉、掌门就按武侠；出现星座、小宇宙、圣衣就按神话；出现御剑、丹田、宗门就按修真。推不出来才问一句，且只问一句「这场是武侠、神话还是修真」——不要摆一张五项菜单让人挑。

体系定了之后，**不要跨体系混用色板**。武侠的金色掌力和神话的金色星屑看起来都是金色，但一个是面状实体掌印、一个是点状碎光，混用就认不出这是哪一套。

## 新增一个体系：四步

1. **定能源**：这套武学的力量从哪来、怎么显形（气？光？符？力场？）。写一句话，后面全部由它推导。
2. **定色板**：主色、辅色、高光、暖点各一个，按 ../ultimate/palette.md 的四槽比例。一体系一套，不要每个角色一套主色。
3. **定法相**：有没有体量化的形象（龙、星座、剑影、兽形）。有就给形态、比例、显形方式；没有就明写「本体系不做法相，只做光效」，别含糊。
4. **定招式谱**：至少 8 招，按 ../ultimate/forms.md 的七个字段排：招式名、画面意象、范式、掌形或法相、递进层、最小秒数、可连段。少于 8 招撑不起一场交手，超过 20 招没人记得住。

四步做完，这套体系就能被单选，也能被别的剧本复用。

## 边界

前四个大分类里的具体作品（金庸武侠、圣斗士星矢等）版权属原作者与版权方。本目录只产出文字提示词与结构方法，用于个人练习与非商用同人：参考图自建、不拿原作截图喂模型、公开发布标「同人作品，非官方」。

要商用，走第五类 original.md：借结构，不借名字。

### 选型交互：逐层下钻与返回

### 为什么需要这份规则

分类做完之后，选项数量已经超出「一次问完」的范围：六大类、几十个门派与阵营、十五部金庸作品、六十几门武功。如果把这些一次性摆出来，用户只会看到一个巨大的列表，然后随便挑一个，或者干脆放弃自己选。

所以选型必须**逐层下钻**，并且**随时能退回上一层**。这份文件就是这套交互的规则。

### 四层结构，一层一问

| 层 | 叫什么 | 典型选项数 | 例子 |
| L1 | 大分类（能量设定） | 5 | 武侠、神话、修真、异能、原创 |
| L2 | 门派 / 阵营 | 4～6 | 丐帮、少林、武当、明教；青铜、黄金 |
| L3 | 作品 / 流派 / 卷 | 3～5 组 | 射雕三部曲、天龙、笑傲、其余中篇、其余短篇 |
| L4 | 招式 | 5～8 推荐 | 见体系卡的参数表 |

**每层只列最多 5 项**。超过 5 项就先分组，再问组内——这是硬约束，不是建议。

### 状态要记住

每次提问都带一行面包屑，让用户随时知道自己站在哪、已经定了什么：

```
已定：武侠 › 丐帮｜待定：招式
```

规则：

- 已定的层**不重复问**，除非用户主动改；
- 待定的层不预先假设，但**能推断就不问**（见下一条）；
- 面包屑只说已定项，不铺开所有可选分支。

### 先推断，推不出来才问

用户给的输入里通常已经有答案，不要为了走流程而重复问：

| 输入里的信号 | 直接定到 |
| --- | --- |
| 「内力、经脉、掌门、帮派」 | 武侠 |
| 「小宇宙、圣衣、星座」 | 神话 |
| 「御剑、丹田、宗门」 | 修真 |
| 「异能、基因、外骨骼」 | 异能 |
| 「降龙十八掌 / 亢龙有悔」 | 武侠 › 丐帮 › 降龙十八掌 |
| 「天马流星拳 / 庐山升龙霸」 | 神话 › 青铜 |
| 「独孤九剑 / 吸星大法」 | 武侠 › 笑傲 |
| 直接给了招式名与时长 | 跳过全部选择，直接出镜 |

**只问缺失并且会改变结果的那一层**。如果用户说「写一场武侠对决，8 秒」，门派没定也不影响开写——按默认（丐帮或少林）先出一版，并在开头说明选了哪派，让用户可以改。

不要问「你想选哪个门派」这种开放式问题。给不超过 5 个具名选项，或直接默认。

### 返回上一步

用户说的每一句「退」都要能落到具体动作。识别与处置如下：

| 用户说 | 落到哪一层 | 保留什么 | 清空什么 |
| 返回 / 上一级 / 退一步 / 回去 | 上一层 | 上面的层 | 该层及其下的选择 |
| 换一个 / 不要这个 / 再看看 | 停在同层 | 上面的层 | 只清空本层这一项，重列本层选项 |
| 重来 / 从头开始 | L1 | 无 | 全部清空 |
| 第 N 个 | 停在同层 | 全部 | 无，直接落定该层第 N 项 |
| 随便 / 你定 / 都行 | 停在同层 | 全部 | 无，按默认策略自动选，并**明确说出选了哪一个** |
| 就到这 / 不用选了 | 当前层 | 全部已定 | 未定的按默认补齐，并说明补了什么 |

三条附加规则：

1. **返回一次只退一层**。用户连说三次返回，就退三层，不要一口气清空。
2. **返回后必须重列该层选项**，并带更新后的面包屑，不能让用户自己回忆上一屏是什么。
3. **已经产出的内容不算废掉**。如果上一层已经出过一版镜头，只改选择，不改已验证的结构——告诉用户「已按新选择重出，前版的时长与镜数不变」。

### 默认策略（用户说「随便」时）

按可执行性排序，不按名气排序：

| 缺什么 | 默认给谁 | 理由 |
| 大分类 | 跟着剧本题材推；推不出按武侠 | 武侠的能量层最省算力，也最容易验证身体动作对不对 |
| 门派 | 挑一个「刚猛」加一个「阴柔」 | 有对撞才有交锋层次 |
| 招式 | 起手 1～2 招 + 收束 1 招，共 3 招 | 符合「一次交手 3～5 招」的上限 |
| 时长 | 起手 5 秒、收束 8 秒，合计约 13 秒 | 够走完四段，又不至于一镜太长 |

默认值要说出来，并且标明「可以改」。默默替用户决定是最坏的做法。

### 深层怎么分组

到 L3 时选项开始变多（金庸十五部就不是 5 个能装下的），用「先分群、再点名」：

| 层 | 分法 |
| --- | --- |
| 金庸作品 | 先给 5 组：射雕三部曲 / 天龙八部 / 笑傲江湖 / 中篇群 / 其余短篇，选定组再列作品 |
| 逍遥派武功 | 先分「吸与转」「掌与擒」「身法」三类，再点名 |
| 少林武功 | 先分「掌」「指」「抓」「防御」四类 |

分组依据是**打起来像不像**，不是书里的辈分或门派大小。同一组里的武功特效写法接近，用户选哪一门都不会翻车——这才是分组的价值。

### 提问模板

一句话，带上已定项，给不超过 5 个选项，最后留一个「或直接说招式名」。

```
已定：武侠 › 丐帮｜待定：招式
想打哪几招？（1 亢龙有悔 收束 · 2 见龙在田 起手 · 3 飞龙在天 压上 · 4 三掌连段 · 5 你按 8 秒帮我配）
也可以直接说招式名，或说「返回」回到门派。
```

关键是最后那句：**永远告诉用户可以退**。用户不知道自己能退，就会硬着头皮乱选。

### 反例

| 做法 | 为什么不行 |
| --- | --- |
| 一上来列 71 门武功 | 用户只会挑最有名的那一个，其余全白写 |
| 问「你想用什么武功」 | 开放式问题，等于把设计工作推回给用户 |
| 连着问四层才出内容 | 用户还没看到任何东西就被 interrogate 了四轮 |
| 用户说返回，却清空全部选择 | 用户只想改一层，却被惩罚 |
| 用户说随便，自己默默定了一套 | 用户不知道定的是什么，后面无法修正 |

### 东方武侠

### 能量形态

真气走经脉，显形为**掌风、剑罡、气墙**，不是光。判断标准：这股力离开身体之后还能撞到东西，但看不见光源。

所以武侠的能量层要克制：不做放射光柱，不做悬浮粒子云，只做三样——

- **风压**：空气被推开的可见形变，尘、沙、雨、雪、落叶被带动的轨迹；
- **劲痕**：掌印、剑痕、拳印留在实体上（墙、地、木、石），不留在空气里；
- **气罩**：护体真气只在受击一瞬间显出一层弧形轮廓，半秒内收掉。

一段武侠武戏里，全段只允许一个「气机外放」的镜头。多了就变成玄幻。

### 四个分支：金庸、古龙、梁羽生、温瑞安

同一套武侠能量层，四种笔法。选谱前先看这句：

| 分支 | 进库招式 | 特征 | 特效落点 |
| 金庸 | 71 招 | 绝学离体、借环境、成体系 | 掌印、龙形、剑罡，命中留痕 |
| 古龙 | 13 招 | 一击定胜负，几乎没有连招 | 白点、刀弧、扇面，一线一点 |
| 梁羽生 | 12 招 | 剑法成阵、门派正反 | 旋涡、浪头、山影，先铺空间再压人 |
| 温瑞安 | 7 招 | 贴身短狠，身体部位极端化 | 光带、拳印、炉火、针阵，加一道血线 |

四家不要混色：金庸的金掌力是**面状实体掌印**，古龙的冷白是**一线刀光**，梁羽生的霜白是**成层浪光**，温瑞安的铁灰是**贴臂光带**。看着都「亮」，画法完全不同。

### 法相

武侠**通常不做体量化法相**。人物背后浮一条金龙的写法属神话或修真，不是武侠。

例外只有一种：招式本身就带兽形（降龙十八掌的龙、打狗棒法的犬形虚影）。这时可以给龙，但要满足三条：

1. 龙形只出现在掌后，长度不超过一掌到一人半身，不飞天；
2. 龙首对齐掌根，不自由游走；
3. 命中后 1 秒内散尽，不留到下一镜。

除此之外的动作片一律按纯物理处理：没有背后影子，没有环绕光带。

### 色板

武侠的色板要**低饱和**，靠环境色出气氛：

| 槽 | 倾向 | 示例 |
| 主色 | 招式色，饱和度中 | 金 `#E8C45A`、青 `#4FC3F7`、绛 `#C0392B` |
| 辅色 | 环境暗部，压住主色 | 赭 `#7A4A16`、墨 `#2B2B2B` |
| 高光 | 冷白或暖白，只给兵器刃口与掌缘 | `#FFF3D0` |
| 暖点 | 命中处的朱红，≤5% | `#D94F2B` |

常见的错是给武侠配霓虹青紫——那是异能，不是武侠。

### 术语与喊招

武侠的喊招要短、要硬，多数招式是四字或三字：

- 二字：劈、崩、截、缠、缠丝、锁喉；
- 三字：劈空掌、擒拿手、铁沙掌；
- 四字：降龙十八掌、打狗棒法、一阳指、六脉神剑。

喊招用 4.1～4.5 字/秒算，四字招式在 1 秒内喊完，所以**起势与宣言可以并成一段**——武侠不需要神话那样长的宣言铺垫，喊两个字就出手。

### 常见失败

| 表现 | 成因 | 改法 |
| 打成玄幻 | 每个镜头都有光柱、粒子、浮空 | 只留一处气机外放，其余靠尘与劲痕 |
| 看不出门派 | 所有招式都用同一套掌风 | 每派锁定一种劲力特征（刚猛/阴柔/刚柔并济） |
| 人物飘 | 出掌不落地、重心不交代 | 每掌的支撑脚、膝弯、腰轴都要在动作描述里出现 |
| 招式变成摆拍 | 每招之间复位再起手 | 按 ../ultimate/forms.md 的承接铁律，上一招收势即下一招起手 |

### 搭一套新的武侠武学

按 [index.md](index.md) 的四步走，落到武侠上是：

4. 招式谱排 8～18 招，按起手/压上/收束分层，收束层只留 1～2 招。

### 原作没有招名怎么写

有些人物原作只写意境，不给招名（西门吹雪、谢晓峰、楚留香本人、燕十三第十五剑、练霓裳天魔解体、唐斩刀法）。这类条目按三条处理，不许硬造一个招名：

1. **条目名写「角色·动作（原作未命名）」**，例如「西门吹雪·一剑西来（原作未命名）」，不写成后人添加的「天外飞仙」。
2. **只写意境卡，不进招式参数表**。意境卡写镜头里看得到什么——剑身位置、光线折角、对方衣料被切开的走向，不写威力评价。
3. **要进参数表，必须指定版本**。指定到某一版影视或动画后按那一版动作写特效，并在条目后标「（XX 版）」。

### 打击面怎么标

每招参数表都有一列「打击面」，只允许八个取值，写别的值体检脚本会报错：

| 取值 | 含义 | 典型例子 |
| 单 | 只打一个目标 | 灵犀一指、天外飞仙 |
| 群 | 同时或连续覆盖多个目标 | 震惊百里、九条群龙、星屑旋转功 |
| 单·群 | 招式本身可单可群，看同框人数 | 降龙十八掌、天马流星拳 |
| 自 | 不命中任何目标，落点由自己选 | 凤舞九天、大移穴法 |
| 区 | 不造成伤害，只封住一片区域或一条路 | 乾坤大挪移、金刚伏魔圈、斗转星移 |
| 群·区 | 一次覆盖多人，同时封住一片空间 | 暗器成阵、先控后伤 |
| 自·单 | 先自位移脱出，再对单点出手 | 神龙摆尾接反击 |
| 自·群 | 先自位移脱出，扫向多名追击者 | 回旋类收势 |

### 神话神系

### 能量形态

这类武学的力量来自**神性授予**，不是修出来的。典型设定是「小宇宙」「神力」「星座之力」，共同特征是：

- 能量可以**离开身体独立成形**，甚至自己打出去；
- 能量有**颜色身份**——每个角色一套，不许换；
- 招式有**名字**，且必须喊出来，喊招本身就是仪式；
- 破坏规模可以越过物理常识（炸地面、断墙、掀屋顶）。

和武侠的分界线：武侠的力离体后只剩风压与劲痕，神话的力离体后是一个**看得见的实体**（龙、星屑、冰晶、锁链）。

### 法相

神话是**最适合做法相**的分类，也是这套技能包里法相规则的主要来源。

法相要满足六要素（详见 ../ultimate/aura.md）：

| 要素 | 神话里的写法 |
| --- | --- |
| 形态 | 星座图形、神兽、铠甲投影、光之人形 |
| 比例 | 本体 1.2～1.5 倍，收束招可到 1.5 |
| 位置 | 背后或身后上方，不遮脸、不遮接触点 |
| 透明度 | 40%～70%，收束时提到上限 |
| 色彩 | 角色主色铺底，高光勾轮廓 |
| 同步 | 相位滞后 0～0.2 秒，与本体动作同向 |

**分层**：起手层给边光与轮廓，压上层给体量与碎屑，收束层给最满的主色与最大比例。三层不是三张不同的图，是同一个法相的三次显形程度。

### 色板

神话允许**高饱和**，因为能量本身就是角色身份：

| 槽 | 神话写法 |
| --- | --- |
| 主色 | 角色专属色，饱和度高，占 30%～40% |
| 辅色 | 同色系深色，压出体积 |
| 高光 | 近白，勾星辰与铠甲边 |
| 暖点 | 命中处的小面积暖色，≤5% |

黄金圣斗士是唯一的例外：十二人共用一个金色，靠**光形与法相形态**区分——有人是光柱，有人是环，有人是拳影阵列。共色不共用光形，否则十二个人打起来分辨不出谁是谁。

### 术语与喊招

神话的招名偏长、偏诗意，常是五到七字，喊招本身就是一段表演：

- 四字：天马流星拳、庐山升龙霸、钻石星尘、凤翼天翔；
- 五字以上：庐山百龙霸、银河星爆、天舞宝轮、极光处刑。

所以在时长分配上，神话的**宣言段不能省**：喊招要 1.2～2 秒，占整段 15%。武侠可以省，神话省了就不像。

### 常见失败

| 表现 | 成因 | 改法 |
| 十二个人长得一样 | 全部共用一个金色，光形也共用 | 共色不共用光形，一人一种主光形 |
| 法相像贴纸 | 比例固定、不透光、没有相位滞后 | 按六要素做分层与相位 |
| 招招都是大爆炸 | 每招都按收束层做 | 按三层预算，只有最后一招是最高点 |
| 光效盖住人 | 法相压住脸与接触点 | 位置限定背后或上方，比例锁死 |
| 能量无来源 | 没有起势，直接从爆炸开始 | 起势段必须写出能量从哪来（小宇宙点燃、圣衣发光） |

### 修真仙侠

### 能量形态

灵炁、真元、剑意。和武侠、神话都不同的一点：**能量的形态是「可塑的」，会按意图变形**——

- 剑修：一道剑罡，笔直、细、长，破空无声；
- 符修：符纹、阵纹先出现，效果后到；
- 丹修：药力、烟气、火候；
- 体修：肉身强化，气劲贴身成甲。

这套分类里最值得写的是**「先有形，后有果」**：修真招式几乎都是先画出符号或阵图，再让效果发生。这是它区别于武侠（先动后风）与神话（先喊后爆）的核心节奏。

### 法相

修真允许三种显形，要选一种并锁死：

| 类型 | 形态 | 适用 |
| 剑影 | 巨大剑形虚影，悬于身后或身侧，剑尖指向目标 | 剑修 |
| 法身 | 人形或神像投影，比例 1.5～2 倍，动作与本体一致 | 道门、佛门 |
| 阵图 | 平面圆形纹样，贴地或贴空，随招式旋转 | 符修、阵法 |

**不要三样同时上**。剑影加阵图加法身，观众只会看到一片花纹。

### 色板

修真偏冷、偏青紫，靠"灵气"感：

| 槽 | 写法 |
| --- | --- |
| 主色 | 青、蓝、紫、白，饱和中偏高 |
| 辅色 | 深墨色压底，如 `#1B2A3A` |
| 高光 | 冷白，给剑刃与阵纹 |
| 暖点 | 极少，只在丹火、雷火类招式里用橙红 |

修真里出现大面积金黄要慎重——那容易读成神话或武侠，不是仙侠。

### 术语

招式名偏「功、诀、剑、经、符、阵」：

- 三字：御剑术、掌心雷；
- 四字：万剑归宗、六脉神剑；
- 五字以上：九霄雷霆诀、太虚剑意。

喊招语感要「稳」，不像神话那样激昂，也不像武侠那样短促——多是一句低声念出，配合结印。

### 常见失败

| 表现 | 成因 | 改法 |
| 满屏花纹 | 阵图、符、剑影同时出现 | 一种显形锁死 |
| 尺度过大 | 动辄剑开天门、毁天灭地 | 单场只给一处环境破坏 |
| 节奏像神话 | 先喊再爆 | 改成先结印成形，效果随后落地 |
| 剑罡是软光 | 剑没有刃、没有指向 | 剑形必须有明确剑尖与一条主轴线 |

| 宗门 | 显形 | 代表招式 | 状态 |

2. 色板锁青蓝紫，暖点只给火雷；
3. 只选一种显形（剑影 / 法身 / 阵图）；

### 异能超能

### 能量形态

力量来自基因、科技或规则，不来自修炼。特征是**能量有机制，光效只是副作用**：

- 电弧、冲击波、力场、激光——每一种都对应一个物理或伪物理机制；
- 光效要跟着机制走：电弧走折线，激光走直线，力场走曲面，冲击波走球面；
- 明显的「过热、冷却、耗尽」状态可以做戏，这是别的分类没有的资源。

这类武戏最容易写成「谁的光更亮」，正确的写法是「谁的机制克制谁」。

### 法相

**通常不做神性法相**，取而代之的是三种：

| 类型 | 形态 |
| --- | --- |
| 能量外骨骼 | 贴身包覆的发光结构，只在发招时出现 |
| 能量拟形 | 由能量构成的兽或人形，半透明，动作跟随本体 |
| 机械投影 | 装备、无人机、外挂模块在身后展开 |

比例不要超过 1.3 倍，否则读成神话。透明度和边缘要「硬」——异能的光是锐利的，不是柔和的。

### 色板

异能偏好高对比的冷色配暖色：

| 槽 | 写法 |
| --- | --- |
| 主色 | 电蓝 `#1E90FF`、青绿 `#00E5C0`、紫 `#8A2BE2` |
| 辅色 | 近黑 `#101418` 压底 |
| 高光 | 白，给电弧与镜头光斑 |
| 暖点 | 橙红，给过载与熔毁 |

### 术语

招式名偏「代号、编号、功能描述」：

- 代号：雷霆一型、零式斩、第三形态；
- 功能：电磁炮、重力井、相位切割。

不要给异能角色配四字文言招名，一配就串味。

### 常见失败

| 表现 | 成因 | 改法 |
| 光效无机制 | 随便糊一层发光 | 先定机制（电/力/热/重），光按机制几何形状走 |
| 和神话撞车 | 也做法相、也喊招 | 换成装备展开或能量拟形，语感改代号 |
| 全程满功率 | 没有过热与耗尽 | 一场里至少一次功率下滑或冷却 |
| 电弧像烟雾 | 折线画成软曲线 | 电弧走锐角折线，每次转折有节点 |

### 阵营与小分类

| 小分类 | 特征 | 状态 |
| 单能力者 | 一种机制打到底，靠用法取胜 | 待补 |
| 能力团队 | 三到五人互补机制，靠配合 | 待补 |
| 机械强化 | 装备驱动，有损耗与维修 | 待补 |
| 规则系 | 改写局部规则（时间、距离、方向） | 待补 |

### 搭一套新的异能武学

1. 能源先定机制，一句话说清「靠什么产生效果」；
2. 色板冷底加一个暖点，过载时才用暖；
3. 显形选外骨骼或能量拟形，比例 ≤1.3；
4. 招式谱 8～12 招，每招对应一种用法（不只是更亮），并留一次耗尽的低谷。

### 原创自定义

### 为什么单独列一类

前四个大分类都带着具体作品的影子，写出来能用，但商用有风险。真正能放心商用的路径只有一条：**照着结构新造一套**。

结构是可以借的——能源设定、色板四槽、法相分层、范式五类、三层预算、承接铁律，这些是方法，不是作品。名字、招式、角色、配色身份必须是自己的。

### 四步搭一套

### 第一步：定能源

回答一句话：这套武学的力量从哪来？

| 能源类型 | 显形 | 适合的故事 |
| 内生（气、血、骨） | 风压、劲痕、贴身气甲 | 武侠、体修 |
| 外授（神、契约、血脉） | 离体成形的实体、法相 | 神话、血脉觉醒 |
| 塑形（意、符、炁） | 可变形能量、阵纹 | 仙侠、术法 |
| 人造（器械、药剂、改造） | 锐利的几何光、外骨骼 | 科幻、异能 |

选一个，不要两个混。混合能源会让观众搞不清规则，规则不清就打不出「克制」。

### 第二步：定色板

按 ../ultimate/palette.md 的四槽：

- 主色 30%～40%：这套武学的身份色，全套共用；
- 辅色 20%～30%：同色系深色，压体积；
- 高光 ≤10%：近白，勾轮廓；
- 暖点 ≤5%：只给命中。

一个体系一套主色。若体系内有多个角色需要区分，靠**光形与法相形态**区分，不要靠换主色——换色会让观众以为这是另一个体系。

### 第三步：定法相

三选一，写清楚要不要：

| 选择 | 写法 |
| --- | --- |
| 不做 | 「本体系不做法相，能量只做前缘与劲痕」，全篇不出现体量化形象 |
| 做，单层 | 「背后浮一个 X 形投影，1.2 倍，只在收束招出现」 |
| 做，分层 | 起手边光、压上体量、收束 1.4 倍满色，按三层预算递进 |

不做也是有效选择，而且更省算力。含糊其辞才是最坏的——观众会看到每镜法相大小都不一样。

### 第四步：定招式谱

至少 8 招，最多 18 招，按七个字段排（见 ../ultimate/forms.md）：

| 列 | 内容 |
| --- | --- |
| 招式名 | 三到五字，同体系内语感统一 |
| 画面意象 | 一句话，写清光形与动作 |
| 范式 | 连打 / 单体突进 / 范围场 / 束缚 / 召唤 |
| 递进层 | 起手 / 压上 / 收束 |
| 最小秒数 | 按范式下限 |
| 可连段 | 能接在谁后面 |
| 独立特效 | 龙形动作、光形、粒子、环境反应、命中反馈、暖点时机 |

分层配额：起手 3～5 招、压上 3～5 招、收束 1～2 招。收束招越少越好，因为它只能用一次。

### 自检

- 能源能否用一句话说清？说不清说明还没定。
- 主色是否全套共用？有没有偷偷给某个角色换主色？
- 法相是「做」还是「不做」，有没有写死？
- 招式数是否在 8～18 之间？收束层是否只有 1～2 招？
- 每招是否有独立特效，而不是共用一套光？
- 名字有没有和别人撞？撞了就换，结构可以像，名字不能像。

### 已落地

目前没有原创体系的完整案例。建议第一个自建体系从「内生能源 + 不做体量化法相 + 10 招」入手——最省算力，也最容易看出动作本身对不对。做完可以按 ../ultimate/forms.md 的体系级检查过一遍，再参照 [cases/xianglong.md](../cases/xianglong.md) 的表格结构留档。
