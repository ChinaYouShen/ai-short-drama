# 神话神系

## 能量形态

这类武学的力量来自**神性授予**，不是修出来的。典型设定是「小宇宙」「神力」「星座之力」，共同特征是：

- 能量可以**离开身体独立成形**，甚至自己打出去；
- 能量有**颜色身份**——每个角色一套，不许换；
- 招式有**名字**，且必须喊出来，喊招本身就是仪式；
- 破坏规模可以越过物理常识（炸地面、断墙、掀屋顶）。

和武侠的分界线：武侠的力离体后只剩风压与劲痕，神话的力离体后是一个**看得见的实体**（龙、星屑、冰晶、锁链）。

## 法相

神话是**最适合做法相**的分类，也是这套技能包里法相规则的主要来源。

法相要满足六要素（详见 [../ultimate/aura.md](../ultimate/aura.md)）：

| 要素 | 神话里的写法 |
| --- | --- |
| 形态 | 星座图形、神兽、铠甲投影、光之人形 |
| 比例 | 本体 1.2～1.5 倍，收束招可到 1.5 |
| 位置 | 背后或身后上方，不遮脸、不遮接触点 |
| 透明度 | 40%～70%，收束时提到上限 |
| 色彩 | 角色主色铺底，高光勾轮廓 |
| 同步 | 相位滞后 0～0.2 秒，与本体动作同向 |

**分层**：起手层给边光与轮廓，压上层给体量与碎屑，收束层给最满的主色与最大比例。三层不是三张不同的图，是同一个法相的三次显形程度。

## 色板

神话允许**高饱和**，因为能量本身就是角色身份：

| 槽 | 神话写法 |
| --- | --- |
| 主色 | 角色专属色，饱和度高，占 30%～40% |
| 辅色 | 同色系深色，压出体积 |
| 高光 | 近白，勾星辰与铠甲边 |
| 暖点 | 命中处的小面积暖色，≤5% |

黄金圣斗士是唯一的例外：十二人共用一个金色，靠**光形与法相形态**区分——有人是光柱，有人是环，有人是拳影阵列。共色不共用光形，否则十二个人打起来分辨不出谁是谁。

## 术语与喊招

神话的招名偏长、偏诗意，常是五到七字，喊招本身就是一段表演：

- 四字：天马流星拳、庐山升龙霸、钻石星尘、凤翼天翔；
- 五字以上：庐山百龙霸、银河星爆、天舞宝轮、极光处刑。

所以在时长分配上，神话的**宣言段不能省**：喊招要 1.2～2 秒，占整段 15%。武侠可以省，神话省了就不像。

## 常见失败

| 表现 | 成因 | 改法 |
| --- | --- | --- |
| 十二个人长得一样 | 全部共用一个金色，光形也共用 | 共色不共用光形，一人一种主光形 |
| 法相像贴纸 | 比例固定、不透光、没有相位滞后 | 按六要素做分层与相位 |
| 招招都是大爆炸 | 每招都按收束层做 | 按三层预算，只有最后一招是最高点 |
| 光效盖住人 | 法相压住脸与接触点 | 位置限定背后或上方，比例锁死 |
| 能量无来源 | 没有起势，直接从爆炸开始 | 起势段必须写出能量从哪来（小宇宙点燃、圣衣发光） |

## 搭一套新的神话武学

1. 能源写「神性授予、离体成形、可独立冲出去」；
2. 色板给每个角色一套主色，同阵营共辅色；
3. 法相定形态与星座图形，全体系共用一套显形三步；
4. 招式谱 8～16 招，收束层只留 1～2 招，且必须带宣言。
