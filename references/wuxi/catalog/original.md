# 原创自定义

## 为什么单独列一类

前四个大分类都带着具体作品的影子，写出来能用，但商用有风险。真正能放心商用的路径只有一条：**照着结构新造一套**。

结构是可以借的——能源设定、色板四槽、法相分层、范式五类、三层预算、承接铁律，这些是方法，不是作品。名字、招式、角色、配色身份必须是自己的。

## 四步搭一套

### 第一步：定能源

回答一句话：这套武学的力量从哪来？

| 能源类型 | 显形 | 适合的故事 |
| --- | --- | --- |
| 内生（气、血、骨） | 风压、劲痕、贴身气甲 | 武侠、体修 |
| 外授（神、契约、血脉） | 离体成形的实体、法相 | 神话、血脉觉醒 |
| 塑形（意、符、炁） | 可变形能量、阵纹 | 仙侠、术法 |
| 人造（器械、药剂、改造） | 锐利的几何光、外骨骼 | 科幻、异能 |

选一个，不要两个混。混合能源会让观众搞不清规则，规则不清就打不出「克制」。

### 第二步：定色板

按 [../ultimate/palette.md](../ultimate/palette.md) 的四槽：

- 主色 30%～40%：这套武学的身份色，全套共用；
- 辅色 20%～30%：同色系深色，压体积；
- 高光 ≤10%：近白，勾轮廓；
- 暖点 ≤5%：只给命中。

一个体系一套主色。若体系内有多个角色需要区分，靠**光形与法相形态**区分，不要靠换主色——换色会让观众以为这是另一个体系。

### 第三步：定法相

三选一，写清楚要不要：

| 选择 | 写法 |
| --- | --- |
| 不做 | 「本体系不做法相，能量只做前缘与劲痕」，全篇不出现体量化形象 |
| 做，单层 | 「背后浮一个 X 形投影，1.2 倍，只在收束招出现」 |
| 做，分层 | 起手边光、压上体量、收束 1.4 倍满色，按三层预算递进 |

不做也是有效选择，而且更省算力。含糊其辞才是最坏的——观众会看到每镜法相大小都不一样。

### 第四步：定招式谱

至少 8 招，最多 18 招，按七个字段排（见 [../ultimate/forms.md](../ultimate/forms.md)）：

| 列 | 内容 |
| --- | --- |
| 招式名 | 三到五字，同体系内语感统一 |
| 画面意象 | 一句话，写清光形与动作 |
| 范式 | 连打 / 单体突进 / 范围场 / 束缚 / 召唤 |
| 递进层 | 起手 / 压上 / 收束 |
| 最小秒数 | 按范式下限 |
| 可连段 | 能接在谁后面 |
| 独立特效 | 龙形动作、光形、粒子、环境反应、命中反馈、暖点时机 |

分层配额：起手 3～5 招、压上 3～5 招、收束 1～2 招。收束招越少越好，因为它只能用一次。

## 自检

- 能源能否用一句话说清？说不清说明还没定。
- 主色是否全套共用？有没有偷偷给某个角色换主色？
- 法相是「做」还是「不做」，有没有写死？
- 招式数是否在 8～18 之间？收束层是否只有 1～2 招？
- 每招是否有独立特效，而不是共用一套光？
- 名字有没有和别人撞？撞了就换，结构可以像，名字不能像。

## 已落地

目前没有原创体系的完整案例。建议第一个自建体系从「内生能源 + 不做体量化法相 + 10 招」入手——最省算力，也最容易看出动作本身对不对。做完可以按 [../ultimate/forms.md](../ultimate/forms.md) 的体系级检查过一遍，再参照 [../ultimate/cases/xianglong.md](../ultimate/cases/xianglong.md) 的表格结构留档。
