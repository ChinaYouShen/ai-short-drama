# 武戏分镜索引

根据用户选择只读取一种主分镜模块；多人交锋可叠加多人模块，续接可叠加续接模块。

| 分镜选择 | 模块 |
| --- | --- |
| 单镜完成 | [single.md](single.md) |
| 多镜连续 | [sequence.md](sequence.md) |
| 续接上一段 | [continuation.md](continuation.md) |
| 多人交锋 | [multi.md](multi.md) |

所有分镜都遵循：每镜一个主要观察目标，前镜末态是后镜起点，关键接触点、支撑、兵器路径和受力方向可见；景别与运镜遵循 [../../cinematography.md](../../cinematography.md)。
