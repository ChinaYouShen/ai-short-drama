# 文戏生成流程

1. 确定当前场景目的、在场人物、关系状态、地点、时长和用户指定的情绪落点。
2. 区分实际说出口的台词、动作、心理、旁白、环境声和画面文字。
3. 按发生顺序排列刺激、发言或动作、接收方反应、关系变化和场景落点。
4. 按人物数量和用户选择加载对白、表演、关系、风格模块。
5. 先容纳完整台词和不可拆开的反应，再分配镜头时间。
6. 按用户选择加载单镜、多镜或续接规则。
7. 依 H3 路线组装字段并检查连续性。

用户提供完整剧本时保留事件顺序、人物关系、对白和结局。用户明确要求创作时，只补授权范围内的内容。没有写出的心理、关系转折、台词和动作不自动当作事实。

## 文戏节拍

将场景按“当前状态 → 刺激 → 人物选择 → 可见或可听反应 → 状态变化”组织。一个连续表演单元可以同时包含对白、视线和动作，不为凑镜头把同一反应重复发生。

有明确时码时沿用；没有时码时按实际对白、停顿、动作和反应安排自然时长。完整句子不能为了镜头切分而截断，时间不足时说明冲突并请用户选择延长、拆段或删减。
