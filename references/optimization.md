# 已有提示词优化流程

优化模式把用户现有提示词视为待维护的基线。先区分“事实错误”“H3 结构问题”“连续性问题”和“表达偏好”，再决定修改范围。

## 优化顺序

1. 标出必须保留的角色、对白、参考素材、动作顺序、结局、时长、比例、声音和禁项。
2. 判断当前文本属于 T2VA、I2VA、L2VA、FL2VA 还是 Ref2VA；发现字段混用先修结构。
3. 检查首帧或尾帧是否被误写成普通参考，检查参考标签是否稳定，检查人物和声音是否错绑。
4. 检查镜头时间、动作因果、文戏反应链或武戏接触链，优先修复会导致生成误解的问题。
5. 处理重复形容词、抽象情绪、堆叠运镜、过量特效和无法在时长内完成的内容。
6. 生成完整优化稿，再逐项核对没有改变未授权的故事事实。

如果用户给出结构化镜头对象，先把 `currentPrompt` 视为当前版本，把 `extra` 视为本轮修改范围。只更新用户点名的字段或段落；没有点名的对白、秒数、标签编号、素材顺序、分镜设定和结尾状态保持不变。除非用户明确要求，不输出新的 `beats`、分镜图提示词或其他镜头。

## 生成不了的四类写法

自查成稿里有没有下面四类写法，命中就改写。这不是审美偏好，是模型画不出来的东西：

- **否定式动作**：「没有接话」「没按下去」「不去看他」。画面生成不了没发生的事，必须换成正在发生的替代动作（把手缩回、把杯子推远、转身去擦桌子）。
- **不可见的内部状态**：「像是听见了什么」「神色一凛」「忽然明白过来」。换成可见的身体反应（眉头皱起、转头看向门口、手里的东西停在半空）。
- **精确拦截**：两人同时争夺一件小物、用手挡住正在合上的东西、运动中截住某物。这类要求双主体的时序和位置同时精确，会糊成一片；换成拦截的后果，或拆成两镜。
- **精细编排链**：一拍里串三步以上手部动作、左右手分工、单指操作小部件、厘米级位移。减到一两步，其余交给下一拍。

### 四条改写法（按顺序试）

1. **换承担者**：让物件或环境承担变化（门被风带上、杯子被碰倒、风把纸吹走），人只做反应。
2. **拆到相邻镜**：写成「动作前」和「结果」两镜，难生成的中间过程省略。
3. **换成停留**：把精细操作换成「做完之后手没有拿开」；情绪峰值仍要有可见的表情和身体变化，不能只靠停留。
4. **交给声音**：动作看不见时由已声明的声音承担（门闩响、瓷片落地、脚步停在门口）。

改写不得改变已确认的镜头边界、起止状态和剧情事实。唯一可行的改写会改变结果时，把冲突报给用户，不自行取舍。


## 修改边界

- 只优化用户选择的文戏或武戏部分；未选的另一戏型不被自动改写。
- 只优化用户选择的生成方式；需要换成另一种方式时先说明会改变输入约束，并让用户确认。
- 原有台词逐字保留，除非用户明确授权改词、翻译、增删或重新创作。
- 原有角色、人物关系、道具、空间和结局保留；补足的是表达路径，不是新剧情。
- 可把一条含混动作拆成起势、接触、反应和结果，但不能借拆分新增一次攻击或一次情绪转折。
- 可删除阻碍理解的重复词和无效镜头，但删除会改变剧情信息时列为待确认项。
- 用户提供的英文或其他语言提示词可以保持原语言；H3 字段名仍按格式文件固定，台词和画面文字保持原文。
- 参考素材清单是编号和类别的唯一依据。优化时不得因为补写画面而增加 `<Picture N>`、`<Video N>` 或 `<Audio N>`，不得把角色、场景、道具、站位的锁定作用互换。
- 连续镜头优化只沿用上一段末态和运动方向；本段时间仍从 `00:00.000` 起算，不把连续关系改写成首尾帧关系。

## 优化交付

完整交付包含：

```text
主要问题：...

优化后提示词：
<按选定 H3 路线的完整字段>

变更摘要：
- ...

文本检查：已检查结构、连续性和用户设定保留；未进行真实成片验证。
```

用户只要求可复制结果时，隐藏“主要问题”和“变更摘要”，只输出优化后的完整字段。用户只要求诊断时，只输出问题和修正建议，不伪造优化稿。

结构化输出至少保留原路线对应的完整字段和最终 `prompt`。如果用户只要求一段可复制文本，则隐藏内部对象和变更摘要，但不能隐藏路线字段导致基础三段与参考六段混用。
