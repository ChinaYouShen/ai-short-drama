## 能力矩阵：这套包管到哪一步

## 三条使用原则

1. **按产物调用，不按顺序跑**。用户要一集剧本，就只给剧本，不顺手把分镜也做了。
2. **缺环要显式说**。某项能力没有对应文件时直说「这块没覆盖」，不要用通用话术糊过去。
3. **一个域一个文件**。规则重复写两份，改起来必然打架；公共规则放公共件，域内规则放域文件。

## 还没覆盖的（如实登记）

| 缺口 | 说明 |
| --- | --- |
| 剪辑与成片合成 | 只给镜头级提示词与分镜，不产时间线工程 |
| 配音与字幕轨 | 有台词容量与音频账，没有逐句配音驱动与字幕时间轴 |
| 逐平台审核口径 | 有合规提醒，没有每家的具体红线清单 |
| 白模预演与三维场景 | 只给镜头规格与画面描述，不产白模工程 |
| 内容抓取与整剧下载 | 不提供抓取、下载、批量搬运 |
| 自动出片与付费接口 | 不代提交生成、不代扣费、不管理账号 |

这六项写清楚是为了让用户知道边界，不是待办清单的装饰。
