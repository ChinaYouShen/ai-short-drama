# 角色细节设定图

生成角色设定板，画幅和正文语言可由用户选择；跳过时沿用项目设置或输入语言，不强制设定固定画幅。保持同一人物、服装和发型。

- 【面部特写】：主区左侧，写清五官、眼神、发际线、发型、妆容、皮肤和身份锁定的脸部标志。
- 【三视图】：主区中部，正面、侧面、背面全身站姿并排，脚底对齐。
- 【局部细节】：按用户指定数量展示可见辨识点；未指定数量时只选足以锁定身份的关键特征，不强制凑格。
- 用户选择包含文字描述时，在右侧加入短信息区，写身份、身高体型、服装主色、性格关键词和有名称的色卡；不把文字区写成剧情。
- 禁止多角色、分镜、杂乱背景、缺失细节条、未经提供的身份特征和过度装饰。

输出 `prompt` 和 `negativePrompt`，按选定版式写明画面分段。
