# 分镜静帧

只为当前镜头生成一张静帧提示词，不写视频字段、时间轴、连续运镜或镜头编号。按 `beats` 选取最能代表该镜的一瞬；没有 `beats` 时使用画面设定。

- 提示词开头写中文景别；人物出镜时按本技能近距景别规则，不使用远景或大全景。
- 继承用户提供的角色、场景、道具和站位参考图编号；未提供的编号不虚构。
- 只表现一个瞬间，写清人物、地点、动作、站位、光线和关键道具；对白只在口型或表情确实需要时轻带，不抄整段台词。
- `linkPrev=true` 时承接上一镜结尾的位置和动作方向，但仍只画一个静止瞬间。
- 不写 `Picture`、`Shot`、秒数、字段名或镜头推进、摇镜等运镜过程。

默认输出 `framePrompt`；用户指定 JSON 时只返回该字段。

## 挂图按画面内容，不按所属场景

挂哪张图由「这一帧画面上有什么」决定，不由「这一段属于哪个场」决定。段在栈桥拍，但画面里出现了渡船、货箱、围观的人，就把渡船、货箱、人群的参考图都挂上；不挂，模型每一帧都会自己发明一条新的船，剪在一起就露馅。

- 逐帧过一次画面清单：出现的人物、穿在身上的服装、手里的道具、站的地面、背景里的建筑与载具，各对应哪张图。
- 用户没给对应图时，如实写出「无此资产图」，不虚构编号；角色没有设定图而必须锁脸时，提示词里写明「参考 <Picture N> 中的同一人」走链式参考，不靠文字重复描述去赌一致性。
- 提示词开头先说清每张参考图管什么：「<Picture 1> 为角色甲的脸与服装，<Picture 2> 为栈桥场景，<Picture 3> 为渡船」。
- **写清人物此刻的位置状态**：「甲已上船，站在船头」「乙仍在岸上，手扶缆桩」。只写「甲在船上」不够——省略起点，模型会把人画回岸上。
- 同一篇里画幅保持一致，不要一格横一格竖。
- 末尾固定一句：`No text, no watermark, no borders — a single clean full-bleed frame.`

## 出图后的验收四问

拿到图，按顺序问四句，任一条不成立就重出，不带病往下走：

1. 这是不是同一个世界？（场景光线、材质、时代感对得上吗）
2. 脸和服装对不对？（还是这个人吗，衣服换了吗）
3. 景别对不对？（写的是近景，出来的是不是中景）
4. 有没有多出来的人或物？（背景里混进来的路人、凭空出现的道具）

图片由外部工具生成，本技能只负责提示词；验收结论要写清是基于「实际看到的图」还是「仅按提示词推断」，没看到图就不写「已核对」。
