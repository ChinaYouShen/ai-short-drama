# 分镜静帧

只为当前镜头生成一张静帧提示词，不写视频字段、时间轴、连续运镜或镜头编号。按 `beats` 选取最能代表该镜的一瞬；没有 `beats` 时使用画面设定。

- 提示词开头写中文景别；人物出镜时按本技能近距景别规则，不使用远景或大全景。
- 继承用户提供的角色、场景、道具和站位参考图编号；未提供的编号不虚构。
- 只表现一个瞬间，写清人物、地点、动作、站位、光线和关键道具；对白只在口型或表情确实需要时轻带，不抄整段台词。
- `linkPrev=true` 时承接上一镜结尾的位置和动作方向，但仍只画一个静止瞬间。
- 不写 `Picture`、`Shot`、秒数、字段名或镜头推进、摇镜等运镜过程。

默认输出 `framePrompt`；用户指定 JSON 时只返回该字段。
