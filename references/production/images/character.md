# 角色设定图

生成一张角色设定拼图，画幅与背景可由用户选择；用户跳过时沿用项目设置或不锁定画幅。保持同一人物、同一套服装和同一发型。根据用户选择中文或英文正文。

## 三视图与面部特写

- 左侧放全身正面、侧面、背面三视图，脚底对齐，体型、服装形制、鞋和一件标志性小道具保持一致。
- 右侧放大尺寸头肩面部特写，写清年龄感、五官、眼神、发际线、发型、妆容、皮肤质感和身份锁定的疤痕、痣、眉形或瞳色。
- 动机和冲突只转成气质或表情，不写剧情；不写镜头运动。
- 不加入底部细节条、文字说明面板、身份关键词、身高列表、色卡、分镜、多角色或杂乱背景。

输出 `prompt` 和 `negativePrompt`。标题可使用“特写+角色设定三视图”，分段使用【三视图】、【面部特写】和【画风】。
