# 道具设定图

道具图只展示一件物件，写清主视图、多角度、结构、材质、尺寸、标志零件和画风。所有角度必须是同一件物件，零件相对位置和长宽厚方向保持一致。

- 依据道具卡的名称、用途、材质、磨损和尺寸生成提示词。
- 不加入人物、手、使用中的剧情、场景故事、对白或额外物件。
- 需要展示结构时分区描述外观、细节和材质；不把服装、发型、妆面或脸当作道具。
- 用户提供的参考图按原编号绑定，不新增图号。

输出可直接用于出图的 `prompt` 和必要的 `negativePrompt`。如果用户只要求道具信息卡，则调用 [../assets.md](../assets.md)，不生成图片提示词。
