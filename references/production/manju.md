# 漫剧制作

从小说原文起步时，先用 [adapt.md](adapt.md) 走完信息提取、人物卡、场景卡与 10～15 秒单元切分，再回到本文件写剧本与分镜。

漫剧是可独立启动的分支，不要求先完成短剧剧本或视频分镜。用户可只生成当前集剧本、只生成分镜或跳过其中一项。

## 漫剧剧本

- 场次数量和单场长度由用户内容与目标时长决定，不设固定场次数。每场围绕一个事件，按需包含标题、可见动作、对白和情绪。
- 对白语言沿用用户选择；画风只影响氛围，不改变题材和剧情。
- 不写镜头号、视频提示词或分镜；动作不混入画风、出图、材质和尺寸清单。
- 输出结构化结果时使用 `scenes`，每场包含 `number`、`heading`、`action`、`dialogue` 和 `emotion`。

## 漫剧分镜

- 一镜一行；换景、换机位、正反打、空镜或风景变化才拆新镜。
- 每镜可包含标题、节拍时间、时长、景别、运镜、画面、对白、人物、场景、道具、声音、续接状态和分镜图提示词。
- 长镜头超过单镜时长时，从下一段标记 `linkPrev=true`，时间重新从零开始并说明机位与运动如何接上。
- 同框人物数量、资产名称、对白和景别沿用输入；人物出镜遵循近距景别规则。
- 运镜枚举可按用户选择使用固定、推近、拉远、平移、摇镜、俯仰、环绕、跟拍、主观视角或克制手持；不叠加无目的动作。

## 检查与交付

检查场次顺序、对白、时长、分镜连续、资产绑定和静帧提示词。用户只要求检查时不生成下一阶段；用户要求 JSON 时返回 `scenes` 或 `shots`，否则输出可读结果。
