# 小说正文 → 分镜剧本

把一篇小说原文变成可以直接填进 H3 的 10～15 秒单元。这是改编层，不是创作层：**原文的事件、人物意图、关系结果不许改**，只改承载形式。

用户跳过某个阶段、只要求检查、或直接给剧本要 H3 提示词时，不跑这条流水线。

## 输入与默认

用户通常给一段正文加几条全局设定。收齐这六项，缺的按默认走，不追问：

| 设定 | 取值 | 默认 |
| --- | --- | --- |
| 画风 | 国风 / 日漫 / 美漫 / 写实 / 赛博 / 古风 | 日漫 |
| 画幅 | 16:9 / 9:16 / 1:1 | 16:9 |
| 单集目标时长 | 60 / 120 / 180 / 300 秒 / 不限 | 120 秒 |
| 台词风格 | 忠于原文 / 口语化改编 / 大幅精简 | 忠于原文 |
| 是否要旁白 | 是 / 否 | 否 |
| 分级 | 全年龄 / 轻度暴力 / 情感亲密戏 | 全年龄 |

默认值只用来开工，交付时说明用了哪些默认，不让用户以为是自己定的。

## 第一步：六类信息提取

通读全文再动笔，不看到第一段就写镜头。提六类：

- **人物**：姓名、性别、年龄段、外貌、服装、标志物、声线、性格三个词
- **关系**：谁对谁、现在什么情绪、权力与亲疏往哪边变了
- **事件链**：谁做了什么 → 导致什么 → 谁的反应，按因果排，不按段落排
- **台词**：原文直接引语，以及间接引语里能改成直接说的部分
- **环境**：时间、地点、天气、光线、空间布局、环境声、关键道具
- **情绪弧线**：从什么情绪起，中间在哪转，落在什么情绪

**心理与旁白只有四条出路**，多一条都不许：

1. 双人及以上场景 → 转成已绑定角色的画外音
2. 单人场景 → 改成画内行为：低声自语、叹气、对道具说话、手上加动作
3. 纯叙述旁白（「三年后」「他不知道的是」）→ 标「后期字幕」，不进视频生成
4. 字幕、论坛截图、聊天记录、片名、时间文字 → 标「后期处理」

单人场景禁止画外音。画外音需要有人在听，没人在听就没人替观众翻译内心。

## 第二步：人物卡

每个出镜角色一张。角色卡的用途是让模型每次都能画出同一个人，所以字段只写**能画出来的**。

- 绑定编号：`Subject N` + `<Picture N>`
- 性别与年龄段、发型（长度／颜色／造型）、服装（上装／下装／鞋／外套，写颜色与材质）
- 辨识锚点：最醒目的 1～2 个特征（疤、眼镜、发饰、纹身）——超过两个模型会挑错
- 身材比例：高瘦 / 中等 / 微胖
- 性格三个词、本段核心意图（这场戏他想要什么）

声线单独一组，七个槽位：

- 年龄段与性别呈现
- 音域：低 / 中 / 高
- 音色：清亮 / 沙哑 / 温柔 / 沉稳 / 尖锐
- 常态语速：偏快 / 适中 / 偏慢
- 音量：轻 / 中 / 大
- 句尾习惯：上扬 / 下沉 / 拖长 / 干脆收住
- 情绪变化：紧张时／生气时／克制时各变成什么样
- 禁止项：夹子音 / 播音腔 / 幼态撒娇腔

**双人同图**：两人在同一张参考图里时都绑 `<Picture 1>`，靠左右位置、发型、服装区分，**不许虚构 `<Picture 2>`**。
**双人独立图**：分别绑 `<Picture 1>`、`<Picture 2>`。
**编号三套独立**：`Subject`、`Picture`、`S` 不共用序号，每个角色写清它用哪张图。

## 第三步：场景卡

每个物理空间或时空跳一次，一张卡：

- 绑定编号（人物编号之后再排）
- 时间（白天／黄昏／夜晚／凌晨 + 季节）、地点（室内／室外 + 具体空间）
- 空间布局：前景、中景、背景各有什么
- 光线：自然光／灯光、方向、色温、明暗对比
- 环境声：风、车、虫鸣、人群、雨
- 关键道具：推动剧情的物品及其初始状态
- 氛围词两三个

场景卡的用途是跨单元复位。没有布局写清，第二段就会自己长出新的家具。

## 第四步：切 10～15 秒单元

### 硬边界（必须切新单元）

- 场景或时空改变
- 主要人物绑定改变（有人入画或离场）
- 动作链彻底结束
- 关系完成一次不可逆转向

### 组合规则

- 默认按 15 秒装：36～44 字有效台词 + 一条动作链
- 合并后超过 48 字、出现两条互不依赖的主链、或表演明显做不完，才拆
- 有效台词少于 24 字且只有简单动作，先试着并入前段或后段
- 按因果组合，不按台词行分段
- 保留完整的「铺垫 → 回应 → 落点」小回合
- 问句与直接回答不无故拆开

### 双层台词预算

这里有两套数字，管的事情不一样，不要混：

| 段长 | 纯口播上限（4.1 字/秒） | 实写预算（含表演） | 硬上限 |
| --- | --- | --- | --- |
| 10 秒 | 41 字 | 20～28 字 | 32 字 |
| 12 秒 | 49 字 | 28～36 字 | 40 字 |
| 15 秒 | 61 字 | 36～44 字 | 48 字 |

- **纯口播上限**是天花板：满屏说话、人不动，最多能念这么多
- **实写预算**是常态：一段里还要走位、抬手、反应、停顿，说话只占六到七成时间
- **硬上限**是红线：超了必须精简或拆段，不许加快语速硬塞

有迟疑、口吃、哽咽、爆发、长停顿、拥抱亲吻或复杂动作时，实写预算再降两成。
有效台词只数真正念出来的汉字、字母、数字，不数标点、动作和说明。

### Shot 密度

| 段长 | 建议 Shot 数 |
| --- | --- |
| 10 秒 | 2～3 |
| 12 秒 | 3～4 |
| 15 秒 | 3～5 |

- 每段只留一条「启动 → 回应 → 结果」主链
- 通常一个中等动作，或两个能接上的小动作
- 不同时安排换衣、长距离走位、取物、转场和长对话
- 倾听者必须对具体台词有可见反应，不能只写「认真听着」

单镜仍受 2～5 秒硬约束，所以 3 个 Shot 撑 10 秒、5 个 Shot 撑 15 秒是最顺的分配。

## 第五步：分段大纲

先出大纲再写正文，方便用户改结构。每段一行到六行：

- 编号、时长、段名
- 场景卡编号
- 有效台词字数
- 事件一句话
- 关系变化（起始 → 结束）
- 情绪弧线（起点 → 转折 → 落点）
- 主动作链（启动 → 回应 → 结果）
- 结尾落点

大纲不改剧情只改切法。用户看不懂大纲，就说明切法有问题。

## 第六步：单元剧本

### 单人场景

```
## P[NN]｜[10/12/15]秒｜[段名]

角色与绑定
S1 → <Picture 1> → Subject 1
场景 → Subject N

站位与初始状态
S1 位置与姿态（画面左/中/右，前景/中景，坐/站/靠，朝向，视线，手持物）
道具初始状态
环境细节（门窗、光线、背景声）
画面无可读文字

[Shot 1] [主体与景别]。[动作启动]，[1～3 个互相配合的表演信号]。
<Subject 1> (S1) says: <d>[Chinese] 台词 </d>

[Shot 2] [手部或道具近景]。[动作继续或道具状态改变]。[由该结果触发的具体反应]。

[Shot 3] [主体与景别]。[反应完成并转向新判断]。
<Subject 1> (S1) says: <d>[Chinese] 落点台词 </d>

末帧状态
S1 位置、姿态、视线、手部落点、表情；道具最终位置；环境是否变化；是否可直接复位
```

### 双人场景

多三样东西：两人距离（一臂／半米／隔桌）、180 度轴线（谁在左谁在右）、每个道具在谁手里。

反应必须落在对方说完之后，且写在具体部位上：肩膀塌、指尖收紧、视线移开半寸。听到刺激之前不许先有反应。

### 画外音（仅双人及以上）

写法固定三行：倾听者或道具镜头 → 延续中的画面动作 → 画外音标注 + 说话人与台词。不加冒号、不加人名解释、不写「继续」。

### 一次性环境人声

传令、报站、叫号这类只出现一次的角色：**不建人物卡、不绑 Subject、不给固定声线**，一句话不超过 20 字，不与主要角色同时说话，不跨单元出现。

### 末帧状态

每段结尾要写清：人物位置、姿态、视线、手部落点、道具状态、环境变化，并说明下一段能不能直接复位。这是跨段连续的接口，漏了下一段就会漂移。

## 台词改写

1. **忠于原文优先**：有直接引语的保留原句，只做自然分句
2. **间接转直接**：「他说他不想去」→「我不想去。」
3. **叙述转动作**：「她心里一紧」→「指尖收紧，呼吸顿了半拍」
4. **删**重复信息、书面连接词（然而、与此同时）、无法可视化的修饰
5. **字数**：落在上表的实写预算内，硬上限不越
6. **不许改**：人物意图、笑点落点、关系结果、关键信息量
7. **人名**：视频提示词正文不写中文姓名，用身份指代；需要拼音标签时用 `Xiao Chen` 格式（每音节首字母大写、音节间半角空格）

## 题材适配

| 题材 | 特殊处理 |
| --- | --- |
| 古风仙侠 | 服装锚点写朝代或架空风格；打斗拆「起手 → 接触 → 反弹」；法术写成光效、粒子、气流 |
| 悬疑恐怖 | 少台词、多环境音与呼吸；靠光影和道具位移制造紧张；单人场景禁画外音 |
| 都市职场 | 道具是手机、文件、杯子；室内光线讲逻辑；对话节奏偏快 |
| 甜宠言情 | 微表情与距离变化为主；亲密戏走安全流程；不用无因尖叫和叠词 |
| 喜剧轻喜 | 笑点来自动作与结果的反差，不靠夸张音效 |
| 科幻赛博 | 场景卡加科技元素；全息屏、机械臂写清交互方式；画面不出可读文字 |
| 战争动作 | 一段只留一条动作链；不同时跑动加对话；爆炸用音效加人物反应代替 |
| 校园青春 | 制服锚点统一；群戏只留主要说话人，其余虚化 |
| 历史年代 | 服装、道具、用语合时代；避免现代词穿帮 |

古风武戏要写特效时，转到 [../wuxi/index.md](../wuxi/index.md) 判体系与范式，不在这里凭空加光。

## 亲密戏与暴力戏的边界

- 亲密戏只在用户允许、关系允许时做，且必须有可见的接近过程：先把道具放下、再缩短距离，不许从数步外直接贴脸
- 不许道具凭空消失，不许单方突然强吻
- 末帧写清双方位置、额头或视线、手部落点、道具位置
- 暴力戏不写可执行的伤害细节，只写受力、姿态变化与后果

## 输出顺序

1. 信息提取摘要
2. 人物卡（每个出镜角色一张）
3. 场景卡（每个场景一张）
4. 分段大纲
5. 逐单元完整剧本
6. 自检结果

不跳步。用户只要其中一项时只给那一项。

## 自检

- 每单元 10～15 秒，台词字数标注且不越硬上限
- 少于 24 字的单元做过合并检查
- 每单元一次关系变化、一条主动作链
- `Subject` / `Picture` / `S` 编号全文一致，不跳号，不虚构未给的图
- 单人场景无画外音、无 S2
- 画外音只出现在双人及以上，写法固定
- 每个 Shot 独占一行、连续编号，单镜 2～5 秒
- 台词格式统一，带语言码
- 站位段在声线块之后、第一个 Shot 之前
- 末帧写清人物、道具、距离、视线
- 无背景音乐描述，只有环境音、人声与音效
- 画面无可读文字、字幕、水印
- 心理描写已全部转成可视动作、画内台词或合规画外音
- 临时环境人声 ≤20 字、不与主角同时说话、不延续
- 新场景重建站位；同场下一单元从上一段末帧完整复位

能用机器判的（字段结构、时间码、单镜与末镜时长、单段 15 秒、台词容量与语言码、说话人编号、主色唯一、法相比例、编号、角色名）跑一遍：

```
python3 scripts/validate.py --prompt 单元提示词.txt
python3 scripts/validate.py --prompt 单元提示词.txt --names 甲,乙
```

多段一起查时脚本按段切开，每段各自从 `00:00.000` 算，不会把第二段误判成时间码倒退。

## 与 H3 的对接

| 剧本里的部分 | 落到 H3 的位置 |
| --- | --- |
| 人物卡与绑定 | `subject_definitions` 的 `<Subject N>` 与声线 |
| 站位与初始状态 | `detailed_description` 开头 |
| 每个 Shot | 对应 `[Shot N]` 与时间码 |
| 末帧状态 | 最后一个 Shot 的收尾句 |
| 本段总时长 | 正文的「本段总长约 X 秒」 |

单元标题（`## P01｜…`）是管理信息，不复制进 H3 正文。

## 固定尾部

需要明确禁止画面文字与配乐时，在单元末尾逐字保留两行：

```
【禁止项】
文字/UI/水印/Logo/角标/可读文字/真实UI

【强制声明】
无背景音乐，仅保留环境音与人声和音效；画面禁字幕/文字/水印/Logo；禁止可读文字（指画面字幕文字，不含人声台词）
```

这两行只在对接口径要求严格时用。默认交付不需要，别把管理条款塞进画面描述。
