# 制作能力索引

本索引把短剧和漫剧的创作能力作为可独立调用的模块。用户可从任意阶段开始、跳过当前阶段、只改一个字段、退回前一步或直接指定最终产物；不要求按表中顺序走完全部流程。

完整能力清单见 [coverage.md](coverage.md)。该清单用于核对覆盖范围，不要求运行时全部加载。

## 路由方式

1. 先识别用户现在要完成的产物，不自动从选题阶段起步。
2. 读取该产物对应的模块，只加载完成当前任务所需的其他模块。
3. 用户说“跳过”时跳过当前选择或阶段，沿用已提供信息继续；不要求补齐被跳过的字段。
4. 没有指定补写强度时，保留故事事实、人物关系和已有对白，只补表达当前产物所必需的非剧情细节。
5. 信息不足但不妨碍当前产物时省略未知项；会导致人物、事件或素材绑定错误时，只询问该项，同时先完成不受影响的部分。
6. 用户要求检查时只报告问题；用户要求修改时只修改指定范围。
