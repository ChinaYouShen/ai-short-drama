# 生成预算与确认关卡

拍之前先算账。这一份管「要花多少次生成、什么时候必须停下来确认」，不涉及镜头写法。素材上限的接口口径见 [../h3-format.md](../h3-format.md)，多段切分见 [multisegment.md](multisegment.md)。

## 一、先算三个数

| 数 | 怎么算 | 用途 |
| --- | --- | --- |
| 镜头数 | 总时长 ÷ 平均镜长（竖屏 2～4 秒、横屏 3～5 秒） | 决定生成次数 |
| 素材数 | 角色参考 + 场景空景 + 道具特写 | 不能超过图 9 / 视频 3 / 音频 3 / 合计 12 |
| 重试系数 | 1.6（首轮约 6 成可用，其余重跑 1～2 次） | 估算实际生成次数 |

实际生成次数 ≈ 镜头数 × 重试系数 + 段数 × 0.3（每段至少一次整体重跑）。

## 二、一集成本表（填完再开工）

| 项 | 数量 | 单次耗时 | 小计 |
| --- | --- | --- | --- |
| 分镜静帧 | 张 |  |  |
| 视频生成 | 段 |  |  |
| 配音 | 条 |  |  |
| 重跑 | 次 |  |  |
| 合计 |  |  |  |

规则：

1. 表没填完不许开工；
2. 合计超过用户给的额度时，先减镜头数，不减时长——短镜头比长镜头更耐看；
3. 素材数超限时，优先砍道具特写，其次砍场景空景，最后才动角色参考图。

## 三、四个确认关卡

| 关卡 | 什么时候 | 确认什么 | 不确认的后果 |
| --- | --- | --- | --- |
| 一、脚本 | 开工前 | 人物、事件、结局、时长 | 后面全部返工 |
| 二、首帧 | 出第一张静帧后 | 脸、服装、光、构图 | 全片换脸 |
| 三、前三镜 | 前 3 镜出片后 | 节奏、特效、声音 | 风格定死，后面改不动 |
| 四、全量 | 全部出片后 | 连续性、伤情、时间线 | 交付后才发现断点 |

关卡三最重要：前三镜定的是这部片子的「手感」，这一关过了再放量。

## 四、止损规则

- 同一镜连续失败 3 次，改设计（换镜位、换动作、换光），不改措辞；
- 同一角色连续两次换脸，回到定妆图重出，不要在提示词里加形容词；
- 一段重跑超过 3 次，把这段拆成两段，短段更容易一次成。

## 五、省钱四招

1. **素材复用**：同一场景只建一张空景板，所有该场景镜头共用；
2. **参考图瘦身**：进生成前把参考图裁到主体，去掉无关背景；
3. **先低后高**：关键镜先出低分辨率定构图，构图过了再出片；
4. **一次多镜**：同一段内镜头连续、机位不变时合并成一次生成。
