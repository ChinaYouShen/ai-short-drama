# 故事大纲

## 可执行任务

- 从选题或用户概念建立完整大纲。
- 只生成大纲骨架、故事线、角色名单、三幕结构、节奏、结局或分集摘要。
- 只补充新增分集或分集看点。
- 从已有原文拆出大纲。
- 检查大纲字段、人物、集数、因果和结局是否完整。

## 执行规则

- 只写用户选择的部分；跳过角色、三幕、节奏或分集时不强行补齐。
- 需要完整大纲时，按“角色功能 → 时空规则 → 核心冲突 → 故事线 → 三幕转折 → 节奏波形 → 情绪锚点 → 结局 → 分集摘要 → 卡点”组织。
- 角色至少说明姓名、功能和一句定位；长画像留给人物卡。
- 每集摘要和看点分开写，集号连续；只补集数时保留已有集标题和摘要。
- 从原文拆解时按原文情节和章节计算集数，不凭固定集数填充；未完结文本不强行写成确定结局。
- 因果必须闭合，人物目标、阻力、转折和结果互相对应；没有原文依据的身份、秘密、反转和结局不新增。
- 用户指定 `strict` 时只整理已给事实；指定 `expand` 时只补授权范围内的结构表达，不新增角色或剧情结果。

## 交付

默认返回可读大纲。用户要求程序载荷时使用 `characters`、`setting`、`storyline`、`acts`、`rhythm`、`endingDesign`、`episodes` 等字段；未选择的字段不输出或保持原值。
