# 竖屏短剧节奏与钩子

这一份管剧集层的节奏，不管你写哪一集、写哪一段。分镜怎么排版见 [storyboard.md](storyboard.md)，剧本字段见 [script.md](script.md)，素材怎么锁脸见 [consistency.md](consistency.md)。

## 一、前 3 秒必须有事发生

观众是在信息流里被截停的，不是坐下来等故事开始。第一场只承担一个任务：让人知道«这里正在发生一件不能划走的事»。

**能用的六种开场**（有动作、有信息、有对抗）：

| 类型 | 长什么样 |
| --- | --- |
| 动作 | 一巴掌甩上去、合同被撕碎、手机砸在地上 |
| 身份 | 隐藏身份的人被叫破，保安被喊「董事长」 |
| 证据 | 录音响起、监控画面出现、聊天记录被投屏 |
| 关系 | 婚礼上新郎转身牵了别人、母亲当众否认亲生女儿 |
| 危机 | 刀架在脖子上、倒计时在响、病房门被撞开 |
| 反差 | 婚纱配菜市场、满身血的人抬头笑 |

**不能做的四件事**：先交代「这是一个普通的早晨」；用旁白介绍自己是谁；先拍空镜与城市街景；前两句台词全是寒暄。

不是只有第一集要抓人。追更用户常从中段切片进来，**每一集的第一场都要能独立抓人**。

## 二、单集三段：钩子 → 升级 → 留扣

| 段落 | 作用 | 常见写法 | 不能犯的错 |
| --- | --- | --- | --- |
| 开场钩子 | 3 秒内截停 | 耳光、摔门、身份暴露、证据出现、一句狠话 | 长篇背景介绍、慢镜铺垫、独白开场 |
| 矛盾升级 | 把冲突往前推一步 | 误会加深、反派加码、主角反击、信息揭露 | 原地吵架、重复情绪、只解释不行动 |
| 集末留扣 | 逼人点下一集 | 门被推开、真相到嘴边、反击刚要开始 | 平淡收尾、总结道理、写「未完待续」 |

单集一般 1～2 分钟，部分题材可到 3～4 分钟；再长就掉完播。判断一集该不该存在的标准很硬：**删掉它，后面完全不受影响，这集就不该有**。

## 三、爽点要有压迫、期待、兑现三件套

爽点是任何让观众立刻获得情绪回报的节点，不只是打脸。

常见六种：打脸反击、身份反转、证据到手、关系确认、反派失控、代价兑现。

密度：**每集至少一个小爽点**（一句反击、一个眼神、一条证据都算），**每 3～5 集一次大爽点**（身份公开、反派翻车、关系质变）。

三个零件缺一不可：先压迫（把人逼到墙角）→ 埋期待（提前给能反击的信号）→ 兑现（在具体动作或台词里完成）。没有压迫的反击是轻的，没有期待的反转是硬的，没有兑现的悬念是空的。

## 四、集末钩子不是暂停，是缺口

观众得停在一个「必须知道下一步」的位置。五种有效型：

- 动作中断：手刚碰上刀柄、巴掌刚举起、刀刚落下；
- 信息差：观众知道身份，反派不知道；
- 选择：主角必须在两个代价之间选一个；
- 反转：以为救星来了，来的是更大的敌人；
- 证据：关键证据刚露面，还没公开。

两个要避免的坑：**假悬念**（下一集一句话就解释完，观众觉得被骗）、**重复悬念**（每集都「门突然开了」，门后没有新信息）。

自检方法：写完这集，单独写下集第一反应。如果只能写「众人愣住了」，这个钩子就不够具体。

## 五、台词短、能演、带立场

- 单句一般不超过 20 字；
- 一句台词推动一个表情、一个动作或一个决定；
- 少解释，人物关系不靠旁白补；
- 冲突里要有立场，不要温吞；
- 留潜台词，狠话不必说满。

| 弱台词 | 强台词 |
| --- | --- |
| 我从来没想过你会这样对我，我真的很失望。 | 这一巴掌，我等了三年。 |
| 其实我一直隐瞒了我的真实身份，我是…… | 看清楚，这家公司姓什么。 |
| 你不要以为你做的事没人知道。 | 你昨晚进的那个房间，监控没坏。 |

台词的字数预算另按「秒数 × 语速」算，见 [../h3-format.md](../h3-format.md) 的双层台词预算；这里只管句子的长度与力度。

## 六、动作描写只写拍得出来的

心理活动一律转成可见动作：

- 不写「她心里很复杂」，写「她攥紧手机，指节发白，屏幕上的未读消息停在三秒前」；
- 不写「他忽然明白了」，写「他眉头猛地皱起，转头看向门口」。

能不能拍成、打斗接触怎么写，见 [../wuxi/generability.md](../wuxi/generability.md)。

## 七、连续性靠档案，不靠记性

写到几十集，崩的从来不是文笔，是连续性：伤疤换了位置、道具凭空消失、称呼前后不一。要有一份台账记：人物真实身份与公开身份、稳定特征、当前状态（受伤、身份暴露、关系变化、已知信息）、关系网、伏线索的 open/resolved、出场记录、关键道具外观与归属。

台账模板见 [../../templates/continuity-ledger.md](../../templates/continuity-ledger.md)。

## 八、这一段 15 秒里，钩子怎么落

我们交付的是 10～15 秒的单段视频，节奏规则要压到段内：

- **一段至少一个可见的变化**，别整段只有一个动作在推进；约每 2 秒应有一次可见的构图或动作变化，除非故意用长镜头压。
- 段的形状固定为：**钩子 → 升级 → 出口**。出口要留一个未闭合的动作或信息（手刚抬起、话没说完、门开一半），不要收在「事情圆满结束」。
- 如果这一整段只有一句台词，把它放在段的前 2/3 内，别拖到最后一秒还没说完。
- 如果这一段的情绪是松弛的，加一个反应转折、一次打断、一个揭示或一次权力反转，不要靠拖时长。

## 九、交付前自查

1. 第一场有没有强冲突或强悬念？是不是又写成了背景介绍。
2. 这一集推进了主线，还是原地对话？
3. 至少有一个明确爽点吗？它有压迫、期待、兑现三个零件吗？
4. 集末是具体缺口，还是「未完待续」。
5. 人物称呼、关键道具、伤疤位置前后一致吗？
6. 台词是不是又长又书面、像论文。
7. 动作描写能不能拍出来，有没有心理活动没落地。
8. 新埋的伏笔，进台账了吗？
