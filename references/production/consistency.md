# 角色、场景、道具的一致性

「换个镜头就换脸」不是提示词措辞能解决的，是三层各自锁死：**设定图**、**场景空景板**、**分镜承接**。跳脸的三个根因正好对应三层。

| 症状 | 根因 | 该修哪一层 |
| --- | --- | --- |
| 同一角色隔几段就换脸，越来越「大众脸」 | 长相描述被大段动作与技术指令稀释，模型退回「好看的脸」先验 | 设定图层：定妆图没有身份打头，或这段生成根本没带参考图 |
| 脸对了，但同场景每镜的光和色调都不一样 | 参考图烘进了光，被每个镜头继承，和分镜布光打架 | 空景板层：参考图不中性 |
| 段内人物位置、动作、道具状态接不上，不在场的人入画 | 镜头之间没有锚点 | 分镜承接层：没写延续，或用否定句点名了不在画面的人 |

三层怎么落到我们的文件：

- 定妆图提示词 → [images/frame.md](images/frame.md)、[characters.md](characters.md)
- 场景空景板 → [assets.md](assets.md)、[images/frame.md](images/frame.md)
- 分镜承接与段内延续 → [storyboard.md](storyboard.md)、[../h3-format.md](../h3-format.md)
- 台账 → [../../templates/continuity-ledger.md](../../templates/continuity-ledger.md)

## 第一层：定妆图（角色设定图）

目的是辨识度，不是气氛。四条硬约束：

1. **纯白底，单独成一条约束**。白底写一遍，负面清单里再写一遍；埋在整段描述中间一定会被突破。
2. **禁平光**。「均匀光、无阴影」是塑料脸配方，平光抹掉了皮肤纹理与骨相。写一盏约 75° 方向主光加补光与轮廓光，要求鼻下与颧骨有阴影、有眼神光、有明暗过渡。
3. **身份打头**。固定顺序：主体身份特征 → 身份锁定（禁网红脸、禁抹平特征）→ 技术参数 → 构图约束。骨相、痣、疤这些辨识特征放最前面；中文骨相词（丹凤眼、柳叶眉、山根、驼峰鼻）不要翻译成泛词，原词保留。
4. **脸 > 体态 > 服装**。声明这是演员定妆照，不是电商穿搭图，禁止为了露服装把脸缩小。也不要写「面无表情」，那等于主动删掉辨识度。

**长外套、长衫角色会「服装吞人」**：9:16 全身构图里米白大衣能占七成画面、脸缩成一小块。解法是另出一张半身照专门承载脸部，代价是每个角色多一张图。

主要角色建议：一张 9:16 全身白底定妆照 + 一张脸部裁切（近景、特写用）。近景脸占画面大块时，身份槽必须有面部图，否则模型按「好看的脸」自由发挥。

## 第二层：场景空景板

场景图是给视频当参考的**空景**，标准同样是中性：

- **无人空景**：场景描述里不出现人物；尺度用建筑构件自比（门高两人、桌宽一臂）。
- **三层纵深**：前景、中景、背景各有明确材质与陈设，模型才有位置安排机位。
- **写光源在哪，不写光落在哪**：写「暖白吊灯自画面右上方斜下打柔光」，不写「光打亮桌面」，不画明暗交界线。不用「暖黄」「冷蓝」这类饱和度词——3200K 打在皮肤上是暖白，写「黄」只会得到黄颜料。
- **禁氛围化**：不写 mood grading、剪影、雾、光束，不堆 cinematic / dramatic / 8K 这类老触发词。参考图里的雾会出现在这个场景的每一个镜头里。

**美术基调是项目级设置**，只注入一次，落在场景描述与分镜的布光里；**不要拼进角色图**，否则白底定妆照就被打上了场景的光。

## 第三层：分镜与段内的承接

- **段要长，镜头要短**。一段就是一次生成调用，尽量顶满 15 秒；提节奏靠压单镜秒数，不靠把段切碎。段切碎了，每段首帧都要重新建立人物位置，反而没有承接机会。
- **段内延续**：同一角色在段内的动作、位置、手持道具要写延续——上一镜他坐在窗边，下一镜就从窗边起。
- **只正向写画面里有谁**。不写「某某出画」「谁不在场」：否定句里的名字是吸引子，反而更容易把人画进来。要让人不在画面里，就换构图、换景别、让他背身或不入框。
- **布光写原因**，光位、介质、调色各写一次，不重复不冲突，与空景板保持一致。

## 五镜验收清单（同一角色并排看）

- ☐ 脸型、眉眼、鼻唇在五个镜头里一眼认得出是同一个人。
- ☐ 视觉锚点（疤、痣、饰品、发型）每镜都在，位置一致。
- ☐ 同一场景五镜的光源方向与色温一致，没有一镜暖一镜冷。
- ☐ 服装与手持道具在段内连续，没有凭空出现或消失。
- ☐ 没有不在场的人入画，没有出现第二个「主角」。
- ☐ 皮肤有纹理和明暗过渡，不是平光塑料脸。

哪一条不过，就回对应的那一层修，不要笼统地「加强提示词」。

## 视频生成侧的补丁

- **快速转头、大动作幅度容易让脸融掉**：稳定帧太少。降运镜幅度、拆成两镜、把大转头放到段首而不是段尾。
- **跨镜年龄漂移**：把年龄感写进定妆图的身份特征里，并每段带同一张图，不靠文字反复描述。
- **多人同框**：每段最多把关人物控制在 3 个以内，主角的脸占画面足够大，别让人群抢焦点。
- **景别跳太大**：同一段内从中景直接跳到过肩特写，脸会重算。用运镜推近，或用同角度的中间景别过渡。
