# 触发与独立路由

## 总触发

推荐格式：

`/AI生成短剧 提示词`

总触发只负责进入技能包，再按后续文字识别阶段、戏型和产物。没有指定阶段时进入总路由，不强制询问完整流程。

## 独立触发

触发词可以直接放在消息开头，后面的内容作为任务输入：

| 触发词 | 直接进入 |
| --- | --- |
| `/AI生成短剧`、`/短剧` | 总路由或用户点名的制作阶段 |
| `/选题` | 选题 |
| `/大纲` | 故事大纲 |
| `/人物` | 人物卡与缺项检查 |
| `/道具` | 道具卡与缺项检查 |
| `/场景` | 场景卡与缺项检查 |
| `/站位` | 站位卡与缺项检查 |
| `/剧本` | 短剧剧本 |
| `/分镜` | 短剧分镜 |
| `/图片` | 角色、道具、场景、站位或静帧图片提示词 |
| `/漫剧` | 漫剧剧本或漫剧分镜 |
| `/文戏` | 文戏模块与 H3 文戏提示词 |
| `/武戏` | 武戏模块与 H3 武戏提示词 |
| `/必杀技`、`/大招` | 必杀技模块：五范式、法相与配色、逐镜与 H3 提示词 |
| `/H3` | H3 基础、多参考或续接提示词 |

也可在总触发后指定阶段，例如：`/AI生成短剧 分镜 跳过剧本，直接把这段对白拆成近景连续镜头。`

## 平台写法

- Codex 原生技能触发：`$ai-short-drama 提示词`。
- 支持自定义斜杠命令的平台：`/AI生成短剧 提示词`。
- 只支持聊天文本的平台：直接输入 `/AI生成短剧 提示词`，或写“使用 AI生成短剧：提示词”。

斜杠是否显示为可点击命令由客户端决定。没有注册客户端命令时，斜杠前缀作为首段文本触发；不依赖按钮注册。任意平台都可以用自然语言直接说明任务，跳过任意阶段。
