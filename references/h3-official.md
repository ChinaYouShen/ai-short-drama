# H3 官方口径与写作细则

本文件对齐 MiniMax 官方两套提示词指南（基础 T2VA/I2VA/FL2VA/L2VA 与全参考六段）、视频生成 V2 接口文档，以及两个开源短剧技能包里被反复验证的实操经验。生成前读一遍，交付前用 `scripts/validate.py` 过一遍。

## 一、硬限制（接口层，不是建议）

| 项 | MiniMax H3 | 备注 |
| --- | --- | --- |
| 时长 | **4～15 秒，只接受整数** | 不是只能 5/10/15；8 秒、12 秒都合法 |
| 输出分辨率 | 768P / 2K | 2K 需走「视频再生成」 |
| 首/尾帧入口图片 | 0、1、2 张 | 0 张即文生视频 |
| 全能参考入口图片 | ≤ 9 张 | 与首尾帧互斥，不能混用入口 |
| 全能参考视频 | ≤ 3 段，单段 2～15 秒，总 ≤ 15 秒 | 只作结构或续接来源 |
| 全能参考音频 | ≤ 3 段，单段 2～15 秒，总 ≤ 15 秒 | 音色、对白、配乐 |
| 混合输入总数 | ≤ 12 个文件 | 图＋视频＋音频合计 |
| 提示词长度 | ≤ 7000 字符 | 超了会被截，台词容易丢 |
| 图片规格 | 边长 256～5760，宽高比 5:2～2:5 | 超范围直接失败 |
| 单文件体积 | 视频 50 MB、图片 30 MB、音频 15 MB | 只限单个素材 |

型号差异：**MiniMax-H3-Max** 为 5～15 秒、480P/768P，只支持文生与首尾帧，**不支持全能参考六段**。用户选了多参就别切到 Max。

接口里的 `role` 语义：`first_frame`、`last_frame`、`reference_image`、`reference_video`、`reference_audio`；再生成任务额外加且仅加一个 `base_video`。

生成前想要更完整的措辞，可先调 **H3-Context-IR**：它只返回增强后的提示词、不建视频任务，但同样要求传 4～15 秒时长；拿到结果仍要核对逐字台词与时长容量。

## 二、运镜必须写成「类型 + 幅度 + 速度」

运镜不是标签，是镜头内的一句自然描述。官方词表：

| 意图 | 写法 | 变的是什么 |
| --- | --- | --- |
| 变焦 | `Zoom In` / `Zoom Out` | 机位不动，焦距变 |
| 前后位移 | `Push In` / `Pull Out` | 机身向主体靠近或远离 |
| 左右平移 | `Truck Left` / `Truck Right` | 整机横向移动，不只是摇头 |
| 上下升降 | `Pedestal Up` / `Pedestal Down` | 整机升高或降低 |
| 原地转动 | `Pan Left` / `Pan Right` / `Tilt Up` / `Tilt Down` | 机身不动，镜头转 |
| 环绕 | `Arc Shot` | 绕主体走弧线 |
| 跟随 | `Tracking Shot` | 跟着移动主体走，保持关系 |
| 主观 | `POV` | 取主体所见 |
| 滚转 | `Roll Clockwise` / `Roll Counterclockwise` | 绕镜头轴转 |
| 不稳 | `Shake Slightly` / `Shake Strongly` | 受控晃动 |
| 不动 | `Static Shot` | 机位与焦距都不动 |

幅度只有两档：`with small amplitude`、`with large amplitude`。速度只有两档：`at slow speed`、`at fast speed`。**中等幅度与常速省略不写**。

```text
The camera pushes in with small amplitude at slow speed toward the folded letter in her hands.
The camera pans right with large amplitude at fast speed, revealing the open doorway.
The camera holds a static shot as the runner exits the frame.
```

中文正文里也照这个结构嵌英文短句，不要只写「镜头缓缓推进」「短弧环绕」——那类中文词模型只能猜。

## 三、切镜：五种动词，别为小变化切

- 切点动词只用这五个：`the camera cuts to`、`shot cuts to`、`shot transitions to`、`shot changes to`、`shot switches to`。交叉溶解、淡入淡出、划像只按用户明确要求使用。
- **切点必须带入新信息**：新主体、新空间、新状态、新视角或新时间。只换景别或轻微角度，一律用运镜解决。
- 首镜不写时间戳；后续写 `[Shot 2] At 00:03.500, ...`，切点严格递增且落在时长之内。
- 首尾帧任务通常一个连续镜头最稳：`[Shot 1]` 从 `Picture 1` 起，末段收束到 `Picture 2`。

## 四、台词、说话人与声音

- 说话人按实际发声顺序编号 `(S1)(S2)`，跨镜沿用；**不发声的角色不给编号**；两人齐说用 `(S1,S2)`。
- 身份、语气、动作写在 `<d>` 外，`<d>` 内只放语言标签与逐字台词：`(S1) 压低声音说：<d>[Chinese] 站住！</d>`。
- 画外音用固定短语 `says in an off-screen voiceover`，并在该 `<d>` 后紧接一句「画内角色嘴唇保持闭合」。同框有不说话的正脸时也要显式写闭嘴，否则口型容易落到近景不说话者身上。
- 同一句跨切镜：两段相接处都标 `<scenetrans>`，并写明声音跨切连续；只有视频结尾真的截断才用 `<cutoff>`。
- 复用的参考音频里听不清的片段写 `[unclear]`，不猜词、不改写；句末标点统一 `.`、`?`、`!`，去掉重复波浪号、表情与装饰符。
- 三层声音不混：
  - 镜头内同步声（台词、门响、画内收音机、角色弹奏）→ 正文时间线；
  - 全片环境与物理音（风、雨、脚步、布料、撞击、呼吸、喘息）→ `overall_soundscape`，1～4 句；不重复对白与音乐；
  - 只有观众听得到的配乐 → `non_diegetic_music`，1～3 句，只写乐器、速度、节奏、力度变化；**不许写抽象情绪词**，也不解释配乐在起什么情绪作用。
  - 无配乐写 `N/A`。省略这一层，模型会自己补一段音乐。

## 五、屏上文字

画面里必须出现的招牌、字幕、标签、界面、霓虹字，放进**英文双引号**并逐字保留原语言与原标点，不翻译、不改写：`A red neon sign above the door reads "开门" and stays unobstructed.`

## 六、全参考六段：标签怎么定

- `<Subject N>`：可复用的可见内容——人、物、场景、服装、道具、风格、动作、姿态、特效。
- `<Picture N>`：**只给真正当帧锚点的图**（首帧、尾帧、关键帧、分镜构图锚点）。
- **只用来定义长相、服装、场景的图，不单独建 `<Picture N>` 行**，把它写进 `<Subject N>` 的定义里：`<Subject 1> is the woman in <Picture 1>, with long dark hair and a blue cardigan.` 想让它当帧锚点，才另建一行。
- `<Video N>`：整段视频被剪辑、续接，或提供整片的镜头、切点、节奏结构。从视频里取出来的人或动作仍然是 Subject。
- `<Audio N>`：被复制或被参考的声音信号。参考视频本身带声音，不等于要建 Audio 标签；只有这段声音真的被复制或参考时才建。
- 一张图可以支撑多个 Subject；一个 Subject 也可以组合「图给外形 + 视频给动作 + 音频给音色」，逐项写明各自贡献。
- 编号在六段之间含义锁定，`summary` 里不新增未定义的标签。

`retention_analysis` 一行一个标签，并标注出现镜次：视觉用 `fully_preserved` / `partially_preserved` / `attribute_transfer` / `weak_reference`，音频用 `fully_copy` / `partially_copy` / `reference` / `weak_reference`。**这一节不写 `(Sx)`**——说话人编号只属于正文。

## 七、正文密度

官方给的参考是 **350～500 英文词**，这是信息量区间不是配额；对白密集的段优先把整条说话时间线写全。中文正文按同等信息量取 **350～550 字**，别为了凑字数灌形容词。

## 八、模型脾气（实操，不是官方条款）

- **文生偏真人**：非实拍画风（二维动画、三维 CG、黏土、水彩）在文生与首帧模式下容易滑向实拍。首句与每个 `[Shot N]` 开头都要声明媒介并排除 `realistic` / `photorealistic`；三维 CG 建议直接挂一张已定稿的画风起始帧走首帧模式。
- **首帧模式常忽略转身与出画方向**：要接戏的转身，先在起始帧把朝向摆出来，或多抽几张挑；还不行就在转身前切走。
- **只有场景图会拉宽景别**：没有起始帧时，场景图容易把镜头拉成远景。正文里要写清取景边界（例如「只拍到桌面与双手，不带到整间屋子」）。
- **近景与特写脸占画面大块时**：身份槽里只有全身板就加一张同造型的面部识别板，两图同时绑给同一个 Subject，保留分析里分工「五官发际」与「体态服装」。
- **首帧模式出声会延迟**：常见 1.3～2.4 秒才开口，排镜长要计入这段等待；纯等待镜头可在剪辑阶段剪掉。
- **两字呼喊容易漂**：单喊一个两三字的名字，发音常跑偏；画面允许时后期换音更稳。

## 九、生成后核对这些

1. 身份：脸、发型、痣位、身高比例是否与参考一致；近景有没有换脸。
2. 服装与道具：版型、颜色、损伤状态是否延续到每个镜头。
3. 构图与落帧：首帧是否就是 `Picture 1`；首尾帧的最后是否真的落到 `Picture 2`。
4. 动作：起势、接触点、受力、落地是否按正文发生；有没有凭空多出的动作。
5. 台词：是否由正确的人开口、口型是否对上、有没有多念或漏念、画外音时画内嘴唇是否闭合。
6. 声音三层：环境声是否缺、配乐是否在没要求时自己冒出来。
7. 时长与切点：实际秒数是否等于声明的时长；切点位置是否与 `At` 一致。

## 十、和官方口径的两处已知差异

- 官方两套指南写的是「六段正文用英文」；本包默认**英文字段名 + 中文正文**，因为中文创作者要直接读懂、直接改。结构、字段顺序、标签语义、保留标记与官方完全一致，只有叙述语言不同。要交给英文审稿或用英文接口时，把正文整体译成英文即可，不动标签。
- 官方 `overall_soundscape` / `non_diegetic_music` 建议 1～4 句 / 1～3 句英文。中文正文按句数对齐，不按词数凑。
