# 通用智能体入口

本包的唯一规则源是上一级 `SKILL.md`。加载本入口时，先读取根入口，再按用户选择读取 `references/production/index.md`、`references/h3-format.md`、`references/wenxi.md`、`references/wuxi.md` 或 `references/optimization.md`；选择文戏时继续读取 `references/wenxi/index.md` 和索引指定的模块，选择武戏时继续读取 `references/wuxi/index.md` 和索引指定的模块。

消息首段可以使用 `/AI生成短剧` 进入总路由，或使用 `/选题`、`/大纲`、`/人物`、`/道具`、`/场景`、`/站位`、`/剧本`、`/分镜`、`/图片`、`/漫剧`、`/文戏`、`/武戏`、`/H3` 直接进入对应模块。斜杠前缀按文本识别，不依赖客户端命令注册。

调用约定：

1. 先识别用户要做的阶段或产物；用户可直接指定选题、大纲、人物、资产、剧本、分镜、图片提示词、漫剧或 H3 提示词。
2. 沿用用户已明确的选择，只询问会造成错误的缺项。
3. 用户说跳过、直接开始、只检查或回到上一步时，立即按指定路径执行，不强制补齐前序阶段。
4. H3 任务再按根入口读取戏型、生成路线、补写强度、语言和对应模块。
5. 按用户要求输出当前产物，不自动生成未请求的下一阶段。

没有用户真实输入的台词、人物、素材和成片结果时不补写、不声称已验证。
