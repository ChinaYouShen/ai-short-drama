# 开工单模板

开工前先填这张单，五项填完再动笔。**没填完就写，返工都出在模型和时长上**：写完一集才发现目标模型只吃 15 秒，分镜全要重切。

放在项目根目录，文件名 `brief.md`。一张单管一个项目，换模型或换平台时改单，不重写正文。

## 一、交付物

| 项 | 值 |
| --- | --- |
| 本次要交 | 选题卡 / 大纲 / 人物卡 / 剧本 / 分镜 / 提示词 / 成片反拆（只填这次要的） |
| 交到哪一步为止 | 文字稿 / 可粘贴提示词 / 待生成清单 |
| 集数与单集时长 | 例：12 集 × 90 秒 |

## 二、目标模型与时长档

| 项 | 值 |
| --- | --- |
| 主用模型 | MiniMax H3 / Seedance 2.5 / 可灵 / Veo |
| 单次生成上限 | H3 15 秒；Seedance 2.5 30 秒 |
| 超过上限怎么办 | 拆段 / 走延长链 |
| 素材上限 | H3 图 9、视频 3、音频 3；Seedance 2.5 图 30、视频 10、音频 10 |

## 三、画幅与平台

| 项 | 值 |
| --- | --- |
| 画幅 | 9:16 / 16:9 / 1:1 |
| 分辨率 | 竖屏 1080×1920 |
| 目标平台 | 红果 / 抖音 / 快手 / 视频号 / 海外 |
| 交付规格 | 字幕、片头时长、水印要求 |

## 四、参考素材作用

每个素材只写一件事：它负责什么。没有的写「无」。

| 编号 | 素材 | 负责什么 | 不继承什么 |
| --- | --- | --- | --- |
| 1 | 主角定妆三视图 | 脸、发型、服装 | 背景、姿势、光位 |
| 2 | 柴房空景 | 空间、光位、材质 | 人物 |
| 3 | 拔刀动作视频 | 动作顺序与节奏 | 人物长相、服装 |

素材清点完再写正文。素材没到位的，标「待生成」，不拿文字描述去赌一致性。

## 五、一句话卖点与下一关

- 一句话卖点：谁 + 在什么处境 + 干了什么反常的事。
- 本单交完后的下一关：例「下一关：第 1 集分镜」。

## 用法

1. 用户第一次开口，先按这张单问缺的四项：交什么、什么模型、什么平台、有没有素材。
2. 用户已经说清的项不重复问。
3. 单填完，按 [SKILL.md](../SKILL.md) 的任务路由只读一个入口文件，一次把当前产物做完。
